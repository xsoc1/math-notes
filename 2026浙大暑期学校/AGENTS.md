# AGENTS.md — 2026 浙大暑期学校

## 项目范围

本目录保存 2026 浙大暑期学校的代数几何和黎曼几何课程记录、作业、参考教材及课程总览。目录下的 `代数几何课程记录/AGENTS.md` 和 `黎曼几何课程记录/AGENTS.md` 由各自子项目维护；本文件只维护暑期学校根目录的总览、跨课程链接和本目录级记录。

## 工作方法

- 维护前先在仓库根目录执行 `git fetch origin`，再检查 `git status --short --branch`。
- 课程总结只能依据目录中实际存在的课程记录、作业和参考资料编写；教材目录不自动等同于已完成的课堂内容。
- 新增 Markdown 使用 UTF-8 编码、YAML frontmatter、Obsidian wikilink、标准 LaTeX 和必要的 Callout。
- 跨课程总览应明确区分已保存记录、教材后续路线和仍需复核的证明边界，不编造授课信息或学习经历。
- 新增或调整根目录笔记后，更新仓库根目录的 `README.md`、根 `AGENTS.md` 和本文件的对话记录/变更日志。
- 提交时只暂存本次暑期学校相关文件，保留其他子目录已有的用户改动；同步前核验文件路径、链接、公式定界符和不可见字符。

## 维护边界

- 不修改 `代数几何课程记录/AGENTS.md`、`代数几何课程记录/Undergraduate Algebraic Geometry/AGENTS.md` 和 `黎曼几何课程记录/AGENTS.md`，除非对应子项目明确要求。
- 本目录不把参考教材的章节目录直接登记为已完成课程，也不将整理后的证明框架表述为经过独立文献审计的完整证明。
