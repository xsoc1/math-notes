# 作业 1

**Q1.** 设 $F(X,Y,Z) \in k[X,Y,Z]$ 为齐次多项式，且 $F(u^2, uv, v^2) \equiv 0$。证明 $(XZ - Y^2) \mid F$。

**证**：将三元多项式环 $k[X,Y,Z]$ 视为以二元多项式环 $k[X,Z]$ 为系数环、关于变元 $Y$ 的一元多项式环 $(k[X,Z])[Y]$。由于二次多项式 $Y^2 - XZ$ 关于变元 $Y$ 是首一多项式（最高次项 $Y^2$ 的系数为 $1$），可在 $(k[X,Z])[Y]$ 中将 $F(X,Y,Z)$ 对首一多项式 $Y^2 - XZ$ 作带余除法，唯一地写出：
$$F = Q \cdot (Y^2 - XZ) + R,\quad R = A(X,Z) + Y \cdot B(X,Z),$$
其中商式 $Q \in k[X,Y,Z]$，余式 $R$ 关于 $Y$ 的次数严格小于 $2$，故可表为 $R(X,Y,Z) = A(X,Z) + Y \cdot B(X,Z)$，这里 $A(X,Z), B(X,Z) \in k[X,Z]$。

现在将二次 Veronese 参数化 $X = u^2, Y = uv, Z = v^2$ 代入上式。由于在 $k[u,v]$ 中恒有 $(uv)^2 - u^2 v^2 = 0$，商式项自然消去，结合题设条件 $F(u^2, uv, v^2) \equiv 0$ 可得：
$$0 = R(u^2, uv, v^2) = A(u^2,v^2) + uv \cdot B(u^2,v^2).$$
考察上式右端在多项式环 $k[u,v]$ 中的单项式次数结构：$A(u^2,v^2)$ 展开后的每一个单项式关于变元 $u$ 的次数均为偶数，而 $uv \cdot B(u^2,v^2)$ 展开后的每一个单项式关于变元 $u$ 的次数均为奇数。由于奇次项与偶次项在 $k[u,v]$ 中线性无关、无法相互抵消，两者必须各自恒等于 $0$：
$$A(u^2, v^2) \equiv 0, \qquad uv \cdot B(u^2, v^2) \equiv 0 \implies B(u^2, v^2) \equiv 0.$$
又因为代入映射 $X \mapsto u^2, Z \mapsto v^2$ 将不同单项式 $X^i Z^j$ 映为互异单项式 $u^{2i} v^{2j}$，它是 $k[X,Z] \to k[u,v]$ 的单同态，由此推得 $A(X,Z) \equiv 0$ 且 $B(X,Z) \equiv 0$。因此余式 $R \equiv 0$，即 $F = (-Q)\cdot(XZ - Y^2)$，故 $(XZ - Y^2) \mid F$。$\square$

**Q2.** 设 $f,g \in k[x,y]$ 非零。证明存在 $p,q \in k[x,y]$ 使得 $pf + qg = r(y) \in k[y]$，且 $\deg_x p < \deg_x g$, $\deg_x q < \deg_x f$, $\deg r \le \deg f \cdot \deg g$。

**证**：将二元多项式 $f, g \in k[x,y] = (k[y])[x]$ 视为变元 $x$ 的多项式，其系数取值于整环 $k[y]$ 中。设 $\deg_x f = m \ge 0$，$\deg_x g = n \ge 0$（总次数分别为 $M = \deg f \ge m$ 与 $N = \deg g \ge n$），并约定零多项式的次数为 $\deg 0 = -\infty$。我们先单独处理 $m = 0$ 或 $n = 0$ 的退化边界情形，再给出 $m, n \ge 1$ 的 Sylvester 矩阵构造：
- **退化边界情形 1（$m = 0$ 且 $n = 0$，即 $f(x,y) = a_0(y), g(x,y) = b_0(y) \in k[y] \setminus \{0\}$ 均不含变元 $x$）**：若题面允许 $r(y) = 0$，则按 $\deg_x 0 = -\infty < 0$ 的约定，直接取 $p = 0, q = 0, r(y) = 0$ 即满足全部不等式（注：若按结式消元本意要求构造非零消元多项式 $r(y) \neq 0$，由于 $\deg_x p < 0$ 与 $\deg_x q < 0$ 迫使 $p = q = 0 \implies pf + qg = 0$，而 $0 \times 0$ 空矩阵行列式约定为 $1 \neq 0$，此时必须在题设中补充“$f, g$ 无非常数公共因子且 $\max(\deg_x f, \deg_x g) \ge 1$”）。
- **退化边界情形 2（仅有一方关于 $x$ 的次数为 $0$，不妨设 $m = 0, n \ge 1$，即 $f(x,y) = a_0(y) \in k[y] \setminus \{0\}$）**：此时直接取 $p(x,y) = a_0(y)^{n-1}$（满足 $\deg_x p = 0 < n = \deg_x g$）、$q(x,y) = 0$（满足 $\deg_x q = -\infty < 0 = \deg_x f$），即得非零多项式 $r(y) = p f + q g = a_0(y)^n \in k[y]$，且 $\deg_y r = n \deg_y a_0 \le N \cdot M = (\deg f)(\deg g)$（这恰好与下方 $n \times n$ 上三角 Sylvester 矩阵行列式 $\det M = a_0(y)^n$ 一致；$m \ge 1, n = 0$ 时完全对称）。
- **主要情形（$m \ge 1$ 且 $n \ge 1$）**：写出 $f, g$ 按 $x$ 的降幂展开式：
$$f(x,y) = a_m(y) x^m + a_{m-1}(y) x^{m-1} + \dots + a_0(y), \qquad g(x,y) = b_n(y) x^n + b_{n-1}(y) x^{n-1} + \dots + b_0(y),$$
其中各系数多项式关于 $y$ 的次数满足 $\deg_y a_{m-i}(y) \le \deg f - (m-i) = (M-m) + i$，$\deg_y b_{n-j}(y) \le \deg g - (n-j) = (N-n) + j$。

构造 $f$ 与 $g$ 关于变元 $x$ 的 $(m+n) \times (m+n)$ 阶 Sylvester 矩阵 $M$（前 $n$ 行由 $a_m, \dots, a_0$ 依次右移构成，后 $m$ 行由 $b_n, \dots, b_0$ 依次右移构成），并令结式为 $r(y) = \det M \in k[y]$。考虑列向量
$$v = \bigl[x^{n-1}, x^{n-2}, \dots, 1, \; x^{m-1}, x^{m-2}, \dots, 1\bigr]^T.$$
在矩阵 $M$ 中，将第 $j$ 列（$1 \le j \le m+n-1$）乘以 $x^{m+n-j}$ 后加到最后一列（第 $m+n$ 列）上，行列式 $\det M = r(y)$ 的值保持不变；此时最后一列的前 $n$ 个分量依次变为 $x^{n-1}f, x^{n-2}f, \dots, f$，后 $m$ 个分量依次变为 $x^{m-1}g, x^{m-2}g, \dots, g$。按最后一列进行代数余子式展开（或等价地，利用伴随矩阵恒等式 $\operatorname{adj}(M) M = (\det M) I_{m+n}$），即得
$$p(x,y) f(x,y) + q(x,y) g(x,y) = r(y),$$
其中 $p(x,y)$ 是由 $x^{n-1}, \dots, 1$ 以 $M$ 最后一列前 $n$ 个代数余子式为系数的 $k[y]$-线性组合，故 $\deg_x p < n = \deg_x g$；$q(x,y)$ 是由 $x^{m-1}, \dots, 1$ 以 $M$ 最后一列后 $m$ 个代数余子式为系数的 $k[y]$-线性组合，故 $\deg_x q < m = \deg_x f$。最后，由 Sylvester 结式的加权等权（isobaric）性质，将 $\deg_y a_{m-i} \le M - m + i$ 与 $\deg_y b_{n-j} \le N - n + j$ 代入行列式的 Leibniz 展开式，每一项关于 $y$ 的次数之和均不超过 $n(M-m) + m(N-n) + mn \le MN = (\deg f)(\deg g)$，从而保证 $\deg r \le (\deg f)(\deg g)$。$\square$

**Q3.** 设 $a \neq b \neq 0$。证明 $y^2 = x(x-a)(x-b)$ 不存在非常数有理参数化：即不存在非常数 $X(t), y(t) \in k(t)$ 满足 $y(t)^2 = X(t)(X(t)-a)(X(t)-b)$。

> [!note] 题面条件校勘说明
> 为使三次曲线 $y^2 = x(x-a)(x-b)$ 非退化（光滑），需将题面中的链式简写“$a \neq b \neq 0$”明确为如下数学补充条件：三个根 **$0, a, b$ 两两互异**（即 $a \neq 0, \, b \neq 0, \, a \neq b$），且底域满足 $\operatorname{char} k \neq 2$。若仅按链式不等号字面允许 $a = 0, b = 1$，则曲线退化为结点三次曲线 $y^2 = x^2(x - 1)$，存在非常数有理参数化 $X(t) = t^2 + 1, \, y(t) = t(t^2 + 1)$。此外，若在任意特征 $\operatorname{char} k \neq 2$ 的域 $k$ 上存在非常数有理函数解 $X(t), y(t) \in k(t)$，则它们在代数闭包 $\bar{k}(t)$ 中依然是非常数有理函数解，因此我们可直接将底域扩张到代数闭域 $\bar{k}$ 进行证明而无需对原域 $k$ 附加代数闭限制！

**证**（在 $0, a, b$ 两两互异且 $\operatorname{char} k \neq 2$ 下，采用 Miles Reid *Undergraduate Algebraic Geometry* Theorem 2.2 & Lemma 2.3, pp. 36–37 的因式分解无穷递降法）：
将系数域扩充至代数闭域 $\bar{k}$。反设存在非常数有理参数化 $X(t) = p(t)/q(t)$ 与 $y(t) = r(t)/s(t)$，其中 $p, q \in \bar{k}[t]$ 互素（$\gcd(p,q)=1$），$r, s \in \bar{k}[t]$ 互素（$\gcd(r,s)=1$），且 $q, s \neq 0$。代入曲线方程 $y^2 = X(X-a)(X-b)$ 并通分去分母，得到 $\bar{k}[t]$ 中的多项式恒等式：
$$r^2 q^3 = s^2 p(p-aq)(p-bq).$$
由 $\gcd(r,s) = 1$ 知 $\gcd(r^2, s^2) = 1$；同理，由 $\gcd(p,q) = 1$ 知 $\gcd\bigl(q^3, p(p-aq)(p-bq)\bigr) = 1$。因为在代数闭域 $\bar{k}$ 上任意非零常数均可开平方吸收，必有 $s^2 = q^3$（从而存在 $u_2 \in \bar{k}[t]$ 使 $q = u_2^2$），且分子满足 $r^2 = p(p-aq)(p-bq)$。由于 $0, a, b$ 两两互异且 $\gcd(p,q)=1$，三个因子 $p, \, p-aq, \, p-bq$ 在 $\bar{k}[t]$ 中两两互素；它们的乘积为完全平方 $r^2$，故在 $\bar{k}[t]$ 中三者各自皆为完全平方！

联同 $q = u_2^2$，互素多项式对 $(p, q) \in \bar{k}[t]^2$ 的四个两两不成比例的线性组合
$$q = u_2^2, \qquad p = u_1^2, \qquad p - aq = u_3^2, \qquad p - bq = u_4^2$$
全都是 $\bar{k}[t]$ 中的完全平方！直接调用 [Miles Reid, *Undergraduate Algebraic Geometry*, Lemma 2.3, p. 37](https://margalit.droppages.net/classes/math6421Fall2021/Reid.pdf)（在 $\operatorname{char} k \neq 2$ 下，通过线性重标定将前三个平方化为 $u_1^2, u_2^2, u_1^2 - u_2^2 = (u_1 - u_2)(u_1 + u_2) = u_3^2$，第四个化为 $u_1^2 - \lambda u_2^2 = (u_1 - \sqrt{\lambda} u_2)(u_1 + \sqrt{\lambda} u_2) = u_4^2$，利用互素性推出四个一次因式 $u_1 \pm u_2, \, u_1 \pm \sqrt{\lambda} u_2$ 也都是完全平方，从而得到最大次数减半 $\max(\deg u_1, \deg u_2) = \frac{1}{2}\max(\deg p, \deg q)$ 的新四平方组合，触发关于 $\max(\deg p, \deg q)$ 的 Fermat 无穷递降），任何具有四个两两不成比例平方线性组合的互素多项式对 $p, q$ 必同为常数。故 $X = p/q \in k$ 为常数，矛盾！$\square$
