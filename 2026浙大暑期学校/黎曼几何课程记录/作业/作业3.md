
## 1. 亏格 3 闭曲面上双曲度量的空间维数

对于亏格 $g \ge 2$ 的闭可定向曲面，泰希米勒空间的维数为：

$$\dim_\mathbb{R} \mathcal{T}_g = 6g - 6$$

代入 $g = 3$：

$$\dim_\mathbb{R} \mathcal{T}_3 = 6 \times 3 - 6 = 12$$

**答**：**12 维**。

> 注：亏格 3 的曲面可沿 $3g-3=6$ 条测地线剪成 $2g-2=4$ 条裤子。6 个长度参数 + 6 个扭转参数 = 12 维。

## 2. 欧氏平面中等角六边形：三条不相邻边不足以唯一确定六边形

**设定**：欧氏平面 $\mathbb{R}^2$ 中的等角六边形，所有内角均为 $120^\circ$。

**关键性质**：等角六边形的对边互相平行。设六边形顶点为 $v_1, \ldots, v_6$（逆时针），边向量为 $e_1 = v_2 - v_1, e_2 = v_3 - v_2, \ldots, e_6 = v_1 - v_6$。

由于内角均为 $120^\circ$，相邻边向量在复平面上相差因子 $e^{\pm i\pi/3}$，可得：

$$e_1 + e_3 + e_5 = 0, \quad e_2 + e_4 + e_6 = 0$$

且 $e_4 = -e_1$，$e_5 = -e_2$，$e_6 = -e_3$（对边平行且反向）。

**证明不充分性**：三条不相邻边的长度 $|e_1|, |e_3|, |e_5|$ 给定后，这三个向量满足 $e_1 + e_3 + e_5 = 0$。在 $\mathbb{R}^2$ 中，三个长度固定且和为 0 向量的向量构成一个**可变三角形**——该三角形可以绕原点整体旋转（1 个自由度）。此外，六边形的绝对位置未固定（2 个平移自由度）。

更直接地：给定 $|e_1|, |e_3|, |e_5|$，向量 $e_1, e_3, e_5$ 构成三角形仅确定到**刚体运动**（旋转 + 反射 = 1 维连续族）。而 $e_2, e_4, e_6$ 完全由 $e_1, e_3, e_5$ 决定（$e_2$ 的方向由 $e_1$ 旋转 $120^\circ$ 确定，等等）。

因此存在**无穷多种**不同（不全等）的等角六边形具有相同的三条不相邻边长。$\square$

## 3. 平坦 3-流形 $M$ 的构造及其双重复叠

**设定**：
- $T^2 = \mathbb{R}^2 / \mathbb{Z}^2$，标准平坦环面
- $A: T^2 \to T^2$，$A(x, y) = (1-x, 1-y)$（对径映射，involution）
- $M = T^2 \times [0, 1] / \sim$，其中 $(p, 0) \sim (A(p), 1)$

**构造双重复叠**：

考虑 $T^3 = \mathbb{R}^3 / \mathbb{Z}^3$，坐标为 $(x, y, z)$。将其视为长 $2$ 的圆周上的环面族：$T^3 = T^2 \times S^1$，其中 $S^1 = \mathbb{R} / 2\mathbb{Z}$（周长 $2$）。

在 $T^3$ 上定义对合映射：
$$\sigma: T^3 \to T^3, \quad \sigma(x, y, z) = (1-x, \; 1-y, \; z+1)$$

**验证 $\sigma$ 是自由作用的不动点无关对合**：
- $\sigma^2(x, y, z) = (x, y, z+2) = (x, y, z)$（模 $\mathbb{Z}^3$，因为 $z+2 \equiv z \pmod{2\mathbb{Z}}$）
- 若 $\sigma(p) = p$，则 $z+1 \equiv z \pmod{2\mathbb{Z}}$，即 $1 \equiv 0 \pmod{2}$，矛盾。故 $\sigma$ 无不动点。

**商空间**：$T^3 / \langle \sigma \rangle$。在基本域 $z \in [0, 1]$ 上，等价关系为：
$$(x, y, 0) \sim \sigma(x, y, 0) = (1-x, 1-y, 1)$$

即 $(p, 0) \sim (A(p), 1)$，这正是 $M$ 的定义。因此：
$$M \cong T^3 / \langle \sigma \rangle$$

**结论**：$T^3$ 是 $M$ 的**双重复叠空间**（因为 $\sigma$ 是二阶的），且 $T^3$ 是标准平坦 $3$-环面。覆叠映射 $\pi: T^3 \to M$ 是局部等距（$\sigma$ 是等距变换），故 $M$ 继承平坦度量。

> 注：$M$ 是一个平坦 3-流形，属于 $\mathbb{R}^3$ 的 Bieberbach 流形分类中的一种。其基本群 $\pi_1(M)$ 是 $\mathbb{Z}^3$ 被 $\mathbb{Z}_2$ 的半直积扩张。
