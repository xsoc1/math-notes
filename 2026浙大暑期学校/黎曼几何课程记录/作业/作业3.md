## 1. 亏格 3 闭曲面上双曲度量的空间维数

**解**：对于亏格 $g \ge 2$ 的紧致无边可定向曲面 $\Sigma_g$，由 Fenchel-Nielsen 定理，其双曲度量（或复结构）的泰希米勒空间 $\mathcal{T}_g$ 与模空间 $\mathcal{M}_g$ 的实维数公式为：

$$\dim_\mathbb{R} \mathcal{T}_g = 6g - 6.$$

将亏格 $g = 3$ 代入上式：

$$\dim_\mathbb{R} \mathcal{T}_3 = 6 \times 3 - 6 = 12.$$

**答**：亏格 3 闭曲面上双曲度量的泰希米勒空间（模空间）实维数为 **12 维**（对应复维数为 $3g - 3 = 6$ 维）。

> **几何参数拆解注记**：亏格 $g = 3$ 的闭曲面可沿着 $3g - 3 = 6$ 条两两不相交的简单闭测地线剪开，分解为 $2g - 2 = 4$ 条双曲裤子对。每条切割闭测地线提供 $1$ 个双曲长度参数 $l_i \in (0, \infty)$ 和 $1$ 个粘合扭转参数 $\tau_i \in \mathbb{R}$，合计给出 $6 \text{ 个长度参数} + 6 \text{ 个扭转参数} = 12$ 维实参数空间。

## 2. 欧氏平面中等角六边形：三条不相邻边不足以唯一确定六边形

**问题与背景对比**：在双曲平面 $\mathbb{H}^2$ 中，一个所有内角均为 $90^\circ$ 的双曲直角六边形完全由其三条不相邻的交替边长唯一确定（这是双曲裤子刚性的基础）。本练习证明：在平坦的欧氏平面 $\mathbb{R}^2$ 中，这一刚性结论**不再成立**！

**设定**：考虑欧氏平面 $\mathbb{R}^2 \cong \mathbb{C}$ 中的一个凸**等角六边形**（Equiangular Hexagon），其六个内角均相等且等于正六边形内角 $\frac{(6-2)\times 180^\circ}{6} = 120^\circ$（即外角转向角均为 $60^\circ = \frac{\pi}{3}$）。

**证明三条交替边长不足以唯一确定欧氏等角六边形**：

1. **建立边向量的复数/向量闭路方程**：设六边形的六个顶点按逆时针顺序依次为 $v_1, v_2, \ldots, v_6 \in \mathbb{C}$，对应的六条有向边向量为
   $$e_1 = v_2 - v_1, \quad e_2 = v_3 - v_2, \quad \ldots, \quad e_6 = v_1 - v_6,$$
   其边长分别为 $l_k = |e_k| > 0$（$k = 1, \dots, 6$）。由于六边形闭合且每个顶点处的外转角均为 $+60^\circ$，若令**本原六次单位根** $\zeta = e^{i\pi/3} = \frac{1}{2} + i\frac{\sqrt{3}}{2}$（满足 $1 - \zeta + \zeta^2 = 0$ 及 $\zeta^3 = -1$），则第 $k$ 条边的单位方向向量恰为 $u_k = \zeta^{k-1} u_1$（不妨通过整体旋转设 $u_1 = 1$）。特别是，三组对边满足方向平行且反向（$u_4 = -u_1, \, u_5 = -u_2, \, u_6 = -u_3$）。
2. **闭路条件与剩余自由度分析**：六边形首尾闭合的充要条件是六个有向边向量之和为零：
   $$\sum_{k=1}^6 e_k = (l_1 - l_4) + (l_2 - l_5)\zeta + (l_3 - l_6)\zeta^2 = 0.$$
   在复平面上，由于 $\zeta = \frac{1}{2} + i\frac{\sqrt{3}}{2}$ 的虚部非零，将上式按实部与虚部分开（或注意到 $\zeta^2 = \zeta - 1$），得到关于六个边长的两个线性方程：
   $$(l_1 - l_4) - (l_3 - l_6) = 0, \qquad (l_2 - l_5) + (l_3 - l_6) = 0,$$
   即六条边长满足且仅满足如下两条边长差相等关系：
   $$l_1 - l_4 = l_3 - l_6 = l_5 - l_2.$$
3. **构造同交替边长的无穷连续族**：现在固定三条不相邻（交替）边的长度 $l_1 = |e_1| > 0, \; l_3 = |e_3| > 0, \; l_5 = |e_5| > 0$。根据上式 $l_1 - l_4 = l_3 - l_6 = l_5 - l_2$，只需引入一个自由实参数 $\delta \in \mathbb{R}$，令公差
   $$l_1 - l_4 = l_3 - l_6 = l_5 - l_2 = \delta,$$
   即可唯一解出其余三条交替边的长度：
   $$l_2 = l_5 - \delta, \qquad l_4 = l_1 - \delta, \qquad l_6 = l_3 - \delta.$$
   （复核闭路方程：$(l_1 - l_4) + (l_2 - l_5)\zeta + (l_3 - l_6)\zeta^2 = \delta - \delta\zeta + \delta\zeta^2 = \delta(1 - \zeta + \zeta^2) = 0$，严格闭合！）
   只要实参数 $\delta$ 满足统一正性条件
   $$\delta < \min(l_1, \, l_3, \, l_5)$$
   （例如取围绕 $0$ 的非空开区间 $(-\varepsilon, \varepsilon)$，其中 $0 < \varepsilon < \min(l_1, l_3, l_5)$），所得的六条边长 $l_1, l_2(\delta), l_3, l_4(\delta), l_5, l_6(\delta)$ 就全部严格为正，且依次沿六个递增 $60^\circ$ 的单位方向向量 $1, \zeta, \zeta^2, -1, -\zeta, -\zeta^2$ 首尾相接构成一个非退化的凸等角六边形 $H(\delta)$。
4. **互不全等性验证**：任何欧氏刚体运动（等距同构）都保持六边形的六条边长构成的多重集 $\{l_1, l_2(\delta), l_3, l_4(\delta), l_5, l_6(\delta)\}$（以及六边形的周长 $P(\delta) = (l_1+l_3+l_5) + (l_1+l_3+l_5 - 3\delta) = 2(l_1+l_3+l_5) - 3\delta$）不变。由于周长 $P(\delta)$ 是关于参数 $\delta$ 的严格单调递减线性函数，对不同的参数值 $\delta_1 \neq \delta_2$，对应的等角六边形 $H(\delta_1)$ 与 $H(\delta_2)$ 周长不同（边长多重集亦不同），故必定**互不全等**！

因此，即使完全固定三条不相邻边的长度 $l_1, l_3, l_5$，在欧氏平面上仍然存在着含有一个自由连续实参数 $\delta < \min(l_1, l_3, l_5)$ 的**无穷多种互不全等**的凸等角六边形。$\square$

## 3. 平坦 3-流形 $M$ 的构造及其双重复叠

**设定**：
- 设 $T^2 = \mathbb{R}^2 / \mathbb{Z}^2$ 为配备标准欧氏平坦度量的二维平坦环面；
- 设 $A: T^2 \to T^2$ 为环面上的二阶保定向等距对合（中心反演映射 / 旋转 $180^\circ$）：
  $$A(x, y) = (-x, -y) \equiv (1-x, 1-y) \pmod{\mathbb{Z}^2};$$
- 将映射环面（mapping torus）定义为商流形 $M = \bigl(T^2 \times [0, 1]\bigr) / \sim$，其中粘合等价关系为 $(p, 0) \sim (A(p), 1)$。

**构造双重覆盖并证明 $M \cong T^3 / \langle \sigma \rangle$ 为平坦 3-流形**：

1. **构造三维平坦环面 $T^3$ 上的二阶等距对合 $\sigma$**：考虑标准三维平坦环面
   $$T^3 = \mathbb{R}^2 / \mathbb{Z}^2 \times (\mathbb{R} / 2\mathbb{Z}) = T^2 \times S^1,$$
   配备标准欧氏平坦度量 $g_0 = dx^2 + dy^2 + dz^2$，其中局部坐标为 $(x, y) \in \mathbb{R}^2 / \mathbb{Z}^2$，$z \in \mathbb{R} / 2\mathbb{Z}$（即将第三个圆周方向的周期取为 $2$）。在 $T^3$ 上定义光滑映射 $\sigma: T^3 \to T^3$ 为：
   $$\sigma(x, y, z) = \bigl(A(x, y), \, z + 1 \bmod 2\bigr) = (-x, \, -y, \, z + 1 \bmod 2).$$
2. **验证 $\sigma$ 是自由作用的二阶保定向等距变换**：
   - **二阶性（对合性）**：因为 $A^2 = \operatorname{id}_{T^2}$ 且 $(z + 1) + 1 = z + 2 \equiv z \pmod 2$，故在 $T^3$ 上恒有
     $$\sigma^2(x, y, z) = (x, y, z + 2 \bmod 2) = (x, y, z), \quad \text{即 } \sigma^2 = \operatorname{id}_{T^3}.$$
   - **自由性（无不动点）**：假设存在不动点 $p = (x, y, z) \in T^3$ 使得 $\sigma(x, y, z) = (x, y, z)$，则比较第三个坐标分量必有 $z + 1 \equiv z \pmod 2 \implies 1 \equiv 0 \pmod 2$，这显然矛盾！因此 $\sigma$ 在 $T^3$ 上没有任何不动点，二阶循环群 $\langle \sigma \rangle \cong \mathbb{Z}_2$ 在紧致流形 $T^3$ 上的作用是**自由且纯不连续的**。
   - **保定向等距性**：$\sigma$ 在万有覆盖 $\mathbb{R}^3$ 上的切映射矩阵为对角正交矩阵 $\operatorname{diag}(-1, -1, 1) \in \operatorname{SO}(3)$，其行列式为 $(-1)\times(-1)\times 1 = +1$，且严格保持欧氏平坦度量 $(dx)^2 + (dy)^2 + (dz)^2$ 不变。因此 $\sigma$ 是平坦 3-环面 $T^3$ 上的保定向等距同构。
3. **验证商空间等同与双重覆盖结论**：考察商流形 $T^3 / \langle \sigma \rangle$。由于在第三个分量上 $\sigma$ 将区间 $[0, 1]$ 平移至 $[1, 2]$，我们可取切片 $T^2 \times [0, 1]$ 作为 $\langle \sigma \rangle$ 作用的闭基本域；在该基本域边界上，$\sigma$ 诱导出唯一的粘合等价关系：
   $$(x, y, 0) \sim \sigma(x, y, 0) = \bigl(A(x, y), \, 1\bigr),$$
   这与映射环面 $M = (T^2 \times [0, 1]) / \bigl((p,0) \sim (A(p),1)\bigr)$ 的定义完全一致！因此：
   $$M \cong T^3 / \langle \sigma \rangle.$$

**结论**：由于 $\langle \sigma \rangle \cong \mathbb{Z}_2$ 通过自由等距变换作用于标准平坦 3-环面 $T^3$，自然商投影 $\pi: T^3 \to M = T^3 / \langle \sigma \rangle$ 是一个**二叶正则覆盖映射（双重覆盖）**，且 $T^3$ 上的平坦欧氏度量通过局部等距投影 $\pi$ 唯一地下降为商流形 $M$ 上的完备**平坦黎曼度量**（截面曲率恒为 $K \equiv 0$）。

> **几何分类注记**：该流形 $M$（即在 $z$ 方向每走一圈将横截面环面 $T^2$ 旋转 $180^\circ$ 粘合所得的半扭转环面丛）是三维可定向紧致平坦 **Bieberbach 流形**（共 6 种）中最经典的一种非平凡例子；其基本群 $\pi_1(M) \cong \mathbb{Z}^2 \rtimes_A \mathbb{Z}$ 包含指标为 $2$ 的极大阿贝尔正规子群 $\pi_1(T^3) \cong \mathbb{Z}^3$，这恰好印证了一般维数的 **Bieberbach 定理**：任何紧致平坦黎曼流形都可由平坦环面 $T^n$ 作有限正则等距覆盖！$\square$
