# 第一课：MATLAB 软件入门

> 资料来源：《第一课 MATLAB软件入门.pdf》。课程安排、示例编号和软件操作来自课件；数学解释与纠错标为“讲解补充”或“数学核验”。

## 本讲目标

1. 理解 MATLAB 作为矩阵化科学计算环境的定位。
2. 熟悉命令窗口、当前文件夹、编辑器、工作区和历史命令。
3. 掌握变量命名、常用数值、运算符、脚本运行和帮助系统。
4. 区分矩阵运算与逐元素运算。
5. 能处理复数，并用简单图形检查计算结果。

## 1. 课程主线

### 课件内容

MATLAB 是 MATrix LABoratory 的缩写。课件把它定位为面向科学计算、可视化和交互式程序设计的软件，并强调解释式运行、矩阵化表达和丰富工具箱。课程内容包括 MATLAB 功能使用、数学与数值计算、编程和可视化。

### 讲解补充

学习 MATLAB 时要同时训练三个层面：

- **语法层**：知道命令怎样写。
- **数值层**：知道浮点数、维度和算法会怎样影响结果。
- **数学层**：知道输出对应哪个定义、定理或近似。

软件输出是计算证据，不自动构成数学证明。

## 2. 工作界面和基本工作流

### 课件内容

- **命令窗口**：交互执行语句；分号可抑制输出。
- **当前文件夹**：管理脚本、数据和结果文件。
- **M 文件编辑器**：编写 `.m` 脚本，F5 或运行按钮执行。
- **工作区**：查看当前变量及其尺寸、类型和值。
- **历史命令**：复用或整理已经执行的命令。

推荐工作流：在独立项目文件夹保存脚本和结果，用编辑器写可重复运行的代码，再在命令窗口做小规模试验。

## 3. 变量、数值和显示

### 课件内容

- 变量名区分大小写，首字符必须是字母。
- MATLAB 预定义常量包括 `pi`、`i`、`j`、`Inf` 和 `NaN`。
- `format` 改变显示格式，不改变内存中数值本身。
- `realmax`、`realmin` 和 `eps` 用于认识浮点数范围与精度。

### 数学核验

`0.1 + 0.2` 在二进制浮点数中通常不能精确表示为十进制的 `0.3`。比较计算结果时应根据问题尺度使用容差，而不是在所有场景直接使用 `==`。

## 4. 矩阵运算和逐元素运算

| 写法 | 含义 | 维度条件 |
|---|---|---|
| `A*B` | 矩阵乘法 | `size(A,2)==size(B,1)` |
| `A.*B` | 对应元素相乘 | 尺寸兼容 |
| `A^2` | 矩阵幂 | `A` 为方阵 |
| `A.^2` | 每个元素平方 | 无方阵要求 |
| `A\b` | 解线性方程组 `A*x=b` | 尺寸与问题匹配 |
| `A/b` | 矩阵右除 | 不是普通逐元素除法 |

### 讲解补充

矩阵左除 `A\b` 通常比显式写 `inv(A)*b` 更稳定、也更高效。应优先把它理解为“求解线性系统”，而不是形式上的除法。

## 5. 复数

课件用 `real`、`imag`、`abs`、`angle` 和 `conj` 处理复数。复数

$$
z=x+iy=re^{i\theta}
$$

满足 $r=|z|$、$\theta=\arg z$。在代码中，若 `i` 可能被用作循环变量，写 `1i` 更稳妥。

## 6. 搜索路径、脚本和帮助

MATLAB 查找名称时会先考虑工作区变量，再按搜索规则定位函数或文件。课件介绍了 Current Folder、Set Path、`path` 和 `addpath`。课程项目应尽量把依赖保存在仓库内部，减少永久修改全局搜索路径。

帮助命令：

```matlab
help svd
helpwin svd
doc svd
```

遇到陌生函数时，先确认输入、输出、维度规则和边界情形，再复制示例。

## 8. 数学核验：谱半径为什么不是矩阵范数

第一周参考答案用非零幂零矩阵说明谱半径不是矩阵范数，这个反例正确，但原答案把原因写成“不具备非负性”并不准确。谱半径始终非负；失败的是范数的**正定性**：存在 $A\ne0$ 却有 $\rho(A)=0$。

例如

$$
A=\begin{pmatrix}0&1\\0&0\end{pmatrix}
$$

的全部特征值均为零，所以 $\rho(A)=0$，但 $A\ne0$。
