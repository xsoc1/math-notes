# 第一课：MATLAB 软件入门

## 本讲目标

1. 理解 MATLAB 作为矩阵化科学计算环境的定位。
2. 熟悉命令窗口、当前文件夹、编辑器、工作区和历史命令的功能分工。
3. 掌握变量命名规则、预定义常数、基本运算符、脚本运行与帮助系统。
4. 严格区分矩阵运算与逐元素数组运算。
5. 掌握复数运算与基础函数绘图方法。

## 1. 课程主线

MATLAB（MATrix LABoratory）是面向科学计算、数据可视化与算法开发的交互式程序设计环境，以矩阵与多维数组作为最基本的数据单元。

在运用 MATLAB 求解数学问题时，需要同时兼顾三个层次：
- **语法层**：掌握函数与运算符的调用规则、括号语义及输入输出格式。
- **数值层**：理解 IEEE 754 双精度浮点数表示、舍入误差、数组维度匹配与算法计算复杂度。
- **数学层**：明确计算结果背后的严格数学定义、定理假设与适用边界。数值输出与图形展示可作为直观检验与定量参考，但不能替代严格的数学证明。

## 2. 工作界面与基本工作流

- **命令窗口 (Command Window)**：交互式执行单条语句或表达式；行末加分号 `;` 可抑制屏幕回显，不加分号则将结果赋给默认变量 `ans`（或指定变量）并打印。
- **当前文件夹 (Current Folder)**：管理当前工作目录下的脚本（`.m`）、实时脚本（`.mlx`）、函数与数据文件（`.mat`）。
- **编辑器 (Editor)**：编写、调试与分节（`%%`）运行脚本或函数文件。
- **工作区 (Workspace)**：实时查看当前内存中变量的名称、数据类型（Class）、尺寸（Size）与字节占用；配合命令 `whos`、`clear`、`clc` 管理会话状态。
- **历史命令 (Command History)**：检索并复用已执行的命令序列（可通过上下方向键快速回调）。

**推荐工作流**：在独立项目目录中管理源码，使用编辑器编写可复现的 `.m` 脚本，并利用命令窗口完成快速算例验证与帮助文档查询。

## 3. 变量、数值格式与浮点精度

- **变量命名规则**：变量名区分大小写（如 `A` 与 `a` 不同），必须以英文字母开头，后接字母、数字或下划线（长度不超过 `namelengthmax`，即 63 个字符），且不可使用 `if`、`for`、`end` 等保留关键字（可通过 `iskeyword` 查询）。
- **常用预定义常量**：
  - `pi`：圆周率 $\pi \approx 3.141592653589793$
  - `i` 或 `j`：虚数单位 $\sqrt{-1}$（编程中推荐写 `1i` 或 `1j` 以防被循环变量覆盖）
  - `Inf`：浮点无穷大（如 `1/0` 或超出 `realmax` 的溢出结果）
  - `NaN`：非数（Not-a-Number，如不定式 `0/0`、`Inf - Inf`）
- **数值显示格式控制**：`format short`（默认保留 4 位小数）、`format long`（15 位有效数字）、`format rat`（有理分数近似显示）仅控制命令窗口的**屏幕打印格式**，**不改变**内存中 `double` 变量的实际存储精度。
- **机器精度特征量**：`realmax`（$\approx 1.7977 \times 10^{308}$）、`realmin`（$\approx 2.2251 \times 10^{-308}$）与 `eps`（$\approx 2.2204 \times 10^{-16}$）分别给出 IEEE 754 双精度浮点数的最大有限正数、最小正规正数以及 $1.0$ 与下一个可表示浮点数之间的间距（机器相对精度 $\varepsilon_{\text{mach}} = 2^{-52}$）。

```matlab
format long
x = 1/3                 % 显示 15 位小数 0.333333333333333
format rat
x                       % 显示有理近似 1/3，但内存中 x 仍为相同的 double 浮点数
format short
```

### 浮点数比较准则

由于十进制小数（如 $0.1, 0.2, 0.3$）在二进制浮点表示下通常为无限循环小数，存储时存在截断舍入误差，直接执行关系判断 `0.1 + 0.2 == 0.3` 会返回逻辑假 `0`（因为 `(0.1 + 0.2) - 0.3` 约为 `5.5511e-17`，即 `eps/4`）。因此，判断两个浮点数 $a, b$ 是否相等时，严禁直接使用 `==`，而应使用绝对或相对容差判据：

```matlab
tol = 1e-12;
is_equal = abs((0.1 + 0.2) - 0.3) < tol; % 返回逻辑真 1 (true)
```

## 4. 矩阵输入、矩阵运算与逐元素运算

### 4.1 矩阵的基本构造与索引

在方括号 `[ ]` 中，同行元素以空格或逗号 `,` 分隔，不同行以分号 `;`（或换行）分隔：

```matlab
A = [1, 2, 3; 4, 5, 6; 7, 8, 10];
b = [1; 1; 1];          % 3x1 列向量
elem_23 = A(2, 3);      % 提取第 2 行第 3 列元素：6
row_1   = A(1, :);      % 提取第 1 行全部元素：[1, 2, 3]
```

### 4.2 矩阵运算与数组逐元素运算对照

| 写法 | 数学与算法含义 | 维度要求 |
| :--- | :--- | :--- |
| `A * B` | 矩阵乘法 $(AB)_{ik} = \sum_j A_{ij}B_{jk}$ | `size(A, 2) == size(B, 1)`（或其中一方为标量） |
| `A .* B` | 逐元素乘法（Hadamard 积 $(A \circ B)_{ij} = A_{ij}B_{ij}$） | `A` 与 `B` 同尺寸，或满足隐式扩展（Implicit Expansion）兼容 |
| `A ^ 2` | 矩阵乘方 $A \cdot A$ | `A` 必须为方阵 |
| `A .^ 2` | 逐元素求平方 $(A_{ij}^2)$ | 任意尺寸数组 |
| `A \ b` | 矩阵左除（求解线性方程组 $Ax = b$） | `size(A, 1) == size(b, 1)` |
| `B / A` | 矩阵右除（求解 $xA = B$，等价于 `(A' \ B')'`） | `size(A, 2) == size(B, 2)` |
| `A ./ B` | 逐元素右除 $(A_{ij} / B_{ij})$ | 同尺寸或满足隐式扩展兼容 |
| `A .\ B` | 逐元素左除 $(B_{ij} / A_{ij})$ | 同尺寸或满足隐式扩展兼容 |
| `A'` | 共轭转置（Hermitian 转置 $A^* = \overline{A}^{\mathsf{T}}$） | 任意二维矩阵 |
| `A.'` | 非共轭普通转置（$A^{\mathsf{T}}$） | 任意二维矩阵 |

**线性方程组求解建议**：求解非奇异线性方程组 $Ax = b$ 时，应始终优先使用矩阵左除 `x = A \ b`（`mldivide`）。其底层根据矩阵结构自动选用三角回代、对称正定 Cholesky 分解或带列主元的 LU 分解，计算复杂度为 $\frac{2}{3}n^3 + O(n^2)$，无论是计算速度还是数值稳定性均显著优于显式求逆 `inv(A) * b`。

## 5. 复数运算与基础函数绘图

### 5.1 复数运算与极坐标表示
复数 $z = x + \mathrm{i}y = r e^{\mathrm{i}\theta}$（$x, y \in \mathbb{R}, \, r \ge 0$）的常用处理函数：
- `real(z)`：提取实部 $x = \operatorname{Re}(z)$
- `imag(z)`：提取虚部 $y = \operatorname{Im}(z)$
- `abs(z)`：计算模长 $r = |z| = \sqrt{x^2 + y^2}$
- `angle(z)`：计算主辐角 $\theta = \operatorname{Arg}(z) \in (-\pi, \pi]$（底层调用四象限反正切 `atan2(imag(z), real(z))`）
- `conj(z)`：计算共轭复数 $\bar{z} = x - \mathrm{i}y$

为避免循环索引变量 `i` 或 `j` 覆盖虚数单位，建议在代码中统一使用数字前缀字面量 `1i`（如 `z = 3 + 4i`）。对于复矩阵 $Z$，务必区分共轭转置 `Z'`（同时转置并取复共轭）与纯转置 `Z.'`（仅交换行列位置而不取共轭）。

### 5.2 二维曲线绘图初步
利用冒号生成离散采样网格向量，并通过逐元素运算计算函数值后调用 `plot` 绘图：

```matlab
x = linspace(0, 2*pi, 200);
y1 = sin(x);
y2 = cos(x);

figure;
plot(x, y1, 'b-', 'LineWidth', 1.5);
hold on;
plot(x, y2, 'r--', 'LineWidth', 1.5);
hold off;
grid on;
xlabel('x'); ylabel('y');
title('正弦与余弦函数图像');
legend('sin(x)', 'cos(x)', 'Location', 'best');
```

## 6. 搜索路径与帮助系统

MATLAB 解析标识符（变量或函数名）时的查找优先级顺序为：
$$\text{当前工作区变量} \longrightarrow \text{内建函数 (Built-in)} \longrightarrow \text{当前文件夹下的文件} \longrightarrow \text{搜索路径 (Search Path) 中的文件}.$$
因此，切勿将变量或脚本命名为 `sum`、`mean`、`sin`、`max`、`disp` 等内建函数名，否则会导致同名函数被变量屏蔽（若不慎覆盖，可执行 `clear 变量名` 恢复）。此外，`.m` 脚本文件名必须符合合法标识符命名规则（以字母开头，不能以数字如 `01_test.m` 开头，也不能包含空格或连字符 `-`）。

常用帮助与诊断命令：
```matlab
help svd        % 在命令窗口显示函数语法摘要
doc svd         % 打开帮助浏览器查看完整文档与数学说明
lookfor Fourier % 按关键字检索相关函数摘要
which -all sum  % 检查标识符是否存在同名覆盖及具体文件路径
```

## 7. 数学概念辨析：谱半径与矩阵范数

方阵 $A \in \mathbb{C}^{n \times n}$ 的**谱半径（Spectral Radius）**定义为其特征值模的最大值：

$$
\rho(A) = \max_{\lambda \in \sigma(A)} |\lambda|, \qquad \text{\texttt{rho = max(abs(eig(A)))}}.
$$

需要注意：**谱半径 $\rho(A)$ 不是矩阵范数**。线性空间上的范数 $\|\cdot\|$ 必须同时满足三条公理：
1. **正定性（非退化性）**：$\|A\| \ge 0$，且 $\|A\| = 0 \iff A = 0$；
2. **绝对齐次性**：$\|cA\| = |c|\|A\|$（$\forall c \in \mathbb{C}$）；
3. **三角不等式**：$\|A + B\| \le \|A\| + \|B\|$（矩阵相容范数还满足次乘性 $\|AB\| \le \|A\|\|B\|$）。

考察二阶非零幂零矩阵（Jordan 块）：

$$
A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} \neq 0, \qquad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} \neq 0.
$$

- $A$ 的特征多项式为 $\lambda^2 = 0$，特征值全为 $0$，故 $\rho(A) = 0$，但 $A \neq 0$，直接违背了范数的**正定性**公理；
- 同时，$\rho(A) = \rho(B) = 0$，但 $A + B = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ 的特征值为 $\pm 1$，满足 $\rho(A + B) = 1 > \rho(A) + \rho(B) = 0$，且 $AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ 满足 $\rho(AB) = 1 > \rho(A)\rho(B) = 0$，说明对一般非正规矩阵，谱半径既**不满足三角不等式**，也**不满足次乘性**。
- 谱半径与任意算子诱导矩阵范数 $\|\cdot\|$ 之间的正确关系是下界估计 $\rho(A) \le \|A\|$，以及 Gelfand 谱半径极限公式 $\rho(A) = \lim_{k\to\infty} \|A^k\|^{1/k}$。

## 8. 基础练习与自检

运行配套示例脚本 [`lecture01_basics.m`](file:///F:/MATLAB%20course/%E7%A4%BA%E4%BE%8B%E4%BB%A3%E7%A0%81/lecture01_basics.m) 并完成以下自检问题：
1. **`A * B` 与 `A .* B` 的代数定义与维度兼容性有何不同？**
   - 答：`A * B` 是线性代数中的矩阵乘法，要求左矩阵列数等于右矩阵行数；`A .* B` 是对应位置元素相乘（Hadamard 积），要求两数组同维或满足隐式扩展兼容。
2. **为什么在复矩阵运算中必须严格区分 `A'` 与 `A.'`？**
   - 答：`A'` 计算共轭转置 $A^* = \overline{A}^{\mathsf{T}}$（适用于复内积空间与伴随算子），而 `A.'` 计算不取共轭的普通转置 $A^{\mathsf{T}}$；当矩阵含非零虚部时二者结果相差虚部符号。
3. **`format long` 是否改变了浮点数在内存中的实际精度？**
   - 答：不改变。所有 `double` 变量在内存中固定以 64 位 IEEE 754 标准存储（53 位二进制尾数），`format` 仅调整终端显示位数。
