- **实验题 2（含参代数式在 $a = 3.7$ 处的代入求值）**：构造含参数 $a$ 的符号代数式，利用 `subs` 对比精确有理分数 `sym('37/10')` 代入与双精度浮点数 `3.7` 代入的差异，并用 `vpa` 和 `double` 输出数值结果。

- **实验题 4（超越函数的零点与极值点数值求解）**：针对无法用初等代数求根公式求解的超越函数，结合函数图像定位有根区间与极值区间，使用 `fzero` / `vpasolve` 求零点，使用符号求导 `diff` 配合 `vpasolve`（或 `fminbnd`）求局部极小值与极大值点。

- **模块三（自然常数 $e$ 的三种数列逼近）**：比较 $a_n = (1 + 1/n)^n$、$b_n = n / \sqrt[n]{n!}$、$c_n = \sum_{k=0}^n 1/k!$ 的前 300 项与 $e$ 的逼近速率，采用对数 Gamma 函数向量化方法规避大数阶乘溢出。

## 2. 四道核心课堂实验题详解与代码实现

### 2.1 实验题 1：阶乘三角函数 $\sin(5!)$（及大整数 $\sin(n!)$）的符号与浮点对比

**问题描述**：分别使用符号计算与双精度浮点计算求 $\sin(5!)$ 的值，比较两者的精度差异；若将 $5!$ 推广为更大整数阶乘（如 $25!$），分析双精度浮点计算为何完全失效。

**数学与数值分析**：
1. 当 $n = 5$ 时，$5! = 120$ 可被 IEEE 754 双精度浮点数精确表示（因为 $120 < 2^{53}$）。此时双精度 `sin(factorial(5))` 先对 $120\text{ rad}$ 做模 $2\pi$ 约化（Payne-Hanek 算法），再计算正弦值，结果与符号可变精度 `vpa(sin(sym(factorial(5))), 30)` 在前 15–16 位有效数字上完全一致：
   $$
   \sin(120) \approx 0.58061118421231428971\dots
   $$
2. 然而当 $n$ 增大（例如 $n = 25$，$25! \approx 1.5511 \times 10^{25} > 2^{53} \approx 9.0072 \times 10^{15}$）时，`double(factorial(25))` 仅能保留高 53 位二进制有效数字，其末位单位间距（`eps(factorial(25))`）高达 $2.0972 \times 10^9 \gg 2\pi$！这意味着双精度浮点数连 $25!$ 模 $2\pi$ 的相位余数都已彻底丢失，此时 `sin(factorial(25))` 给出的完全是伪随机噪声，唯有符号整数 `vpa(sin(factorial(sym(25))), 30)` 才能通过高精度 $\pi$ 先做精确相位归约再求得真实值。

```matlab
%% 实验题 1：sin(5!) 与大阶乘三角函数的符号 vs 浮点对比
% (1) n = 5 时：5! = 120
val_double_5 = sin(factorial(5));
val_sym_5    = sin(factorial(sym(5)));       % 保持精确符号形式 sin(120)
val_vpa_5    = vpa(val_sym_5, 30);           % 30 位有效数字：0.580611184212314289713114703497
abs_err_5    = vpa(abs(sym(val_double_5, 'f') - val_sym_5), 10);

fprintf('sin(5!) 双精度值: %.16f\n', val_double_5);
fprintf('sin(5!) 30位VPA : %s\n', char(val_vpa_5));
fprintf('sin(5!) 绝对误差: %s\n\n', char(abs_err_5));

% (2) 推广对比：n = 25 时双精度整数溢出 2^53 导致相位完全失真
val_double_25 = sin(factorial(25));
val_vpa_25    = vpa(sin(factorial(sym(25))), 30);
fprintf('sin(25!) 双精度值(失真): %.16f\n', val_double_25);
fprintf('sin(25!) 精确30位VPA  : %s\n', char(val_vpa_25));
```

### 2.2 实验题 2：含参代数式在 $a = 3.7$ 处的代入求值

**问题描述**：设含参数 $a$ 的代数表达式（如 $E(a) = \frac{a^3 - 3a^2 + 2a - 1}{a^2 - a + 2} + \sqrt{a^2 + 1}$），求其在 $a = 3.7$ 处的精确符号值、30 位可变精度近似值与双精度数值。

**实现要点**：
使用 `subs(E, a, val)` 执行符号变量替换。若传入 `sym('3.7')` 或 `sym(37)/sym(10)`，MATLAB 先在有理数域 $\mathbb{Q}$ 上完成精确分式化简，消去公因式后再按需调用 `vpa` 转为任意精度小数，避免了中间步骤的浮点舍入累积。

```matlab
%% 实验题 2：含参代数式在 a = 3.7 处的代入求值
syms a
E = (a^3 - 3*a^2 + 2*a - 1) / (a^2 - a + 2) + sqrt(a^2 + 1);

% 方式 A：以精确有理数 37/10 代入
a_exact = sym('3.7');                % 等价于 sym(37)/sym(10)
E_sub_exact = simplify(subs(E, a, a_exact));
E_vpa_30    = vpa(E_sub_exact, 30);  % 30 位高精度值
E_double    = double(E_sub_exact);   % 转换为双精度浮点数

fprintf('代入 a = 37/10 后的精确符号式: %s\n', char(E_sub_exact));
fprintf('30 位 VPA 数值结果: %s\n', char(E_vpa_30));
fprintf('双精度 double 结果: %.15f\n', E_double);
```

### 2.3 实验题 3：函数 $f(x)$ 在 $x = \pi/3$ 处的求值与绘图

**问题描述**：设函数 $f(x) = e^{-x/2}\sin(2x) + \cos^2(x)$，计算 $f(\pi/3)$ 的精确符号值与双精度值，并在区间 $[0, 2\pi]$ 上绘制 $f(x)$ 的曲线，在图中用红色圆圈标出点 $\bigl(\frac{\pi}{3}, f(\frac{\pi}{3})\bigr)$。

```matlab
%% 实验题 3：函数 f(x) 在 x = pi/3 处的求值与图像绘制
syms x
f(x) = exp(-x/2) * sin(2*x) + cos(x)^2;

% 1. 在 x = pi/3 处精确求值与浮点求值
x0_sym = sym(pi) / 3;
y0_sym = simplify(f(x0_sym));        % 精确值: (sqrt(3)*exp(-pi/6))/2 + 1/4
y0_num = double(y0_sym);

fprintf('f(pi/3) 精确符号值: %s\n', char(y0_sym));
fprintf('f(pi/3) 双精度数值: %.15f\n', y0_num);

% 2. 在 [0, 2*pi] 上绘制函数图像并标记 (pi/3, f(pi/3))
figure;
fplot(f, [0, 2*pi], 'b-', 'LineWidth', 1.5);
hold on;
plot(pi/3, y0_num, 'ro', 'MarkerSize', 8, 'MarkerFaceColor', 'r');
text(pi/3 + 0.1, y0_num, sprintf('(\\pi/3, %.4f)', y0_num), 'FontSize', 10);
hold off;
grid on;
xlabel('x'); ylabel('f(x)');
title('f(x) = e^{-x/2}sin(2x) + cos^2(x) 及其在 x = \pi/3 处的取值');
legend('f(x)', 'x = \pi/3 处取值', 'Location', 'best');
```

### 2.4 实验题 4：超越函数的零点与极值点数值求解

**问题描述**：考察超越函数 $g(x) = e^{-x/3}\cos(2x) - \frac{1}{5}x$ 在区间 $[0, 2\pi]$ 上的性态：
1. 绘制 $g(x)$ 及其一阶导函数 $g'(x)$ 的图像，直观观察零点与驻点分布；
2. 求出 $g(x)$ 在 $[0, 2\pi]$ 内的全部实零点；
3. 求出 $g(x)$ 在 $[0, 2\pi]$ 内的所有局部极值点（驻点）及对应的极值。

**数学与算法原理**：
- 超越方程 $g(x) = 0$ 无初等代数求根公式，可利用 `fzero(g_num, [a, b])` 在变号子区间上求双精度根，或用 `vpasolve(g(x) == 0, x, [a, b])` 求任意精度根。
- 根据可微函数极值的 Fermat 引理，开区间 $(0, 2\pi)$ 内的局部极值点必满足驻点方程 $g'(x) = 0$，且当二阶导数 $g''(x^*) > 0$ 时为严格局部极小值点，当 $g''(x^*) < 0$ 时为严格局部极大值点。

```matlab
%% 实验题 4：超越函数的零点与极值点数值求解
syms x
g(x)  = exp(-x/3) * cos(2*x) - x/5;
dg(x) = diff(g(x), x);
d2g(x)= diff(g(x), x, 2);

g_fn  = matlabFunction(g);
dg_fn = matlabFunction(dg);

% 1. 扫描网格定位变号子区间并求解全部零点
x_grid = linspace(0, 2*pi, 500);
y_grid = g_fn(x_grid);
idx_zero = find(y_grid(1:end-1) .* y_grid(2:end) <= 0);
roots_g = zeros(size(idx_zero));
for k = 1:numel(idx_zero)
    roots_g(k) = fzero(g_fn, [x_grid(idx_zero(k)), x_grid(idx_zero(k)+1)]);
end

% 2. 扫描导函数变号区间求解全部驻点（极值点）
dy_grid = dg_fn(x_grid);
idx_ext = find(dy_grid(1:end-1) .* dy_grid(2:end) <= 0);
ext_x = zeros(size(idx_ext));
ext_y = zeros(size(idx_ext));
ext_type = strings(size(idx_ext));
for k = 1:numel(idx_ext)
    ext_x(k) = fzero(dg_fn, [x_grid(idx_ext(k)), x_grid(idx_ext(k)+1)]);
    ext_y(k) = g_fn(ext_x(k));
    if double(d2g(ext_x(k))) < 0
        ext_type(k) = "局部极大值";
    else
        ext_type(k) = "局部极小值";
    end
end

% 3. 绘图可视化零点与极值点
figure;
plot(x_grid, y_grid, 'b-', 'LineWidth', 1.5); hold on;
yline(0, 'k--');
plot(roots_g, zeros(size(roots_g)), 'ks', 'MarkerSize', 7, 'MarkerFaceColor', 'g');
plot(ext_x, ext_y, 'ro', 'MarkerSize', 7, 'MarkerFaceColor', 'r');
hold off; grid on;
xlabel('x'); ylabel('g(x)');
title('超越函数 g(x) 在 [0, 2\pi] 上的零点与局部极值点');
legend('g(x)', 'y = 0', '零点', '极值点', 'Location', 'best');
```

## 3. 浮点显示格式与存储精度分析（模块一）

MATLAB 默认数值类型为 IEEE 754 双精度浮点数（`double`，64 位，含 1 位符号位、11 位指数位和 52 位显式尾数位，合 53 位二进制有效尾数，约折合 $15 \sim 17$ 位十进制有效数字）。
- `format short` 与 `format long` 仅改变终端打印的小数位数，不改变变量在内存中的二进制值。
- 若直接写出数值字面量 `0.123456789012345678901`，MATLAB 在词法解析阶段即将其截断为 64 位 `double`；要保留全部 21 位十进制精度，必须通过字符串或大整数之比直接构造符号对象：

```matlab
exact_num = sym('0.123456789012345678901');
vpa(exact_num, 25)
```

对比数值平方根与符号平方根的真实舍入误差（以 $\sqrt{2}$ 与 $\sqrt{979797}$ 为例）：
```matlab
x_num = sqrt(2);              % double 浮点近似
x_exact = sqrt(sym(2));       % 精确符号无理数
err_2 = vpa(abs(sym(x_num, 'f') - x_exact), 30);

y_num = sqrt(979797);
y_exact = sqrt(sym(979797));
err_big = vpa(abs(sym(y_num, 'f') - y_exact), 30);
```
其中 `sym(x_num, 'f')` 将双精度浮点数按其内存中实际的二进制分数忠实转换为符号有理数，从而可与 `sqrt(sym(2))` 作精确差值比较。

## 4. 符号级数求和与二重积分推导（模块二）

IEEE 754 特殊浮点值验证：`1/0` 返回 `Inf`，`-1/0` 返回 `-Inf`，不定式 `0/0` 返回 `NaN`。

待求符号级数与二重积分分别为：

$$
S(x)=\sum_{n=1}^{\infty}\frac{n+1}{n!}x^n,\qquad
I=\int_0^1\int_0^1\frac{1}{(1+x^2+y^2)^{3/2}}\,\mathrm{d}x\,\mathrm{d}y.
$$

**解析推导与 MATLAB 实现**：
1. 幂级数可拆分为 $\sum_{n=1}^\infty \frac{x^n}{(n-1)!} + \sum_{n=1}^\infty \frac{x^n}{n!} = x e^x + (e^x - 1) = (x+1)e^x - 1$。
2. 二重积分先对 $x$ 积分：利用原函数 $\int (a^2+x^2)^{-3/2}\,\mathrm{d}x = \frac{x}{a^2\sqrt{a^2+x^2}}$（令 $a^2 = 1+y^2$），得内层积分为 $\int_0^1 (1+y^2+x^2)^{-3/2}\,\mathrm{d}x = \frac{1}{(1+y^2)\sqrt{2+y^2}}$；再作换元 $t = \frac{y}{\sqrt{2+y^2}}$（此时 $\mathrm{d}t = \frac{2}{(2+y^2)^{3/2}}\,\mathrm{d}y$，$1-t^2 = \frac{2}{2+y^2}$，$1+t^2 = \frac{2(1+y^2)}{2+y^2}$），积分化为 $\int_0^{1/\sqrt{3}} \frac{\mathrm{d}t}{1+t^2} = \arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}$。

```matlab
syms x y n
T_atan = taylor(atan(x), x, 0, 'Order', 11); % x - x^3/3 + x^5/5 - x^7/7 + x^9/9
S_x = simplify(symsum((n + 1)/factorial(n) * x^n, n, 1, Inf)); % (x + 1)*exp(x) - 1
I_xy = int(int((1 + x^2 + y^2)^(-3/2), x, 0, 1), y, 0, 1);     % pi/6
```

## 5. 数列逼近实验与防溢出对数化变换（模块三）

考察收敛于自然常数 $e$ 的三个序列（$n = 1, 2, \dots, 300$）：

$$
a_n = \left(1 + \frac{1}{n}\right)^n, \qquad b_n = \frac{n}{\sqrt[n]{n!}}, \qquad c_n = \sum_{k=0}^n \frac{1}{k!}.
$$

**数值溢出分析与规避方法**：
在双精度浮点数下，`realmax` 约为 $1.7977 \times 10^{308}$，而 $171! \approx 1.241 \times 10^{309} > \text{realmax}$，因此当 $n \ge 171$ 时直接计算 `factorial(n)` 会上溢为 `Inf`，导致 $b_n = n / (\text{Inf})^{1/n} = 0$ 彻底失效。利用内建对数 Gamma 函数 `gammaln(n+1)`（满足 $\ln(n!) = \ln\Gamma(n+1) = \sum_{k=1}^n \ln k$）将大数阶乘开方转化为稳定的指数-对数运算：

$$
b_n = \exp\!\left(\ln n - \frac{\operatorname{gammaln}(n+1)}{n}\right).
$$

对于部分和序列 $c_n$，同样使用 `exp(-gammaln(n+1))` 或递推通项配合 `cumsum` 进行向量化累加：

```matlab
n = 1:300;
a = (1 + 1./n).^n;
b = exp(log(n) - gammaln(n + 1)./n);
c = 1 + cumsum(exp(-gammaln(n + 1)));

figure;
semilogy(n, abs(a - exp(1)), 'r-', ...
         n, abs(b - exp(1)), 'b--', ...
         n, abs(c - exp(1)) + eps, 'k-.', 'LineWidth', 1.2);
grid on;
xlabel('n'); ylabel('|x_n - e|');
title('三种数列逼近自然常数 e 的绝对误差对数曲线');
legend('a_n = (1+1/n)^n', 'b_n = n/(n!)^{1/n}', 'c_n = \Sigma 1/k!');
```

**收敛阶对比**：由渐近展开与 Stirling 公式 $n! = \sqrt{2\pi n}\left(\frac{n}{e}\right)^n e^{O(1/n)}$ 可知：
- $a_n = e\exp\bigl(n\ln(1+1/n)-1\bigr) = e - \frac{e}{2n} + O(n^{-2})$，收敛阶为 **$O(1/n)$**；
- $b_n = e\exp\bigl(-\frac{\ln(2\pi n)}{2n} + O(n^{-2})\bigr) = e - \frac{e\ln(2\pi n)}{2n} + O\bigl(\frac{\ln^2 n}{n^2}\bigr)$，收敛阶为 **$O\bigl(\frac{\ln n}{n}\bigr)$**（渐近略慢于 $a_n$）；
- Taylor 级数部分和 $c_n - e = -\sum_{k=n+1}^\infty \frac{1}{k!} = -\frac{1}{(n+1)!}\bigl(1 + O(1/n)\bigr)$ 呈**超指数（阶乘级）收敛**，仅需 $n = 18$ 项即达到双精度机器精度极限 $\approx 10^{-16}$。
