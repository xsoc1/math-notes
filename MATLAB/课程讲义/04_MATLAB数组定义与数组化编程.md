## 2. 核心语法与数学原理详解

### 2.1 数组生成与尺寸查询
- `a:h:b` 按固定步长 $h$ 生成行向量（共 $\lfloor\frac{b-a}{h}\rfloor + 1$ 个元素）；`linspace(a, b, n)` 生成 $n$ 个等距节点（步长 $\frac{b-a}{n-1}$）；`logspace(a, b, n)` 生成 $10^a$ 到 $10^b$ 之间的 $n$ 个对数等比节点。
- `ndims(A)` 返回数组维数（至少为 2）；`size(A)` 返回各维长度向量 `[m, n, ...]`；`length(A)` 返回非空数组的最大维长度 $\max(\text{size}(A))$（空数组返回 `0`）；`numel(A)` 返回元素总数 $\prod_i \text{size}(A, i)$。

### 2.2 列主序内存布局、越界自动扩容与循环内存预分配
1. **列主序（Column-major order）**：MATLAB 按“先列后行”的顺序在连续内存中存储数组元素。对于 $m \times n$ 矩阵 $A$，第 $(i, j)$ 个元素对应的线性下标（单下标）为：

$$
k = i + m(j - 1), \quad 1 \le i \le m, \; 1 \le j \le n.
$$

   `reshape(A, m, n)` 保持线性下标顺序不变，仅重新划分维度视图（要求元素总数 $m \cdot n = \operatorname{numel}(A)$）。例如 `A = reshape(1:12, 3, 4)` 中，`A(2, 3)` 与线性索引 `A(8)` 指向同一元素 `8`。二维下标与线性下标可通过 `sub2ind` 和 `ind2sub` 相互转换。

2. **越界赋值自动扩容与循环内动态扩容的性能陷阱**：
   - 在交互式单次操作中，若对超出当前矩阵边界的位置赋值（例如对 $1 \times 2$ 向量 `A = [10, 20]` 执行 `A(2, 3) = 5`），MATLAB 会自动将矩阵扩展至 $2 \times 3$，并将未赋值的空缺位置填补为 `0`（而越界**读取**则会直接报错 `Index exceeds array bounds`）。
   - **重要性能原则**：虽然 `A(2, 3) = 5` 这样的单次隐式扩容在语法上合法，但**严禁在 `for` / `while` 循环内部通过越界赋值或 `[A, new_elem]` 反复隐式动态扩容**！因为 MATLAB 数组要求连续物理内存，在循环中每次扩大数组尺寸都会触发**重新申请更大连续内存块并将全部旧元素逐一拷贝至新内存**的操作，使 $N$ 步循环的总时间复杂度从 $O(N)$ 退化为 $O(N^2)$。在已知或可预估数组规模时，必须先使用 `zeros(m, n)`（或 `NaN`、`true`）一次性完成**内存预分配（Preallocation）**，再按索引填入结果。

### 2.3 数组化编程（向量化）的适用范围与串行依赖边界

向量化（Vectorization）是利用数组整体运算、隐式扩展与逻辑索引替代显式 `for` 循环的编程范式，但必须明确其**适用前提与算法边界**：
- **可直接向量化的情形（数据并行 / 独立分量计算）**：当每个输出分量 $y_i$（或网格点 $F_{ij}$）的计算彼此独立、不依赖其他分量的后继状态，或者可归结为线性代数内积、前缀累积和（`cumsum`）、前缀累积积（`cumprod`）与固定步差分（`diff`）时，均可直接用逐元素运算与隐式扩展一步完成。
- **不能简单套用逐元素向量化的情形（状态依赖串行递推与动态终止循环）**：
  1. **非线性串行状态递推**：当第 $k$ 步状态 $x_k = g(x_{k-1}, x_{k-2})$ 非线性地依赖于前一步刚算出的输出状态时，各步之间存在严格的因果数据依赖（Data Dependency），不能改写为对整个数组的同步逐元素运算；
  2. **动态终止条件循环**：当迭代总步数未知、取决于运行期状态何时首次满足终止判据（如课堂练习题 7 的角谷猜想 $3n+1$ 循环 `while n ~= 1` 或自适应求根迭代）时，必须保留 `while` 循环结构。

### 2.4 逻辑掩码与分段函数计算

**原课例（原始课件第 30–31 页，例 3.3-3）**：计算三段式分段函数

$$
y(x) = \begin{cases}
x, & x < 0, \\
x^3 \cos(2\pi x), & 0 \le x < 1, \\
e^{-x+1}, & x \ge 1.
\end{cases}
$$

对输入数组 `x`，不可直接使用标量 `if x < 0`（因为数组放进 `if` 会要求全部元素同时满足条件），而应构造互斥的逻辑掩码（Logical Masks）或采用算术指示函数相加：

```matlab
x = linspace(-1, 2, 601);

% 方法一：预分配 + 逻辑掩码分段赋值（推荐，仅对落入各分支的元素求值）
y = zeros(size(x));
mask1 = (x < 0);
mask2 = (x >= 0) & (x < 1);
mask3 = (x >= 1);

y(mask1) = x(mask1);
y(mask2) = x(mask2).^3 .* cos(2 * pi * x(mask2));
y(mask3) = exp(-x(mask3) + 1);

% 方法二：逻辑数组转 0-1 权重乘法合并
y_alt = x .* (x < 0) + (x.^3 .* cos(2*pi*x)) .* (x >= 0 & x < 1) + exp(-x + 1) .* (x >= 1);
```

**补充例（限幅截断函数）**：对三段限幅函数 $g(x) = \operatorname{clip}(x, -1, 1)$（当 $x \le -1$ 时取 $-1$，$-1 < x \le 1$ 时取 $x$，$x > 1$ 时取 $1$），既可用逻辑掩码分段赋值，也可简化为 `g = min(max(x, -1), 1)`。

### 2.5 软阈值算子与可去奇点处理
1. **软阈值算子（Soft-thresholding Operator，课件第 32 页）**：在 $\ell_1$ 稀疏优化与小波去噪中，软阈值函数定义为：

$$
S_\lambda(a) = \begin{cases} a - \lambda, & a > \lambda, \\ 0, & |a| \le \lambda, \\ a + \lambda, & a < -\lambda. \end{cases}
$$

该分段定义在 $|a| = \lambda$ 处连续且左右分支取值均为 $0$，在 MATLAB 中可浓缩为单行数组化表达式：
```matlab
S = sign(A) .* max(abs(A) - lambda, 0);
```

2. **Sinc 函数的零点奇异性处理**：计算 $f(t) = \frac{\sin t}{t}$ 时，原点 $t = 0$ 为可去奇点（$\lim_{t\to 0}\frac{\sin t}{t} = 1$）。若直接计算 `sin(0)/0` 会产生 `NaN`。工程上应优先利用逻辑掩码将 `t == 0` 处的函数值显式置为 `1`（或调用内建 `sinc(t/pi)`）。若采用 `t + realmin` 平移零点的近似做法，在二维乘积 $\frac{\sin X}{X}\cdot\frac{\sin Y}{Y}$ 中需注意分别计算两个一维商再相乘 `(sin(X)./X) .* (sin(Y)./Y)`，避免在 `X .* Y` 中因 `realmin * realmin` 发生浮点下溢归零。

## 3. 课堂练习与综合编程题全解（题 1–题 9）

本节完整收录原课件中的全部 9 道课堂练习与综合题及其标准向量化实现。

### 练习 1：等距/对数向量生成与子数组切片
生成行向量 $v = [1, 3, 5, \dots, 99]$，提取其前 10 个元素、倒数 10 个元素，并将其偶序数位置的元素全部置为 $0$：
```matlab
v = 1:2:99;
first_10 = v(1:10);
last_10  = v(end-9:end);
v(2:2:end) = 0;
```

### 练习 2：对角矩阵与分块矩阵构造
利用 `eye`、`ones`、`zeros` 与 `diag` 构造主对角线为 $2$、次上/次下对角线为 $-1$ 的 $5 \times 5$ 三对角矩阵 $T$：
```matlab
T = 2 * eye(5) - diag(ones(4, 1), 1) - diag(ones(4, 1), -1);
```

### 练习 3：`reshape` 列主序重排与转置构造
用 `1:20` 构造 $4 \times 5$ 矩阵，使元素按**行优先**依次递增排列（即第 1 行为 `1:5`，第 2 行为 `6:10`）：
```matlab
% reshape 默认按列填充，故先重排为 5x4 再转置
M_row_major = reshape(1:20, 5, 4).';
```

### 练习 4：二维下标、线性索引与矩阵外围边框提取
给定 $6 \times 6$ 矩阵 `A = magic(6)`，提取其最外圈边界元素并将内部 $4 \times 4$ 子块置零：
```matlab
A = magic(6);
A_border = A;
A_border(2:end-1, 2:end-1) = 0; % 内部子块切片直接赋 0
```

### 练习 5：逻辑索引与异常值清洗
将随机矩阵 `R = randn(5, 5)` 中所有绝对值小于 $0.5$ 的元素置为 $0$，并统计大于 $1$ 的元素个数与均值：
```matlab
rng(42);
R = randn(5, 5);
R(abs(R) < 0.5) = 0;
gt1_vals = R(R > 1);
cnt_gt1  = numel(gt1_vals);
mean_gt1 = mean(gt1_vals);
```

### 练习 6：初等行变换的切片向量化实现（课件第 34–35 页）
对增广矩阵 $A$ 执行三种初等行变换（交换第 $i, j$ 两行；将第 $i$ 行乘以非零常数 $c$；将第 $i$ 行的 $k$ 倍加到第 $j$ 行上）：
```matlab
A([i, j], :) = A([j, i], :);         % 1. 交换第 i 行与第 j 行
A(i, :)      = c * A(i, :);          % 2. 第 i 行乘以非零常数 c
A(j, :)      = A(j, :) + k * A(i, :);% 3. 第 i 行的 k 倍加到第 j 行
```

### 练习 7：角谷猜想（Collatz $3n+1$ 问题）循环终止分析
**问题**：对任意正整数 $n_0$，若当前项 $n$ 为偶数则令 $n \leftarrow n/2$，若为奇数则令 $n \leftarrow 3n+1$，重复迭代直至 $n = 1$。记录轨迹序列与总步数。
**算法分析**：该问题属于典型的**状态依赖且终止步数未知的串行递推**，必须使用 `while n > 1` 循环，不可强行套用固定长度逐元素向量化：
```matlab
n = 27;
seq = n;
steps = 0;
while n > 1
    if mod(n, 2) == 0
        n = n / 2;
    else
        n = 3 * n + 1;
    end
    seq(end + 1) = n; %#ok<SAGROW> % 未知终止步数下的轨迹追加
    steps = steps + 1;
end
fprintf('初值 27 到达 1 共需 %d 步，序列峰值 = %d\n', steps, max(seq));
```

### 练习 8：分段数组的逻辑掩码向量化计算
对二维网格或一维采样点上的多分支分段函数，使用逻辑掩码一次性完成全部采样点求值（完整实现见上文 §2.4 原课例例 3.3-3）。

### 练习 9：Taylor 级数部分和的向量化求和
**问题**：不借助 `for` 循环，利用向量化数组运算计算余弦函数 Taylor 级数部分和 $\cos x \approx \sum_{k=0}^{N} (-1)^k \frac{x^{2k}}{(2k)!}$ 在一组节点 `x` 上的值。
**向量化实现**：利用隐式扩展构造幂次矩阵与 `gammaln`（或 `factorial`）系数向量，通过矩阵-向量乘法一步完成多点级数求和：
```matlab
x = linspace(0, pi, 100).'; % 100x1 列向量
k = 0:10;                   % 1x11 阶数行向量 (最高至 x^20 / 20!)
terms_sign = (-1).^k;       % 1x11 交替符号
% 利用隐式扩展 (x .^ (2*k)) 生成 100x11 矩阵，右乘系数列向量
coeffs = terms_sign ./ factorial(2 * k);
cos_approx = (x .^ (2 * k)) * coeffs.';
max_err_10 = max(abs(cos_approx - cos(x))); % 在 x = pi 处截断余项约为 pi^22/22! ≈ 7.60e-11

% 若将截断阶数提升至 k = 0:13 (最高至 x^26 / 26!)，则全区间最大绝对误差达到双精度极限 < 1e-15
k_full = 0:13;
cos_approx_13 = (x .^ (2 * k_full)) * ((-1).^k_full ./ factorial(2 * k_full)).';
max_err_13 = max(abs(cos_approx_13 - cos(x))); % 最大绝对误差 ≈ 4.44e-16 < 1e-15
```
