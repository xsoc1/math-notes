## 2. 矩阵运算与矩阵函数

### 2.1 左除首先表示求解问题

**课件内容（第 2–6 页）：** `A\b` 用于线性方程组，矩阵运算与逐元素运算应分别理解。

**讲解补充：** 对可逆方阵，数学上 `A\b` 与 $A^{-1}b$ 相等；MATLAB 的实际求解过程不需要先显式计算逆矩阵。优先写 `A\b`，用 `norm(A*x-b)` 检查回代，而不是先写 `inv(A)*b`。矩形矩阵的左除通常是最小二乘问题，不能一概解释成取逆。

**数学核验：** 两条不相容的方程 $x=0$、$x=2$ 没有共同解，但使平方误差 $x^2+(x-2)^2$ 最小的解是 $x=1$，残差范数为 $\sqrt2$。因此，课件“无解方程可能返回 NaN”的说法不能作为一般判据。残差非零不等于程序失败；必须先明确求的是精确解还是最小二乘解。矩形左除也不保证返回所有最小二乘解中的最小范数解，见 [MathWorks 左除文档](https://www.mathworks.com/help/matlab/ref/double.mldivide.html)。

### 2.2 `expm(A)` 与 `exp(A)` 的定义不同

**课件内容（第 3 页）：** `expm`、`logm`、`sqrtm`、`funm` 是矩阵函数；课件用对角化说明其意义。

**讲解补充：** `exp(A)` 把每个元素单独取指数；`expm(A)` 计算矩阵指数，其幂级数使用矩阵乘法：

$$
e^A=I+A+\frac{A^2}{2!}+\cdots.
$$

对角化 $A=PDP^{-1}$ 是可用时的解释工具，不是矩阵指数存在的前提。取 $N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，它不可对角化，但 $N^2=0$，所以 $e^N=I+N$。

```matlab
% 矩阵指数使用矩阵幂; 逐元素指数分别处理每个元素.
N = [0 1; 0 0];
MatrixExp = expm(N)
ElementExp = exp(N)
```

前者应为 `[1 1; 0 1]`；后者应为 `[1 exp(1); 1 1]`。`expm` 名称中的 `m` 表明这里是矩阵函数。两者结果尺寸相同，仍可能代表完全不同的计算。

`sqrtm(A)` 的核验应使用 `Root*Root` 与 `A` 比较，不能用 `Root.^2`。浮点核验采用误差容限，不要求逐位相等。`logm`、非整数矩阵幂和一般 `funm` 还涉及函数定义域、分支和矩阵条件；本课先理解命令用途，不把标量函数性质直接照搬到所有矩阵。

**数学核验（第 2 页术语）：** 多元素数组在逐元素加、乘下不是“域”。例如 `[1 0].*[0 1]=[0 0]`，两个非零数组的乘积为零，存在零因子；复数元素数组可理解为复数域的有限直积环。这个术语修正不增加教学关卡。

## 3. 有标签的输出与条件分支

### 3.1 `fprintf` 把格式和数据分开

**课件内容（第 9–10 页）：** `fprintf(格式字符串, 数据...)` 支持 `%d`、`%f`、`%e`、`%s`、`\n` 等格式。

**讲解补充：** `fprintf('PositiveTotal = %g\n', Total)` 中，第一项决定输出结构，`%g` 是数值占位符，第二项提供该数值，`\n` 在最后换行。格式占位符应与参数的含义和顺序匹配；输出标签能避免一串无说明的 `ans`。

`%6.4e` 的 `6` 是最小字段宽度，内容较长时不会截断；`.4` 表示小数点后四位，科学记数法因而有五位有效数字。格式只控制显示，不增加计算精度。

### 3.2 `if` 处理条件，`switch` 处理匹配

**课件内容（第 11、20、22 页）：** `if/elseif/else/end` 依次选择第一个成立的分支；`switch/case/otherwise/end` 根据值匹配分支。

**讲解补充：** 条件的含义要明确。判断“所有元素都满足”或“至少一个元素满足”时，应显式使用 `all` 或 `any`；不要把整个逻辑数组误当成一个元素。需要短路且两边均为标量条件时，使用 `&&`、`||`；数组条件使用 `&`、`|`。MATLAB 的 `switch` 匹配后执行该分支，不需要用 C/C++ 风格的 `break` 防止继续落入下一分支。

## 4. 循环、预分配和控制流程

**课件内容（第 24–32 页）：** `for` 适合明确的遍历，`while` 根据条件反复执行；`break` 跳出最内层循环，`continue` 跳过本轮后续语句；`return` 结束当前函数或脚本。

**讲解补充：** `for Index = 1:numel(Values)` 的右侧是行向量，每轮给 `Index` 一个值。一般情况下，`for` 遍历右侧数组的各列。`while` 则需要确保循环体改变相关状态，并设置可解释的停止条件；搜索程序通常还应有迭代上限。

### 4.1 一段小函数把循环和条件连接起来

下面是[程序设计示例](file:///F:/MATLAB%20course/%E7%A4%BA%E4%BE%8B%E4%BB%A3%E7%A0%81/lecture05_programming.m)中的局部函数，不是本次作业的答案。

```matlab
function Total = sum_positive(Values)
% SUM_POSITIVE Sum only the positive elements of a numeric vector.
	Total = 0;
	for Index = 1:numel(Values)
		if Values(Index) <= 0
			continue;
		end
		Total = Total+Values(Index);
	end
end
```

`Values` 是输入，`Total` 是输出；`Index` 只负责取当前位置。非正数使程序直接进入下一轮，正数才累加。完整脚本用 `[-2 0 3 4]` 调用函数，输出应为 `7`。学习时需要解释条件怎样影响累加过程，再由本人修改和运行。

### 4.2 预分配与数组化要保留核验

**课件内容（第 25–26 页）：** 比较逐步扩大数组、`zeros` 预分配和数组化生成 Hilbert 矩阵；元素满足 $H_{ij}=1/(i+j-1)$。

**讲解补充：** 先创建 `H=zeros(Count,Count)`，再填写元素，可避免循环中反复扩大数组。数组化形式 `1./(Indices.'+Indices-1)` 利用列向量与行向量的隐式扩展生成全部分母；`./` 对每个分母分别求倒数。两种写法应先比较结果，再讨论时间和内存。

课件给出的耗时是其示例环境的输出，不是本机测量，也不保证所有规模下保持同样排名。循环层数少不直接等于复杂度低或耗时短；`tic/toc` 测量应说明输入规模和运行环境。课件矩阵乘法比较中的逐元素相对误差，若分母为零会出问题；可补充用 `norm(Computed-Reference,'fro')` 或有明确尺度的整体相对误差核查。

`format rat` 仅改变数值显示，不会把 `double` 转为精确有理数；这点沿用先前 `format` 的学习证据，不另做重复练习。双偶数阶幻方（第 27–29 页）用于综合索引与循环，可在章节节点按需复现，不作为每个命令的独立关卡。

## 5. cell、函数工作区与调试

### 5.1 cell 的括号决定取得什么

**课件内容（第 21–23 页）：** cell 可以在不同格子存放不同类型的数据。

**讲解补充：** 对 `Data={7,'ready'}`，`Data(1)` 返回一个 cell 容器，`Data{1}` 取出其中的数值 `7`。因此 `class(Data(1))` 为 `cell`，`class(Data{1})` 为 `double`。向单格写入内容可用 `Data{1}=新内容`；用圆括号给 cell 子数组赋值时，右侧也应提供 cell。`inputdlg` 返回的文字也在 cell 中，需先取内容，再按输入类型转换。

### 5.2 用输入输出表达数据流

**课件内容（第 34–39 页）：** 脚本与函数、局部变量、`global`、函数帮助注释和 `%%` 分节。

**讲解补充：** 常规独立函数有自己的工作区；需要调用者数据时，将它作为输入传入，需要把结果交出去时写成输出。脚本通常使用运行它的工作区，脚本末尾的局部函数仍有自己的函数工作区。嵌套函数和 `persistent` 等另有规则，不把“所有局部变量都会消失”当作无条件结论。

课件第 36 页将输入参数理解为必须立即复制整个数组；实际 MATLAB 采用写时复制等机制，不能据此推断每次函数调用都产生完整数据副本，见 [MathWorks 内存复制说明](https://www.mathworks.com/help/matlab/matlab_prog/avoid-unnecessary-copies-of-data.html)。教学重点仍是函数内修改普通数值输入通常不会直接改变调用者变量，而不是依赖未经测量的内存假设。

`global` 要在相关工作区分别声明，但会隐藏依赖；本课优先用参数和返回值。首段帮助注释说明用途、输入与输出，`%%` 把脚本组织成可以分节运行的段落。

### 5.3 看见变量，再定位错误

**课件内容（第 30–33 页）：** Ctrl+C 中断运行；`pause` 暂停；`keyboard` 进入调试环境，`dbcont` 继续。还展示 `input`、`inputdlg`、`listdlg`、`questdlg`。

**讲解补充：** 调试先看变量值、尺寸和类型，再判断哪条语句偏离预期。简单数字文本可用 `str2double` 转换并检查是否为 `NaN`；`input(...,'s')` 读入文本，避免把本来希望读取的文字解释为 MATLAB 表达式。交互界面属于可选工具；自动复运行的示例尽量避免等待对话框。

## 6. 搜索示例的结果边界

**课件内容（第 12–19 页）：** `fminbnd`、逐步细分搜索区间、模拟退火及搜索路径可视化。

**讲解补充：** `fminbnd` 针对区间内的局部极小值，不能直接把一次返回值宣称为全局最小值；端点通常也需要另行比较，见 [MathWorks fminbnd 文档](https://www.mathworks.com/help/matlab/ref/fminbnd.html)。多区间搜索和“连续若干次结果不变”的停止规则可以产生候选解，但不自动成为覆盖全部区间的证明。

模拟退火允许以随温度和目标差值变化的概率接受较差候选点，以减少过早停在局部位置的风险。一次有限随机运行的最好结果只是该次算法结果，不保证全局最优。课件的具体最小值、区间细分次数与运行路径均视为原材料展示，未在本轮复现；本轮仅运行下面两份短示范。
