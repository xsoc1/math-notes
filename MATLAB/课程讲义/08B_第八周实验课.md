## 一、 原课件核心实验题解析（第 1–2 页）

### 实验题 1：高阶 Newton-Cotes 求积公式（Boole 公式）与复合实现

在闭区间 $[a, b]$ 上取 $n$ 等分节点 $x_k = a + kh \, (h = \frac{b-a}{n}, \, k = 0, 1, \dots, n)$，通过 Lagrange 插值多项式积分导出的闭型 Newton-Cotes 求积公式为：

$$
\int_a^b f(x)\,dx \approx (b - a)\sum_{k=0}^n C_k^{(n)} f(x_k),
$$

其中求积系数（Cotes 系数）为 $C_k^{(n)} = \frac{(-1)^{n-k}}{n \cdot k!(n-k)!} \int_0^n \prod_{j \neq k} (t - j)\,dt$。
- 当 $n = 1$ 时为梯形公式，权重比 $[1, 1]$，步长因子 $\frac{h}{2}$，代数精度为 $1$；
- 当 $n = 2$ 时为 Simpson 公式，权重比 $[1, 4, 1]$，步长因子 $\frac{h}{3}$，代数精度为 $3$；
- 当 $n = 4$ 时为**四阶 Newton-Cotes 公式（Boole 公式）**，单区间形式与余项为：

$$
\int_{x_0}^{x_4} f(x)\,dx = \frac{2h}{45}\bigl[7f(x_0) + 32f(x_1) + 12f(x_2) + 32f(x_3) + 7f(x_4)\bigr] - \frac{8h^7}{945}f^{(6)}(\xi),
$$

其代数精度达到 $5$ 阶，全局复合误差阶为 $O(h^6)$。将区间 $[a, b]$ 划分为 $N = 4m$ 个子区间（步长 $h = \frac{b-a}{4m}$，共 $4m+1$ 个节点），复合 Boole 公式的内部周期衔接点 $x_{4j} \, (j=1,\dots,m-1)$ 由相邻两段各自的端点权重 $7 + 7 = 14$ 叠加而成，整体权重向量为：

$$
w_{\text{Boole}} = \frac{2h}{45}\bigl[7, \, 32, \, 12, \, 32, \, 14, \, 32, \, 12, \, 32, \, 14, \, \dots, \, 32, \, 12, \, 32, \, 7\bigr].
$$

> [!warning] **高阶闭型 Newton-Cotes 公式的负权重与数值不稳定性（$n = 8$ 及 $n \ge 10$）**
> 在等距闭型 Newton-Cotes 公式中，当 $1 \le n \le 7$ 以及 **$n = 9$** 时，全部求积权重 $C_k^{(n)} > 0$ 均为正数；但从 **$n = 8$ 开始（具体为 $n = 8$ 及一切 $n \ge 10$）**，权重系数 $C_k^{(n)}$ 中出现**正负交替的大系数**，且当 $n \to \infty$ 时条件数 $\sum_{k=0}^n |C_k^{(n)}| \to \infty$（由 Pólya--Steklov 定理知对一般连续函数不再保证收敛），不仅引发剧烈的 Runge 振荡，还会严重放大浮点舍入误差。因此工程上从不采用单一超高阶等距 Newton-Cotes 公式，而是通过**加密子区间数 $m$ 的低阶复合求积（复合梯形、复合 Simpson 或复合 Boole）**或非等距 Gauss 求积来获得高精度。

```matlab
% 原课件实验题 1：在 [0, 1] 上利用高阶 Newton-Cotes (Boole) 公式积分 1/(1+x^2) 并乘以 4 近似圆周率 pi
a = 0; b = 1;
m = 10;                  % 4m 个子区间
N = 4 * m;
h = (b - a) / N;
x = linspace(a, b, N + 1);
f_q1 = @(x) 1 ./ (1 + x.^2);

w = zeros(1, N + 1);
w(1) = 7; w(end) = 7;
w(2:4:N) = 32;
w(3:4:N-1) = 12;
w(4:4:N) = 32;
w(5:4:N-3) = 14;         % 相邻子段交界节点权重 7 + 7 = 14
w = (2 * h / 45) * w;

% 原题 Q1：计算 4 * \int_0^1 1/(1+x^2) dx 逼近 pi，并与真值 pi 比较误差
pi_boole = 4 * sum(w .* f_q1(x));
fprintf('原题 Q1: 复合 Boole 估计 pi = %.15f, 相对 pi 绝对误差 = %.2e\n', pi_boole, abs(pi_boole - pi));
```

### 实验题 2：随机乱序采样点的联合排序与数值求积（含原题 `[0, 1]` 上 $x^2+x$ 与 `prob_data401.mat`）

若实验采集到的离散观测点 $(X_i, Y_i) \, (i = 1, \dots, K)$ 的横坐标 $X_i \in [a, b]$ 是无序随机分布的（如原课件第 2 题在 $[0, 1]$ 上随机抽取 $X_i \sim U(0, 1)$ 计算 $Y_i = X_i^2 + X_i$，求积真值为 $\int_0^1 (x^2 + x)\,dx = \frac{5}{6}$）：
1. **错误做法**：直接对未排序的 $(X, Y)$ 调用 `trapz(X, Y)`，会导致折线在区间内来回往复交叉，积分结果完全错误；而只对 `X` 排序 `sort(X)` 却不重排 `Y`，则会破坏自变量与函数值的一一对应关系。
2. **正确做法（联合排序）**：利用 `[X_sorted, idx] = sort(X)` 获取升序排列的索引向量 `idx`，再用同一索引重排纵坐标 `Y_sorted = Y(idx)`，最后调用非等距复合梯形公式 `trapz(X_sorted, Y_sorted)`（必要时补齐区间左右端点 $a = 0, b = 1$）。

```matlab
rng(2026);
K = 500;
X = rand(1, K);               % 原题：[0, 1] 上的无序随机横坐标
Y = X.^2 + X;                 % 原题被积函数 f(x) = x^2 + x (精确积分 = 5/6 ≈ 0.833333)

% 联合排序：保持 (X_i, Y_i) 配对关系
[X_sorted, idx] = sort(X);
Y_sorted = Y(idx);

% 在排序后的非均匀网格上执行复合梯形积分，并与均匀采样 Monte Carlo 均值对比
I_trapz = trapz(X_sorted, Y_sorted);
I_mc    = mean(Y);
fprintf('原题 [0,1] 上 x^2+x: 联合排序 trapz = %.6f, MC 均值 = %.6f (精确值 5/6 = %.6f)\n', ...
    I_trapz, I_mc, 5/6);
```

（注：原课件第 3 题配套实验数据文件名为 `prob_data401.mat`，其中 `401` 为题库编号，文件内部实际存储的是区间 $t \in [0, 2\pi]$ 上的 **$2001$ 个采样点** `(t, y)`，处理流程见下节实验题 3。）

### 实验题 3：含噪观测数据的数值求导与平滑降噪

设真实光滑信号为 $y(t) = \sin(2\pi t)$，叠加幅值为 $\sigma$ 的零均值高斯白噪声后得到观测序列 $\tilde{y}_i = y(t_i) + \eta_i$。若直接在细网格步长 $h$ 下计算差商：

$$
\frac{\tilde{y}_{i+1} - \tilde{y}_{i-1}}{2h} = \frac{y(t_{i+1}) - y(t_{i-1})}{2h} + \frac{\eta_{i+1} - \eta_{i-1}}{2h},
$$

则第一项截断误差为 $O(h^2)$，而第二项随机噪声的标准差被放大为 $\frac{\sigma}{\sqrt{2}h} = O(h^{-1})$！当网格步长 $h$ 很小时，直接调用 `diff` 或 `gradient` 会使导数波形完全被高频噪声淹没。
- **工程解决方案**：先对含噪序列执行移动平均滤波（`movmean` / `smoothdata`）、Savitzky-Golay 局部多项式滤波（`sgolayfilt`）或低阶样条拟合，抑制高频噪声后再计算数值导数。

```matlab
%% (a) 原题任务：读取外部观测数据文件 prob_data401.mat (含 t in [0, 2*pi] 上 2001 个观测点 t, y，无解析真导数)
if isfile('prob_data401.mat')
    S = load('prob_data401.mat');
    t_obs = S.t(:).';
    y_obs = S.y(:).';
    dt_obs = t_obs(2) - t_obs(1);
    dy_obs_raw    = gradient(y_obs, dt_obs);
    dy_obs_smooth = gradient(smoothdata(y_obs, 'movmean', 21), dt_obs);
    fprintf('原题 prob_data401.mat (2001 点): 直接差商标准差 = %.4f, 平滑后求导标准差 = %.4f\n', ...
        std(dy_obs_raw), std(dy_obs_smooth));
end

%% (b) 补充合成教学示范（已知真实无噪信号 sin(t) 与真导数 cos(t)，仅用于定量展示 RMSE 放大机理）
rng(42);
t_syn = linspace(0, 2 * pi, 2001);
h_syn = t_syn(2) - t_syn(1);
y_syn_noisy = sin(t_syn) + 0.03 * randn(size(t_syn));
dy_syn_exact = cos(t_syn);

dy_syn_raw    = gradient(y_syn_noisy, h_syn);
dy_syn_smooth = gradient(smoothdata(y_syn_noisy, 'gaussian', 21), h_syn);
fprintf('合成教学信号: 直接求导 RMSE = %.4f, 平滑后求导 RMSE = %.4f\n', ...
    sqrt(mean((dy_syn_raw - dy_syn_exact).^2)), sqrt(mean((dy_syn_smooth - dy_syn_exact).^2)));
```

### 实验题 4：圆盘内四只鸭子同处一个半圆的几何概率问题

**问题描述**：在圆形池塘（单位圆盘 $D = \{x^2 + y^2 \le 1\}$）内独立、均匀地随机放置 $n = 4$ 只鸭子，求这 4 只鸭子能够同时位于某同一个半圆内的概率。

**解析证明（一般 $n$ 个独立随机点）**：
由于半圆由过圆心的直径界定，问题仅依赖于每只鸭子相对于圆心的极角 $\Theta_i \stackrel{\text{i.i.d.}}{\sim} U[0, 2\pi) \, (i = 1, \dots, n)$（极角连续分布，两点共直径的概率为 $0$）。
- $n$ 个点位于同一个半圆内，等价于圆周上存在一段长度 $\ge \pi$ 的开弧不含任何点；
- 对每个点 $i \in \{1, \dots, n\}$，记事件 $A_i$ 为“从点 $\Theta_i$ 出发沿逆时针方向走过半圆弧 $(\Theta_i, \, \Theta_i + \pi \bmod 2\pi)$ 的区域内包含其余全部 $n-1$ 个点”。
- 当这 $n$ 个点共处某半圆时，这样的“最顺时针端点”是唯一的，故事件 $A_1, A_2, \dots, A_n$ **两两互斥**，且每个事件发生的概率均为 $P(A_i) = \left(\frac{1}{2}\right)^{n-1}$。
- 因此 $n$ 只鸭子同处一个半圆的精确概率为：

$$
P_n = \sum_{i=1}^n P(A_i) = \frac{n}{2^{n-1}}.
$$

特别地，当 $n = 4$ 时：

$$
P_4 = \frac{4}{2^{4-1}} = \frac{4}{8} = \frac{1}{2} = 0.5.
$$

**向量化 Monte Carlo 模拟判据**：将每次试验的 4 个极角升序排列为 $0 \le \theta_{(1)} \le \theta_{(2)} \le \theta_{(3)} \le \theta_{(4)} < 2\pi$，计算圆周上 4 段相邻弧长间隔：

$$
\Delta_1 = \theta_{(2)} - \theta_{(1)}, \quad \Delta_2 = \theta_{(3)} - \theta_{(2)}, \quad \Delta_3 = \theta_{(4)} - \theta_{(3)}, \quad \Delta_4 = 2\pi - \theta_{(4)} + \theta_{(1)}.
$$

4 只鸭子位于同一半圆当且仅当最大相邻弧长间隔满足 $\max_{1 \le k \le 4} \Delta_k \ge \pi$：

```matlab
rng(2026);
M = 1e6;                                    % 模拟试验次数
theta = sort(2 * pi * rand(4, M), 1);       % 每列为一次试验的 4 个升序极角
gaps = [diff(theta, 1, 1); 2*pi - theta(4, :) + theta(1, :)];
prob_est = mean(max(gaps, [], 1) >= pi);
fprintf('四鸭同处半圆 Monte Carlo 估计概率 = %.6f (理论精确值 = 0.500000)\n', prob_est);
```

### 实验 3：矩阵的 LU、Cholesky、QR 与 SVD 四大分解检验

**题目要求**：对非奇异矩阵 $A$ 与对称正定矩阵 $S = A^{\mathsf T}A + I$，分别执行列主元 LU 分解 $PA = LU$、Cholesky 分解 $S = R^{\mathsf T}R$、正交三角分解 $A = QR$ 以及奇异值分解 $A = U\Sigma V^{\mathsf T}$，验证各分解的重构残差范数达到机器精度 $O(\varepsilon_{\text{mach}})$。

```matlab
rng(1);
A = randn(5, 5);
S = A.' * A + eye(5);

[L, U, P] = lu(A);
[R_chol, flag] = chol(S);
[Q, R_qr] = qr(A);
[U_svd, Sigma, V_svd] = svd(A);

fprintf('LU 残差 = %.2e, Chol 残差 = %.2e, QR 残差 = %.2e, SVD 残差 = %.2e\n', ...
    norm(P*A - L*U), norm(S - R_chol.'*R_chol), norm(A - Q*R_qr), norm(A - U_svd*Sigma*V_svd.'));
```

### 实验 4：特征值谱分解、不变子空间与马尔可夫状态演化

A = [0.8, 0.3; 0.2, 0.7];

```

### 实验 5：Hilbert 病态矩阵条件数与右端微扰放大实验

**题目要求**：对 $n = 4, 8, 12$ 阶 Hilbert 矩阵 $H_n$，设真解为 $x_{\text{true}} = \mathbf{1}_n$，右端项 $b = H_n x_{\text{true}}$。对 $b$ 施加量级为 $10^{-10}$ 的微小扰动 $\delta b$，观察相对误差 $\frac{\|\hat{x} - x_{\text{true}}\|_2}{\|x_{\text{true}}\|_2}$ 随条件数 $\kappa_2(H_n) = \text{cond}(H_n)$ 急剧放大的现象。

rng(0);

```

### 实验 6：Jacobi 与 Gauss-Seidel 分裂迭代法的谱半径与收敛速率对比

**题目要求**：对严格对角占优矩阵 $A = \begin{bmatrix} 4 & -1 & 0 \\ -1 & 4 & -1 \\ 0 & -1 & 4 \end{bmatrix}$ 与 $b = [3; 2; 3]$，构造 Jacobi 迭代矩阵 $B_J = D^{-1}(L+U)$ 与 Gauss-Seidel 迭代矩阵 $B_{GS} = (D-L)^{-1}U$，比较两者的谱半径 $\rho(B_J)$ 与 $\rho(B_{GS})$，并统计达到相对残差 $10^{-10}$ 所需的迭代步数。

```matlab
A = [4, -1, 0; -1, 4, -1; 0, -1, 4];
b = [3; 2; 3];
D = diag(diag(A));
L = -tril(A, -1);
U = -triu(A, 1);

B_J  = D \ (L + U);
B_GS = (D - L) \ U;
fprintf('rho(B_J) = %.6f, rho(B_GS) = %.6f (验证 rho(B_GS) = rho(B_J)^2)\n', ...
    max(abs(eig(B_J))), max(abs(eig(B_GS))));
```

## 三、 补充专题：高阶微分方程、偏微分方程工具箱与二维 Simpson 求积

### 3.1 高阶常微分方程降阶与数值求解
对于显式 $n$ 阶常微分方程初值问题 $y^{(n)} = f\bigl(t, y, y', \dots, y^{(n-1)}\bigr)$，引入状态向量 $Y = [y_1, y_2, \dots, y_n]^{\mathsf T} = [y, y', \dots, y^{(n-1)}]^{\mathsf T}$，将其等价改写为一阶常微分方程组：

$$
\frac{dY}{dt} = \begin{bmatrix} y_2 \\ y_3 \\ \vdots \\ f(t, y_1, y_2, \dots, y_n) \end{bmatrix}.
$$

在 MATLAB 中编写返回列向量 `dYdt` 的右端函数句柄，传入 `ode45`（非刚性问题）或 `ode15s`（刚性问题）完成数值积分。

### 3.2 二维偏微分方程数值求解与 PDE Toolbox
考虑有界区域 $\Omega \subset \mathbb{R}^2$ 上的二阶椭圆型偏微分方程 $-\nabla \cdot (c \nabla u) + a u = f \, ((x, y) \in \Omega)$，配合边界 $\partial\Omega$ 上的 Dirichlet 条件 $u = g_D$ 或 Neumann 条件 $\mathbf{n} \cdot (c \nabla u) + q u = g_N$：
1. 定义几何区域 $\Omega$ 的 CSG 矩阵与边界分解 `decsg`；
2. 创建 PDE 模型容器 `model = createpde()` 并导入几何 `geometryFromEdges`；

### 3.3 二维复合 Simpson 数值求积
推广至矩形区域 $D = [a, b] \times [c, d]$（分别划分为 $2m$ 与 $2n$ 个偶等分，步长 $h_x = \frac{b-a}{2m}, \, h_y = \frac{d-c}{2n}$），二维复合 Simpson 公式可表示为张量积权重求和：

$$
\iint_D f(x, y)\,dx\,dy \approx \frac{h_x h_y}{9} \sum_{i=0}^{2m} \sum_{j=0}^{2n} w_i^{(x)} w_j^{(y)} f(x_i, y_j),
$$

其中一维权重序列为 $w = [1, 4, 2, 4, 2, \dots, 2, 4, 1]$。完整推导、误差阶验证与原课件二重积分算例 $\iint_{[0,1]^2}(1+x^2+y^2)^{-3/2}dx\,dy = \frac{\pi}{6}$ 详见 [[MATLAB/课程讲义/08C_第八周实验代码与二维Simpson|08C_第八周实验代码与二维Simpson]]。
