# 第八课迭代补充：定常分裂迭代法、SOR 与共轭梯度法

来源：[[MATLAB/课程讲义/08_MATLAB线性代数|第八课：MATLAB 线性代数]] 迭代法与变分二次泛函专题补充。本讲义完整梳理 Jacobi 迭代、Gauss-Seidel 迭代（含教师脚本推导细节）、逐次超松弛法（SOR）、最速下降法以及共轭梯度法（CG）的矩阵分裂推导、谱半径收敛定理与仿射 Krylov 子空间极小化理论。

## 一、 定常矩阵分裂迭代法：Jacobi、Gauss-Seidel 与 SOR

设非奇异线性方程组为 $Ax = b$（$A \in \mathbb{R}^{n \times n}$ 且对角元 $a_{ii} \neq 0$）。关于矩阵的三角分裂存在两种常见符号约定，阅读代码时需首先甄别：
- **正定减法分裂约定**：记 $A = D - L - U$，其中 $D = \operatorname{diag}(a_{11}, \dots, a_{nn})$，$-L = \text{\texttt{tril(A, -1)}}$ 为严格下三角部分，$-U = \text{\texttt{triu(A, 1)}}$ 为严格上三角部分；
- **教师脚本直接加法分解约定**：记 $A = D + L_0 + U_0$，其中 $L_0 = -L = \text{\texttt{tril(A, -1)}}$，$U_0 = -U = \text{\texttt{triu(A, 1)}}$ 直接取自原矩阵的下、上三角元素。

以下统一采用 $A = D - L - U$ 推导，并在代码注释中标明与 `tril`/`triu` 的对应关系。

### 1.1 Jacobi 迭代与 Gauss-Seidel 教师脚本推导

1. **Jacobi 同时位移法**：第 $k+1$ 步的每个分量全部使用第 $k$ 步的旧分量同步计算：

$$
D x^{(k+1)} = (L + U)x^{(k)} + b \iff x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \neq i} a_{ij} x_j^{(k)}\right), \qquad B_J = D^{-1}(L + U).
$$

2. **Gauss-Seidel 逐次位移法**：在按标号 $i = 1, 2, \dots, n$ 依次更新分量时，一旦计算出新分量 $x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}$，立即在当前步后续分量的求和中使用最新值替换旧值：

$$
x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^n a_{ij} x_j^{(k)}\right), \quad i = 1, \dots, n.
$$

写成矩阵形式即为：

$$
(D - L) x^{(k+1)} = U x^{(k)} + b \iff x^{(k+1)} = B_{GS} x^{(k)} + (D - L)^{-1}b, \qquad B_{GS} = (D - L)^{-1}U.
$$

**教师脚本实现要点与数值规范**：
- **下三角前代求解**：在 MATLAB 中，$\text{\texttt{tril(A)}} = D - L$，$\text{\texttt{triu(A, 1)}} = -U$，因此单步更新写为 `x_new = tril(A) \ (b - triu(A, 1) * x_old)`。由于 `tril(A)` 为下三角矩阵，左除算子 `\` 会自动调用 $O(n^2)$ 的前向回代（Forward Substitution），严禁显式调用 $O(n^3)$ 的 `inv(D - L)`。
- **单向量原地更新**：若采用分量循环实现，由于第 $i$ 个分量更新时只需前 $i-1$ 个新分量与后 $n-i$ 个旧分量，只需维护单个向量 `x(i) = (b(i) - A(i,[1:i-1, i+1:n]) * x([1:i-1, i+1:n])) / A(i,i)` 即可自动实现 Gauss-Seidel 的新旧分量混合。
- **相邻步差不等于真误差**：设迭代满足 $\|B\| = q < 1$，由三角不等式有
  $$
  \|x^{(k)} - x^*\| \le \|x^{(k+1)} - x^{(k)}\| + \|B(x^{(k)} - x^*)\| \implies \|x^{(k+1)} - x^*\| \le \frac{q}{1 - q}\|x^{(k+1)} - x^{(k)}\|.
  $$
  当迭代矩阵范数 $q$（或谱半径 $\rho(B)$）接近 $1$ 时，因子 $\frac{q}{1-q} \gg 1$，此时**相邻两步的步差 $\|x^{(k+1)} - x^{(k)}\|$ 很小绝不意味着真误差 $\|x^{(k+1)} - x^*\|$ 很小**！因此收敛判据应结合相对残差 $\|b - Ax^{(k)}\|_2 / \|b\|_2 < \text{tol}$ 共同检验。

```matlab
%% 教师课堂脚本算例：400 阶严格对角占优矩阵的 Gauss-Seidel 迭代及步差 vs 真误差对比
rng(2026);
n = 400;
% 构造测试矩阵 A = rand(400, 400) + 500 * eye(400):
% 对角元 a_{ii} >= 500, 而每行非对角元绝对值之和 <= 399 * 1 = 399 < 500, 故严格行对角占优！
A = rand(n, n) + 500 * eye(n);
x_star = ones(n, 1);          % 预设已知精确真解 x*
b = A * x_star;               % 生成对应右端项

% 按教师脚本加法分裂 A = D + L0 + U0, 其中 D + L0 = tril(A), U0 = triu(A, 1)
DL = tril(A);
U0 = triu(A, 1);

x = zeros(n, 1);              % 初始猜测 x^(0)
tol = 1e-12;
for k = 1:100
    x_next = DL \ (b - U0 * x);
    step_diff = norm(x_next - x, 2);      % 相邻两步位移 ||x^(k+1) - x^(k)||_2
    true_err  = norm(x_next - x_star, 2); % 相对已知真解的真误差 ||x^(k+1) - x*||_2
    x = x_next;
    if step_diff < tol
        fprintf('GS 迭代在第 %d 步终止: 步差 = %.3e, 真误差 = %.3e\n', k, step_diff, true_err);
        break;
    end
end
```

### 1.2 逐次超松弛法（SOR）推导

在 Gauss-Seidel 预测值 $\tilde{x}_i^{(k+1)}$ 与旧值 $x_i^{(k)}$ 之间引入松弛因子 $\omega > 0$ 作加权平均：

$$
x_i^{(k+1)} = (1 - \omega)x_i^{(k)} + \frac{\omega}{a_{ii}}\left(b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^n a_{ij} x_j^{(k)}\right).
$$

左乘 $D$ 并移项整理，得到 SOR 法的矩阵分裂格式与迭代矩阵 $B_\omega$：

$$
(D - \omega L)x^{(k+1)} = \bigl[(1 - \omega)D + \omega U\bigr]x^{(k)} + \omega b, \qquad
B_\omega = (D - \omega L)^{-1}\bigl[(1 - \omega)D + \omega U\bigr].
$$

- 当 $\omega = 1$ 时，SOR 退化为标准 Gauss-Seidel 法；
- 当 $0 < \omega < 1$ 时称为低松弛法（Under-relaxation）；当 $1 < \omega < 2$ 时称为超松弛法（Over-relaxation）。

### 1.3 谱半径分析与收敛性定理（严格区分充要条件与充分条件）

> [!important] **定理 1.1（定常迭代收敛的基本定理与充分条件）**
> 1. **谱半径充要条件**：一般定常线性迭代 $x^{(k+1)} = B x^{(k)} + f$ 对任意初始向量 $x^{(0)} \in \mathbb{R}^n$ 收敛于唯一真解 $x^*$ 的**充要条件**是迭代矩阵的谱半径严格小于 $1$：
>    $$
>    \rho(B) = \max_{1 \le i \le n} |\lambda_i(B)| < 1.
>    $$
> 2. **Kahan 必要条件（SOR 松弛参数范围）**：由于 $\det(B_\omega) = \det(D)^{-1}\det\bigl((1-\omega)D\bigr) = (1 - \omega)^n$，故 $\rho(B_\omega) \ge |\det(B_\omega)|^{1/n} = |1 - \omega|$。因此，SOR 法收敛的**必要条件**是松弛因子满足 $0 < \omega < 2$。
> 3. **严格对角占优充分条件**：若系数矩阵 $A$ 为严格行（或列）对角占优矩阵（即 $|a_{ii}| > \sum_{j \neq i} |a_{ij}|, \, \forall i$），则 Jacobi 法与 Gauss-Seidel 法均收敛，且对 $0 < \omega \le 1$ 的 SOR 法也必收敛。
> 4. **对称正定（SPD）充分条件（Ostrowski-Reich 定理）**：**系数矩阵 $A$ 对称正定（$A = A^{\mathsf T} > 0$）是 Gauss-Seidel 法收敛以及 SOR 法（对一切 $0 < \omega < 2$）收敛的充分条件**（注意是**充分条件而非必要条件**，许多非对称矩阵如严格对角占优阵同样使 GS 与 SOR 收敛；反之，对 Jacobi 法而言，$A$ 对称正定仅在 $2D - A$ 也正定时才收敛）。

## 二、 严格凸二次泛函的精确线搜索与最速下降法

设 $A \in \mathbb{R}^{n \times n}$ 为实对称正定矩阵（$A = A^{\mathsf T} > 0$），求解 $Ax = b$ 等价于极小化严格凸二次能量泛函：

$$
f(x) = \frac{1}{2} x^{\mathsf T} A x - b^{\mathsf T} x, \qquad \text{等价于极小化 } A\text{-能量误差范数 } \|x - x^*\|_A^2 = (x - x^*)^{\mathsf T}A(x - x^*).
$$

其在当前迭代点 $x_k$ 处的梯度为 $g_k = \nabla f(x_k) = A x_k - b$，负梯度即为残差向量 $r_k = -g_k = b - A x_k$。沿最速下降方向 $r_k$ 更新 $x_{k+1} = x_k + \alpha_k r_k$，**精确线搜索（Exact Line Search）**选取步长 $\alpha_k > 0$ 使一维函数 $\phi(\alpha) = f(x_k + \alpha r_k)$ 达到极小：

$$
\phi(\alpha) = f(x_k) - \alpha r_k^{\mathsf T} r_k + \frac{1}{2}\alpha^2 r_k^{\mathsf T} A r_k.
$$

由于 $A$ 正定，当 $r_k \neq 0$ 时必有 $r_k^{\mathsf T} A r_k > 0$。令 $\phi'(\alpha) = -r_k^{\mathsf T} r_k + \alpha r_k^{\mathsf T} A r_k = 0$，解得唯一最优步长：

$$
\alpha_k = \frac{r_k^{\mathsf T} r_k}{r_k^{\mathsf T} A r_k} = \frac{g_k^{\mathsf T} g_k}{g_k^{\mathsf T} A g_k}.
$$

此时相邻两步残差恒正交 $r_{k+1}^{\mathsf T} r_k = (r_k - \alpha_k A r_k)^{\mathsf T} r_k = 0$，能量范数误差满足 Kantorovich 不等式上界：

$$
\|x_{k+1} - x^*\|_A \le \left(\frac{\kappa_2(A) - 1}{\kappa_2(A) + 1}\right) \|x_k - x^*\|_A.
$$

## 三、 共轭梯度法（Conjugate Gradient, CG）与仿射 Krylov 子空间

为克服最速下降法在椭球等值面狭长（$\kappa_2(A) \gg 1$）时的直角锯齿振荡，共轭梯度法（CG）构造一组关于 $A$-内积 $\langle p, q \rangle_A = p^{\mathsf T} A q$ 两两正交（即 **$A$-共轭**：$p_i^{\mathsf T} A p_j = 0, \, \forall i \neq j$）的搜索方向 $\{p_0, p_1, \dots, p_{k-1}\}$。

### 3.1 仿射 Krylov 子空间极小化性质（含非零初值 $x_0$）

给定任意初始猜测向量 $x_0 \in \mathbb{R}^n$，计算初始残差 $r_0 = b - A x_0$，定义 $k$ 阶 **Krylov 子空间**为：

$$
\mathcal{K}_k(A, r_0) = \operatorname{span}\bigl\{r_0, \, A r_0, \, A^2 r_0, \, \dots, \, A^{k-1} r_0\bigr\}.
$$

> [!important] **定理 3.1（共轭梯度法的仿射 Krylov 子空间最优性）**
> 设 $A \in \mathbb{R}^{n \times n}$ 对称正定。对任意初始猜测 $x_0 \in \mathbb{R}^n$，共轭梯度法第 $k$ 步产生的迭代解 $x_k$ 的步进修正量满足 $x_k - x_0 \in \mathcal{K}_k(A, r_0)$，且 $x_k$ 是**仿射 Krylov 子空间** $x_0 + \mathcal{K}_k(A, r_0)$ 上使二次泛函 $f(x)$（等价于能量范数误差 $\|x - x^*\|_A$）达到极小的唯一最优解：
> $$
> x_k = \underset{x \in x_0 + \mathcal{K}_k(A, r_0)}{\operatorname{argmin}} f(x) = \underset{x \in x_0 + \mathcal{K}_k(A, r_0)}{\operatorname{argmin}} \|x - x^*\|_A,
> $$
> 其残差 $r_k = b - A x_k$ 与子空间 $\mathcal{K}_k(A, r_0)$ 正交（Galerkin 正交条件：$r_k \perp \mathcal{K}_k(A, r_0)$）。
> - **初值辨析**：仅当初始猜测取为零向量 $x_0 = 0$（此时 $r_0 = b$）时，仿射子空间 $x_0 + \mathcal{K}_k(A, r_0)$ 才退化为线性 Krylov 子空间 $\mathcal{K}_k(A, b)$；若 $x_0 \neq 0$，不可漏写初值平移项 $x_0$（例如取 $A = I_2, \, b = [1; 0], \, x_0 = [0; 1]$，则 $r_0 = [1; -1]$，一步 CG 即得真解 $x_1 = [1; 0] \in x_0 + \operatorname{span}\{r_0\}$，但 $x_1 \notin \operatorname{span}\{r_0\}$）。
> - **有限步终止与收敛界**：在精确算术（无浮点舍入误差）下，由于 $\dim \mathcal{K}_k(A, r_0) \le n$，CG 至多经过 $m \le n$ 步（$m$ 为 $A$ 的互异特征值个数）必求得精确解 $x^*$；第 $k$ 步误差满足 Chebyshev 多项式界：
>   $$
>   \|x_k - x^*\|_A \le 2\left(\frac{\sqrt{\kappa_2(A)} - 1}{\sqrt{\kappa_2(A)} + 1}\right)^k \|x_0 - x^*\|_A.
>   $$

### 3.2 标准共轭梯度递推格式

初始化 $x_0$，$r_0 = b - A x_0$，$p_0 = r_0$。对 $k = 0, 1, 2, \dots$ 循环执行：

$$
\begin{aligned}
\alpha_k &= \frac{r_k^{\mathsf T} r_k}{p_k^{\mathsf T} A p_k}, \\
x_{k+1} &= x_k + \alpha_k p_k, \\
r_{k+1} &= r_k - \alpha_k A p_k, \\
\beta_k &= \frac{r_{k+1}^{\mathsf T} r_{k+1}}{r_k^{\mathsf T} r_k}, \\
p_{k+1} &= r_{k+1} + \beta_k p_k.
\end{aligned}
$$

## 四、 四种迭代算法完整 MATLAB 实现与对比

```matlab
function [x_gs, x_sor, x_sd, x_cg] = iter_methods_comparison(A, b, x0, omega, tol, max_iter)
% ITER_METHODS_COMPARISON 对比 Gauss-Seidel, SOR, 最速下降法与共轭梯度法 (CG)
    b_norm = max(norm(b), eps);
    D = diag(diag(A));
    L = -tril(A, -1);
    U = -triu(A, 1);

    % 1. Gauss-Seidel 迭代（利用下三角前代求解，避免 inv）
    x_gs = x0;
    for k = 1:max_iter
        if norm(b - A * x_gs) / b_norm < tol, break; end
        x_gs = (D - L) \ (U * x_gs + b);
    end

    % 2. SOR 逐次超松弛迭代 (0 < omega < 2)
    x_sor = x0;
    for k = 1:max_iter
        if norm(b - A * x_sor) / b_norm < tol, break; end
        x_sor = (D - omega * L) \ (((1 - omega) * D + omega * U) * x_sor + omega * b);
    end

    % 3. 最速下降法 (Steepest Descent)
    x_sd = x0;
    for k = 1:max_iter
        r = b - A * x_sd;
        if norm(r) / b_norm < tol, break; end
        alpha = (r.' * r) / (r.' * A * r);
        x_sd = x_sd + alpha * r;
    end

    % 4. 共轭梯度法 (Conjugate Gradient, 在 x0 + K_k(A, r0) 上极小化)
    x_cg = x0;
    r = b - A * x_cg;
    p = r;
    rs_old = r.' * r;
    for k = 1:max_iter
        if sqrt(rs_old) / b_norm < tol, break; end
        Ap = A * p;
        alpha = rs_old / (p.' * Ap);
        x_cg = x_cg + alpha * p;
        r = r - alpha * Ap;
        rs_new = r.' * r;
        p = r + (rs_new / rs_old) * p;
        rs_old = rs_new;
    end
end
```
