## 一、 线性方程组、求根与约束最优化实验（原课件第 1–2 页）

### 1.1 线性方程组相容性判别与 Moore-Penrose 伪逆

对比三组幻方系数线性系统 $Ax = b$ 的求解特征：
1. $A = \text{magic}(3)$（满秩 $\operatorname{rank}(A) = 3$），$b = \text{ones}(3, 1)$：方程组有唯一精确解 $x = \frac{1}{15}[1; 1; 1]$。
2. $A = \text{magic}(4)$（秩亏 $\operatorname{rank}(A) = 3 < 4$），$b = \text{ones}(4, 1)$：由于 4 阶幻方每行元素之和均为 $34$，$\operatorname{rank}([A, b]) = \operatorname{rank}(A) = 3$，方程组**相容且有无穷多解**。其中 `x_basic = A \ b` 通过列主元 QR 分解给出至多含 $3$ 个非零分量的基本解，而 `x_pinv = pinv(A) * b` 给出唯一极小 2-范数解 $x^+ = \frac{1}{34}[1; 1; 1; 1]$。
3. $A = \text{magic}(4)$，$b = [1; 2; 3; 4]$：此时 $\operatorname{rank}(A) = 3 < \operatorname{rank}([A, b]) = 4$，方程组**不相容（无精确解）**，仅存在最小二乘解。

**Moore-Penrose 广义逆 `pinv(A)`**：
对任意矩阵 $A \in \mathbb{R}^{m \times n}$，其 Moore-Penrose 伪逆 $A^+ \in \mathbb{R}^{n \times m}$ 由四条 Penrose 方程唯一确定：

$$
AA^+A = A, \quad A^+AA^+ = A^+, \quad (AA^+)^{\mathsf T} = AA^+, \quad (A^+A)^{\mathsf T} = A^+A.
$$

若 $A = U \Sigma V^{\mathsf T}$ 为奇异值分解，则 $A^+ = V \Sigma^+ U^{\mathsf T}$。向量 $x^+ = A^+ b$（或 `lsqminnorm(A, b)`）给出**极小范数最小二乘解**：
- 当 $Ax = b$ 相容时，$x^+$ 是所有精确解中欧氏 2-范数 $\|x\|_2$ 最小的唯一解；
- 当 $Ax = b$ 不相容时，$x^+$ 是所有使残差 $\|Ax - b\|_2$ 达到最小的最小二乘解中 $\|x\|_2$ 最小的唯一解。

### 1.2 二分法与 Newton 法求根对比

求解超越方程 $f(x) = x \sin x + \cos x = 0$ 在区间 $[\pi/2, \pi]$ 内的实根（Newton 法取初值 $x_0 = 3\pi/4$）：
- 导函数为 $f'(x) = \sin x + x\cos x - \sin x = x\cos x$。在 $(\pi/2, \pi]$ 上 $f'(x) < 0$，$f(x)$ 严格单调递减，且 $f(\pi/2) = \pi/2 > 0, \, f(\pi) = -1 < 0$，故区间内存在唯一单根 $x^* \approx 2.798386045783887$。
- 二分法每次迭代将有根区间长度缩半，收敛速率为 $O(2^{-k})$；Newton 法迭代格式为：

$$
x_{k+1} = x_k - \frac{x_k \sin x_k + \cos x_k}{x_k \cos x_k} = x_k - \tan x_k - \frac{1}{x_k},
$$

在单根邻域内展现二阶（平方）收敛速度，仅需 $4 \sim 5$ 次迭代即达到双精度机器精度。

### 1.3 固定步长梯度下降法的收敛域分析

对对称正定二次目标函数 $\phi(x) = \frac{1}{2}x^{\mathsf T} A x - b^{\mathsf T} x \, (A = A^{\mathsf T} > 0)$，固定步长 $\alpha > 0$ 的梯度下降迭代与误差演化满足：

$$
\begin{aligned}
x_{k+1} &= x_k + \alpha (b - A x_k), \\
e_{k+1} &= x_{k+1} - x^* = (I - \alpha A) e_k.
\end{aligned}
$$

迭代矩阵 $I - \alpha A$ 的特征值为 $1 - \alpha \lambda_i(A)$。因此，固定步长梯度下降对任意初值收敛的充要条件为：

$$
\rho(I - \alpha A) = \max_i |1 - \alpha \lambda_i(A)| < 1 \iff 0 < \alpha < \frac{2}{\lambda_{\max}(A)}.
$$

以 $A = \operatorname{diag}(2, 8)$ 为例，$\lambda_{\max}(A) = 8$，临界步长上界为 $2 / 8 = 0.25$：
- 当 $\alpha = 0.1 \in (0, 0.25)$ 时，谱半径 $\rho = 0.8 < 1$，误差指数衰减；
- 当 $\alpha = 0.25$ 时，对应 $\lambda = 8$ 的特征分量放大因子为 $1 - 0.25 \times 8 = -1$，误差发生等幅正负交替振荡而不衰减；
- 当 $\alpha = 0.3 > 0.25$ 时，放大因子 $|1 - 2.4| = 1.4 > 1$，迭代指数发散。

### 1.4 3×3 矩阵的六项范数/谱半径计算与铁丝截段约束最优化建模

#### (a) 3×3 矩阵的五种范数与谱半径计算（原课件第 2 页）

给定原课件中的 $3 \times 3$ 实方阵：

$$
A = \begin{bmatrix} 1 & -1 & 1 \\ 1 & 2 & -3 \\ 2 & 1 & -1 \end{bmatrix} \in \mathbb{R}^{3 \times 3},
$$

完整计算其 **1-范数、2-范数、$\infty$-范数、Frobenius 范数、核范数（Nuclear Norm）与谱半径（Spectral Radius）** 六项指标：
1. **列和 1-范数**：$\|A\|_1 = \max_{1 \le j \le 3} \sum_{i=1}^3 |a_{ij}| = \max\{1+1+2, \, 1+2+1, \, 1+3+1\} = \max\{4, 4, 5\} = 5 \implies \text{\texttt{norm(A, 1)}}$；
2. **谱 2-范数（最大奇异值）**：Gram 矩阵 $A^{\mathsf T}A = \begin{bmatrix} 6 & 3 & -4 \\ 3 & 6 & -8 \\ -4 & -8 & 11 \end{bmatrix}$ 的三个特征值依次约为 $18.829936, \, 4.052110, \, 0.117954$，开方得三个奇异值为 $\sigma_1 \approx 4.33934742, \, \sigma_2 \approx 2.01298535, \, \sigma_3 \approx 0.34344422$，故谱 2-范数为 $\|A\|_2 = \sigma_1(A) \approx 4.33934742 \implies \text{\texttt{norm(A, 2)}}$；
3. **行和 $\infty$-范数**：$\|A\|_\infty = \max_{1 \le i \le 3} \sum_{j=1}^3 |a_{ij}| = \max\{3, 6, 4\} = 6 \implies \text{\texttt{norm(A, inf)}}$；
4. **Frobenius 范数**：$\|A\|_F = \sqrt{\sum_{i,j} |a_{ij}|^2} = \sqrt{\sum_{k=1}^3 \sigma_k^2(A)} = \sqrt{1+1+1+1+4+9+4+1+1} = \sqrt{23} \approx 4.79583152 \implies \text{\texttt{norm(A, 'fro')}}$；
5. **核范数（迹范数 / 奇异值之和）**：$\|A\|_* = \sum_{k=1}^3 \sigma_k(A) \approx 4.33934742 + 2.01298535 + 0.34344422 = 6.69577700 \implies \text{\texttt{sum(svd(A))}}$；
6. **谱半径（特征值最大模）**：$A$ 的特征多项式为 $\lambda^3 - 2\lambda^2 + \lambda - 3 = 0$，最大模实特征值为 $\rho(A) = \max_{1 \le k \le 3} |\lambda_k(A)| \approx 2.17455941 \implies \text{\texttt{max(abs(eig(A)))}}$（满足 $\rho(A) \le \|A\|_p$）。

```matlab
A = [1, -1, 1; 1, 2, -3; 2, 1, -1];
n1    = norm(A, 1);            % 5
n2    = norm(A, 2);            % 最大奇异值 \sigma_1(A) ≈ 4.33934742
ninf  = norm(A, inf);          % 6
nfro  = norm(A, 'fro');        % sqrt(23) ≈ 4.79583152
nnuc  = sum(svd(A));           % 核范数 \sum \sigma_i(A) ≈ 6.69577700
rho_A = max(abs(eig(A)));      % 谱半径 \max |\lambda_i(A)| ≈ 2.17455941
```

- **矩形矩阵拓展辨析**：若将矩阵改为非方阵 $B \in \mathbb{R}^{m \times n} \, (m \neq n)$，则 $B$ 不存在特征值与谱半径 $\rho(B)$；但其诱导 1-范数、2-范数、$\infty$-范数、Frobenius 范数以及**核范数 $\|B\|_* = \sum_{i=1}^{\min(m,n)} \sigma_i(B) = \text{\texttt{sum(svd(B))}}$ 对任意矩形矩阵均严格有定义**。

#### (b) 铁丝截段总面积极值问题

将总长为 $L = 2\text{ m}$ 的铁丝截为三段（长度分别记为 $x, y, z \ge 0$，满足 $x + y + z = 2$），分别围成正三角形、正方形和圆，总面积目标函数为：

$$
S(x, y, z) = \frac{\sqrt{3}}{36} x^2 + \frac{1}{16} y^2 + \frac{1}{4\pi} z^2, \qquad \text{s.t. } x + y + z = 2, \; x, y, z \ge 0.
$$

- **极小值（内部驻点）**：目标函数 $S(x, y, z)$ 为严格凸二次函数（Hessian 矩阵对角正定），由 Lagrange 乘子法得内部唯一驻点满足 $\frac{\sqrt{3}}{18}x = \frac{1}{8}y = \frac{1}{2\pi}z = \lambda$，即边长按面积系数倒数之比 $x : y : z = \frac{18}{\sqrt{3}} : 8 : 2\pi$ 分配时总面积取得**全局最小值** $S_{\min} = \frac{1}{9\sqrt{3} + 4 + \pi} \approx 0.043995\text{ m}^2$。
- **极大值（可行域单纯形顶点）**：凸函数在紧凸多面体（二维单纯形 $\Delta_2$）上的全局最大值必在极点（顶点）处达到。比较三个顶点 $(2, 0, 0)$、$(0, 2, 0)$、$(0, 0, 2)$ 的面积值：由于 $\frac{1}{4\pi} > \frac{1}{16} > \frac{\sqrt{3}}{36}$，故当全部铁丝用于围成圆 $(0, 0, 2)$ 时，总面积达到**全局最大值** $S_{\max} = \frac{1}{\pi} \approx 0.318310\text{ m}^2$。

## 二、 概率统计抽样、多元正态分布与曲线拟合四道实验题

### 实验题 A：均匀分布与指数分布的逆变换抽样（Inverse Transform Sampling）

**数学原理**：设连续型随机变量 $X$ 的严格递增累积分布函数为 $F(x)$。若 $U \sim U(0, 1)$，则对任意 $x \in \mathbb{R}$：

$$
P\bigl(F^{-1}(U) \le x\bigr) = P\bigl(U \le F(x)\bigr) = F(x).
$$

因此 $X = F^{-1}(U)$ 严格服从分布 $F$。
1. **区间 $[a, b]$ 上的均匀分布 $U(a, b)$**：由 $F(x) = \frac{x-a}{b-a} = U$ 解得仿射变换 $X = a + (b - a)U$；
2. **参数为 $\lambda > 0$ 的指数分布 $\operatorname{Exp}(\lambda)$**（密度 $f(x) = \lambda e^{-\lambda x} \mathbf{1}_{x \ge 0}$，均值为 $\mu = 1/\lambda$）：由 $F(x) = 1 - e^{-\lambda x} = U$ 解得逆变换抽样公式：

$$
X = -\frac{1}{\lambda}\ln(1 - U) \stackrel{d}{=} -\frac{1}{\lambda}\ln U.
$$

（注意 MATLAB 内建函数 `exprnd(mu)` 的输入参数是均值 $\mu = 1/\lambda$，而非率参数 $\lambda$。）

```matlab
rng(2026);
N = 50000;
U = rand(N, 1);

% 1. 仿射变换生成 U(-2, 3) 样本
a = -2; b = 3;
X_unif = a + (b - a) * U;

% 2. 逆变换法生成率参数 \lambda = 2 (均值 \mu = 0.5) 的指数分布样本
lambda = 2;
X_exp = -log(1 - U) / lambda;

figure;
subplot(1, 2, 1);
histogram(X_unif, 40, 'Normalization', 'pdf'); hold on;
x_u = linspace(-2.5, 3.5, 200);
plot(x_u, unifpdf(x_u, a, b), 'r-', 'LineWidth', 1.8);
title('U(-2, 3) 逆变换抽样与理论密度');

subplot(1, 2, 2);
histogram(X_exp, 60, 'Normalization', 'pdf'); hold on;
x_e = linspace(0, 4, 200);
plot(x_e, lambda * exp(-lambda * x_e), 'r-', 'LineWidth', 1.8);
title('Exp(\lambda=2) 逆变换抽样与理论密度');
```

### 实验题 B：二维相关正态分布随机抽样、散点图与等高线椭圆

**数学原理**：设二维正态分布 $\mathbf{X} = [X_1; X_2] \sim \mathcal{N}(\boldsymbol{\mu}, \Sigma)$，其中均值向量 $\boldsymbol{\mu} = [\mu_1; \mu_2]$，对称正定协方差矩阵为：

$$
\Sigma = \begin{bmatrix} \sigma_1^2 & \rho \sigma_1 \sigma_2 \\ \rho \sigma_1 \sigma_2 & \sigma_2^2 \end{bmatrix}, \qquad |\rho| < 1.
$$

对其进行下三角 Cholesky 分解 $\Sigma = L L^{\mathsf T}$（在 MATLAB 中 `R = chol(Sigma)` 返回上三角阵满足 $R^{\mathsf T}R = \Sigma$，故 $L = R^{\mathsf T}$）。若标准正态随机向量 $\mathbf{Z} \sim \mathcal{N}(\mathbf{0}, I_2)$，则仿射变换 $\mathbf{X} = \boldsymbol{\mu} + L \mathbf{Z}$ 满足 $\operatorname{Cov}(\mathbf{X}) = L I_2 L^{\mathsf T} = \Sigma$。其联合概率密度函数为：

$$
f(\mathbf{x}) = \frac{1}{2\pi\sqrt{\det\Sigma}} \exp\!\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^{\mathsf T}\Sigma^{-1}(\mathbf{x} - \boldsymbol{\mu})\right),
$$

等密度线 $(\mathbf{x} - \boldsymbol{\mu})^{\mathsf T}\Sigma^{-1}(\mathbf{x} - \boldsymbol{\mu}) = c^2$ 为以 $\boldsymbol{\mu}$ 为中心、主轴沿 $\Sigma$ 特征向量方向的倾斜椭圆。

```matlab
rng(42);
mu = [1; 2];
Sigma = [2.0, 1.2; 1.2, 1.5];        % 相关系数 \rho = 1.2 / sqrt(3) \approx 0.6928
N = 3000;

% Cholesky 分解构造二维相关正态样本（等价于 mvnrnd(mu.', Sigma, N)）
R = chol(Sigma);                     % R.' * R = Sigma
Z = randn(2, N);
X_corr = mu + R.' * Z;

% 计算二维网格上的联合概率密度与等高线
x1 = linspace(-4, 6, 150);
x2 = linspace(-3, 7, 150);
[G1, G2] = meshgrid(x1, x2);
DX1 = G1 - mu(1); DX2 = G2 - mu(2);
invS = inv(Sigma);
Q_form = invS(1,1)*DX1.^2 + 2*invS(1,2)*DX1.*DX2 + invS(2,2)*DX2.^2;
PDF_2d = exp(-0.5 * Q_form) / (2 * pi * sqrt(det(Sigma)));

figure;
scatter(X_corr(1,:), X_corr(2,:), 8, 'filled', 'MarkerFaceAlpha', 0.35); hold on;
contour(G1, G2, PDF_2d, 6, 'LineWidth', 1.5);
axis equal; grid on;
xlabel('X_1'); ylabel('X_2');
title('二维相关正态分布散点图与等密度椭圆线');
```

### 实验题 C：三维二元高斯概率密度曲面与带等高线底座绘制

利用 `surf` 与 `surfc` 绘制二元高斯核函数 $f(x, y) = \frac{1}{2\pi\sigma_x\sigma_y\sqrt{1-\rho^2}}\exp\bigl(-\frac{1}{2}Q(x, y)\bigr)$ 的三维光滑曲面及底面投影等高线：


### 实验题 D：含噪数据的三次多项式最小二乘拟合与 95% 预测区间

给定三次多项式真实模型 $y_{\text{true}}(x) = 0.5 x^3 - 1.2 x^2 + 0.8 x + 2.0$，在 $x \in [-2, 3]$ 上抽取 $N = 25$ 个叠加独立同方差高斯噪声 $\varepsilon_i \sim \mathcal{N}(0, 0.6^2)$ 的观测样本，执行三次多项式最小二乘拟合：
- 调用 `[p, S, mu] = polyfit(x, y, 3)` 获得中心化缩放后的降幂系数与误差结构体 `S`（自由度 $\nu = \text{\texttt{S.df}} = N - 4 = 21$）；
- 调用 `[y_hat, delta] = polyval(p, x_grid, S, mu)`，其中返回的 `delta` 是**新观测值的预测标准误差估计（Standard Error of Prediction）**，因此逐点 $1 - \alpha = 95\%$ 预测区间为 $\hat{y}(x) \pm t_{0.975, \, N-4} \cdot \delta(x)$（其中 $t_{0.975, \, 21} = \text{\texttt{tinv(0.975, S.df)}}$）。

```matlab
rng(2026);
N = 25;
x_obs = linspace(-2, 3, N).';
y_clean = 0.5*x_obs.^3 - 1.2*x_obs.^2 + 0.8*x_obs + 2.0;
y_obs = y_clean + 0.6 * randn(N, 1);

% 三次多项式最小二乘拟合（带中心化与缩放 mu）
[p, S, mu] = polyfit(x_obs, y_obs, 3);

x_grid = linspace(-2, 3, 200).';
[y_hat, delta] = polyval(p, x_grid, S, mu);

% 自由度 df = N - 4 = 21 下的双侧 95% t 分布临界值
t_crit = tinv(0.975, S.df);
ci_lower = y_hat - t_crit * delta;
ci_upper = y_hat + t_crit * delta;

figure;
plot(x_obs, y_obs, 'ko', 'MarkerFaceColor', 'k'); hold on;
plot(x_grid, y_hat, 'b-', 'LineWidth', 1.8);
plot(x_grid, ci_lower, 'r--', x_grid, ci_upper, 'r--', 'LineWidth', 1.2);
legend('含噪观测点', '三次多项式拟合曲线', '95% 预测区间下界', '95% 预测区间上界', 'Location', 'northwest');
xlabel('x'); ylabel('y'); grid on;
title('含噪数据三次多项式最小二乘拟合与 95% 预测区间');
```
