## 二、 奇异值分解（SVD）与图像低秩压缩

### 2.1 SVD 几何意义、Eckart-Young-Mirsky 定理与课件勘误

对任意实矩阵 $A \in \mathbb{R}^{m \times n} \, (\operatorname{rank}(A) = R)$，存在正交矩阵 $U = [u_1, \dots, u_m] \in \mathbb{R}^{m \times m}$ 与 $V = [v_1, \dots, v_n] \in \mathbb{R}^{n \times n}$，使得：

$$
A = U \Sigma V^{\mathsf T} = \sum_{i=1}^R \sigma_i u_i v_i^{\mathsf T}, \qquad \sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_R > 0.
$$

- **课件勘误（第 5 页）**：计算 $A = \begin{bmatrix} 3 & 0 \\ 4 & 5 \end{bmatrix}$ 时，$A^{\mathsf{T}}A = \begin{bmatrix} 25 & 20 \\ 20 & 25 \end{bmatrix}$ 的特征值为 $\lambda_1 = 45, \, \lambda_2 = 5$，奇异值为 $\sigma_1 = \sqrt{45} = 3\sqrt{5}, \, \sigma_2 = \sqrt{5}$。原课件第 5 页将对角阵误写为 $\Sigma = \operatorname{diag}(\sqrt{5}, \sqrt{45})$，与所给左右奇异向量的列顺序相反；按标准非增序及 MATLAB `svd(A)` 输出，应修正为 $\Sigma = \operatorname{diag}(\sqrt{45}, \sqrt{5})$。

**Eckart-Young-Mirsky 低秩逼近定理**：对 $1 \le r < R$，取前 $r$ 个奇异值构造截断矩阵 $A_r = U_{:,1:r} \Sigma_{1:r,1:r} V_{:,1:r}^{\mathsf T} = \sum_{i=1}^r \sigma_i u_i v_i^{\mathsf T}$，则 $A_r$ 在谱范数（2-范数）与 Frobenius 范数意义下同时给出 $A$ 的最优秩 $r$ 逼近：

$$
\min_{\operatorname{rank}(B) \le r} \|A - B\|_2 = \|A - A_r\|_2 = \sigma_{r+1}, \qquad
\min_{\operatorname{rank}(B) \le r} \|A - B\|_F = \|A - A_r\|_F = \sqrt{\sum_{i=r+1}^R \sigma_i^2}.
$$

### 2.2 灰度图像低秩压缩、存储压缩比与完整实现

对于 $m \times n$ 的双精度灰度图像矩阵 $A$，原始存储需 $m n$ 个浮点数；而秩 $r$ 截断逼近只需存储 $U_{:,1:r}$、$\operatorname{diag}(\Sigma_{1:r,1:r})$ 与 $V_{:,1:r}$，共 $(m + n + 1)r$ 个浮点数，存储压缩比与相对能量保留率分别为：

$$
\mathrm{CR}(r) = \frac{(m + n + 1)r}{mn}, \qquad \eta_F^2(r) = \frac{\|A_r\|_F^2}{\|A\|_F^2} = \frac{\sum_{i=1}^r \sigma_i^2}{\sum_{i=1}^R \sigma_i^2}.
$$

```matlab
function svd_image_compression_demo()
% SVD_IMAGE_COMPRESSION_DEMO 基于截断 SVD 的图像低秩压缩与误差分析
    % 构造合成测试图像（或使用 imread 读取标准灰度图像并转为 double）
    [X, Y] = meshgrid(linspace(-3, 3, 256), linspace(-3, 3, 256));
    A = peaks(X, Y) + 2 * exp(-(X.^2 + Y.^2)) + 0.5 * cos(4*X).*sin(4*Y);
    [m, n] = size(A);

    [U, S, V] = svd(A, 'econ');
    sigma = diag(S);
    total_energy = sum(sigma.^2);

    ranks = [1, 5, 15, 30];
    for k = 1:numel(ranks)
        r = ranks(k);
        A_r = U(:, 1:r) * S(1:r, 1:r) * V(:, 1:r).';
        rel_err_2   = sigma(r + 1) / sigma(1);
        rel_err_fro = norm(A - A_r, 'fro') / norm(A, 'fro');
        energy_kept = sum(sigma(1:r).^2) / total_energy;
        comp_ratio  = r * (m + n + 1) / (m * n);
        fprintf('秩 r = %2d: 压缩比 = %5.2f%%, 能量保留 = %6.2f%%, 相对Fro误差 = %.4e, 相对2范数误差 = %.4e\n', ...
            r, 100*comp_ratio, 100*energy_kept, rel_err_fro, rel_err_2);
    end
end
```

## 三、 主成分分析（PCA）、子空间聚类与 K-means 算法

### 3.1 主成分分析（PCA）数学推导与行列约定辨析

给定高维观测样本，PCA 寻找正交投影轴使投影后样本的方差最大化（等价于重构平方误差最小化）。在调用 `svd` 或 `pca` 时，需严格区分数据矩阵的两种行列约定：
1. **列表示样本、行表示特征指标**（原课件第 20–25 页约定，$X \in \mathbb{R}^{d \times m}$，$d$ 维特征、$m$ 个样本）：
   记样本均值列向量为 $\bar{x} = \frac{1}{m}\sum_{j=1}^m x_j \in \mathbb{R}^{d \times 1}$，中心化矩阵为 $\tilde{X} = X - \bar{x}\mathbf{1}_m^{\mathsf T}$。样本协方差矩阵为：
   $$
   C = \frac{1}{m - 1}\tilde{X}\tilde{X}^{\mathsf T} = \frac{1}{m - 1} U \Sigma^2 U^{\mathsf T} \in \mathbb{R}^{d \times d}.
   $$
   此时主成分方向（主轴基）为 $\tilde{X}$ 的**左奇异向量** $U_{:, 1:r}$，降维坐标为 $G = U_{:, 1:r}^{\mathsf T} \tilde{X} \in \mathbb{R}^{r \times m}$。
2. **行表示样本、列表示特征指标**（MATLAB `pca(X)` 默认约定，$X \in \mathbb{R}^{m \times d}$，$m$ 个样本、$d$ 维特征）：
   对每列减去均值得到 $\tilde{X} = X - \mathbf{1}_m \bar{x}^{\mathsf T}$，样本协方差矩阵为 $C = \frac{1}{m - 1}\tilde{X}^{\mathsf T}\tilde{X} = \frac{1}{m - 1} V \Sigma^2 V^{\mathsf T}$，主成分方向（载荷矩阵 `coeff`）为 $\tilde{X}$ 的**右奇异向量** $V_{:, 1:r}$，主成分得分为 `score` $= \tilde{X} V_{:, 1:r} = U_{:, 1:r}\Sigma_{1:r, 1:r}$。

### 3.2 子空间分组的鸽巢原理条件与 K-means 聚类

- **子空间分组的一般位置条件（第 28 页）**：若数据采样自两个三维线性子空间 $S_1, S_2 \subset \mathbb{R}^d$，由鸽巢原理（抽屉原理），任取 $7$ 个样本必有至少 $4$ 个落在同一个三维子空间内；但要保证这 $4$ 个向量张成整个三维子空间（即矩阵秩等于 $3$），还需附加**一般位置（General Position）假设**，以排除 $4$ 个向量退化共面或共线的特殊情形。
- **K-means 聚类交替最小化**：给定样本集 $\{x_1, \dots, x_m\}$ 与簇数 $K$，K-means 交替执行两步以单调下降簇内平方误差和 $\mathrm{WCSS} = \sum_{k=1}^K \sum_{x_i \in \mathcal{C}_k} \|x_i - \mu_k\|_2^2$：
  1. **簇分配步**：固定质心 $\{\mu_k\}$，将每个样本归入欧氏距离最近的簇 $c_i = \arg\min_k \|x_i - \mu_k\|_2^2$；
  2. **质心更新步**：固定簇划分 $\{\mathcal{C}_k\}$，更新各簇质心为簇内样本算术均值 $\mu_k = \frac{1}{|\mathcal{C}_k|}\sum_{x_i \in \mathcal{C}_k} x_i$。

```matlab
function [coeff, score, explained] = pca_via_svd_demo(X)
% PCA_VIA_SVD_DEMO 使用经济型 SVD 实现标准 PCA (行表示样本 m x d)
    [m, ~] = size(X);
    X_centered = X - mean(X, 1);
    [U, S, V] = svd(X_centered, 'econ');
    coeff = V;                              % 主成分载荷方向 (右奇异向量)
    score = U * S;                          % 主成分投影得分 X_centered * V
    latent = diag(S).^2 / (m - 1);          % 协方差矩阵特征值（各主成分方差）
    explained = 100 * latent / sum(latent); % 方差贡献率 (%)
end
```

## 四、 梯度下降法与牛顿法优化轨迹对比

在机器学习与统计估计中，无约束优化问题 $\min_{x \in \mathbb{R}^d} f(x)$ 的两类核心一阶与二阶算法对比如下：
1. **梯度下降法（Gradient Descent, GD）**：仅利用一阶梯度信息 $x_{k+1} = x_k - \alpha \nabla f(x_k)$。在病态曲率区域（Hessian 矩阵条件数 $\kappa(\nabla^2 f) \gg 1$），负梯度方向垂直于等高线但不指向极小点，导致轨迹呈剧烈锯齿状缓慢推进，具有**局部线性收敛率**。
2. **牛顿法（Newton's Method）**：利用二阶 Taylor 近似的局部曲率（Hessian 矩阵 $H_k = \nabla^2 f(x_k)$）对梯度作仿射白化校正：

$$
x_{k+1} = x_k - \bigl[\nabla^2 f(x_k)\bigr]^{-1} \nabla f(x_k) = x_k - H_k \backslash g_k.
$$

对正定二次函数，牛顿法**一步直达全局极小点**；对一般强凸 $C^3$ 目标函数，在极小点邻域内具有与坐标缩放无关的**局部二阶（平方）收敛率** $\|x_{k+1} - x^*\| = O(\|x_k - x^*\|^2)$。

```matlab
function gd_vs_newton_demo()
% GD_VS_NEWTON_DEMO 对比梯度下降法与牛顿法在非二次强凸函数上的优化轨迹
    % 目标函数: f(x1, x2) = 0.5*(x1^2 + 10*x2^2) + 0.1*(x1^4 + x2^4) - x1 - 2*x2
    f    = @(x) 0.5*(x(1)^2 + 10*x(2)^2) + 0.1*(x(1)^4 + x(2)^4) - x(1) - 2*x(2); %#ok<NASGU>
    grad = @(x) [x(1) + 0.4*x(1)^3 - 1; 10*x(2) + 0.4*x(2)^3 - 2];
    hess = @(x) [1 + 1.2*x(1)^2, 0; 0, 10 + 1.2*x(2)^2];

    x0 = [-2.5; 2.0];
    alpha = 0.12;

    % 1. 固定步长梯度下降法
    x_gd = x0; traj_gd = x0;
    for k = 1:60
        g = grad(x_gd);
        if norm(g) < 1e-10, break; end
        x_gd = x_gd - alpha * g;
        traj_gd = [traj_gd, x_gd]; %#ok<AGROW>
    end

    % 2. 二阶牛顿法
    x_nt = x0; traj_nt = x0;
    for k = 1:20
        g = grad(x_nt);
        if norm(g) < 1e-10, break; end
        x_nt = x_nt - hess(x_nt) \ g;
        traj_nt = [traj_nt, x_nt]; %#ok<AGROW>
    end

    fprintf('梯度下降步数 = %2d, 终端梯度范数 = %.2e\n', size(traj_gd, 2)-1, norm(grad(x_gd)));
    fprintf('牛顿法步数   = %2d, 终端梯度范数 = %.2e\n', size(traj_nt, 2)-1, norm(grad(x_nt)));
end
```

## 五、 离散时间 Markov 链平稳分布与 PageRank 算法

### 5.1 随机矩阵、Perron-Frobenius 定理与平稳分布

设有限状态空间 $\{1, 2, \dots, n\}$ 上的齐次 Markov 链一步转移概率矩阵为 $P = (p_{ij}) \in \mathbb{R}^{n \times n}$（若采用**列随机矩阵**约定，即 $p_{ij} = P(X_{t+1} = i \mid X_t = j) \ge 0$ 且每列元素之和 $\sum_{i=1}^n p_{ij} = 1$，状态分布列向量演化满足 $\pi^{(t+1)} = P \pi^{(t)}$；若采用行随机矩阵约定，则行向量演化满足 $\pi^{(t+1)} = \pi^{(t)} P$）。

由 **Perron-Frobenius 定理**：当转移矩阵 $P$ 不可约且非周期（或正矩阵 $P > 0$）时，最大特征值 $\lambda_1 = 1$ 是代数单根，其余特征值严格满足 $|\lambda_k| < 1 \, (k \ge 2)$，且存在唯一的正概率分布向量 $\pi^* > 0$（满足 $\sum_{i=1}^n \pi_i^* = 1$）使得：

$$
P \pi^* = \pi^*, \qquad \lim_{t \to \infty} P^t \pi^{(0)} = \pi^*.
$$

### 5.2 Google PageRank 阻尼转移矩阵与幂法求解

在有向网页图 $G = (V, E)$ 中，若节点 $j$ 出度 $d_j > 0$，则以 $1/d_j$ 概率跳转至各出边邻点；若 $j$ 为无出边的悬挂节点（Dangling Node，$d_j = 0$），则以均匀概率 $1/n$ 跳转至任意节点，构成列随机矩阵 $P$。为保证全图不可约与非周期性，引入阻尼因子（Teleportation Factor）$\alpha \in (0, 1)$（通常取 $\alpha = 0.85$），构造 Google 矩阵：

$$
G = \alpha P + (1 - \alpha) \frac{1}{n} \mathbf{1}_n \mathbf{1}_n^{\mathsf T}.
$$

由于 $G > 0$ 为严格正列随机矩阵，其第二大特征值模满足 $|\lambda_2(G)| \le \alpha < 1$。使用**幂法（Power Iteration）**求解时，无需显式构造稠密矩阵 $G$，只需在每步执行稀疏矩阵-向量乘积与标量偏置补偿：

$$
\pi^{(k+1)} = \alpha P \pi^{(k)} + \frac{1 - \alpha}{n} \mathbf{1}_n \quad (\text{因 } \mathbf{1}_n^{\mathsf T}\pi^{(k)} = 1),
$$

收敛率由 $\alpha^k = 0.85^k$ 严格保证。

```matlab
function [pi_power, pi_exact] = pagerank_demo()
% PAGERANK_DEMO 演示 Markov 链平稳分布与 Google PageRank 幂法迭代
    % 构造 5 节点有向图的邻接矩阵 A_adj (A_adj(i, j) = 1 表示存在 j -> i 的有向链接)
    A_adj = [0, 1, 1, 0, 0;
             1, 0, 0, 1, 0;
             1, 1, 0, 1, 1;
             0, 0, 1, 0, 1;
             0, 0, 0, 1, 0];
    n = size(A_adj, 1);
    out_deg = sum(A_adj, 1);

    % 构造列随机转移矩阵 P (处理潜在悬挂列)
    P = zeros(n, n);
    for j = 1:n
        if out_deg(j) > 0
            P(:, j) = A_adj(:, j) / out_deg(j);
        else
            P(:, j) = 1 / n;
        end
    end

    alpha = 0.85;
    G = alpha * P + (1 - alpha) * (ones(n, n) / n);

    % 1. 幂法 (Power Method) 迭代求解 PageRank 向量
    pi_power = ones(n, 1) / n;
    for k = 1:200
        pi_next = alpha * (P * pi_power) + (1 - alpha) / n;
        if norm(pi_next - pi_power, 1) < 1e-12
            pi_power = pi_next;
            break;
        end
        pi_power = pi_next;
    end

    % 2. 线性方程组直接求解 (I - G)*pi = 0, sum(pi) = 1
    M_sys = [eye(n) - G; ones(1, n)];
    rhs   = [zeros(n, 1); 1];
    pi_exact = M_sys \ rhs;

    fprintf('PageRank 幂法与直接法 L1 误差 = %.2e\n', norm(pi_power - pi_exact, 1));
    disp(table((1:n).', pi_power, 'VariableNames', {'Node', 'PageRank_Score'}));
end
```
