# 第七周微分方程数值解法：动力系统相图、刚性与边值问题

来源：第七周常微分方程数值解法参考资料包，对应 [[MATLAB/课程讲义/07_MATLAB微分方程数值解法|第七课：MATLAB 微分方程数值解法]]。本文完整梳理显式/隐式单步法体系、Lotka-Volterra 捕食者-猎物生态相图与显式 Euler 守恒量漂移分析、Van der Pol 极限环与刚性弛豫振荡求解器对比，以及两点边值问题（BVP）的打靶法、有限差分法与 `bvp4c`/`bvp5c` 误差控制机制。

## 一、 显式与隐式单步法体系及 MATLAB 求解器选型

### 1.1 经典单步法公式与稳定性对比

针对初值问题 $\frac{dy}{dt} = f(t, y), \, y(t_0) = y_0$：
1. **显式 Euler 法**：$y_{n+1} = y_n + h f(t_n, y_n)$，一步局部截断误差 $O(h^2)$，全局精度一阶 $O(h)$，绝对稳定域为 $|1 + h\lambda| < 1$（条件稳定）。
2. **隐式（向后）Euler 法**：$y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})$，全局精度一阶 $O(h)$，放大因子 $G(z) = \frac{1}{1 - z}$ 的稳定域包含整个左半复平面 $\operatorname{Re}(z) < 0$（具备 $A$-稳定性与 $\lim_{\operatorname{Re}z \to -\infty}|G(z)| = 0$ 的 $L$-稳定性），适合求解快慢时间尺度悬殊的刚性微分方程（Stiff ODEs）。
3. **经典四阶 Runge-Kutta 法（RK4）**：

$$
\begin{aligned}
k_1 &= f(t_n, y_n), \\
k_2 &= f\!\left(t_n + \frac{h}{2}, \, y_n + \frac{h}{2}k_1\right), \\
k_3 &= f\!\left(t_n + \frac{h}{2}, \, y_n + \frac{h}{2}k_2\right), \\
k_4 &= f(t_n + h, \, y_n + h k_3), \\
y_{n+1} &= y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4).
\end{aligned}
$$

RK4 每步计算 4 次右端函数值，一步局部截断误差为 $O(h^5)$，全局累积误差为四阶 $O(h^4)$。

### 1.2 MATLAB 常微分方程初值求解器选型指南

| 求解器 | 数学方法与阶数 | 适用问题类型 |
| :--- | :--- | :--- |
| `ode45` | 显式 Dormand-Prince (4,5) 阶嵌入式 Runge-Kutta | 大多数非刚性（Nonstiff）初值问题的首选求解器 |
| `ode23` | 显式 Bogacki-Shampine (2,3) 阶 Runge-Kutta | 容差要求宽松或存在轻度刚性的问题 |
| `ode113` | 变阶 Adams-Bashforth-Moulton 线性多步法（1–13 阶） | 右端函数计算开销极大或要求极高精度容差的非刚性问题 |
| `ode15s` | 基于数值微分公式（NDF/BDF，1–5 阶）的隐式多步法 | 刚性微分方程（Stiff ODEs）及指标 1 微分代数方程（DAEs） |
| `ode23s` | 2 阶修正 Rosenbrock 单步隐式法 | 低精度要求下的强刚性问题 |

## 二、 Lotka-Volterra 捕食者-猎物相图与显式 Euler 守恒量漂移分析

### 2.1 数学模型与首次积分（守恒量）推导

设猎物（Prey）种群密度为 $x(t) > 0$，捕食者（Predator）种群密度为 $y(t) > 0$，经典的 Lotka-Volterra 生态动力系统为（参数 $\alpha, \beta, \gamma, \delta > 0$）：

$$
\begin{cases}
\dfrac{dx}{dt} = x(\alpha - \beta y), \\[6pt]
\dfrac{dy}{dt} = y(-\gamma + \delta x).
\end{cases}
$$

系统在第一象限内存在唯一的非平凡共存平衡点 $(x^*, y^*) = \left(\frac{\gamma}{\delta}, \, \frac{\alpha}{\beta}\right)$。消去时间 $t$ 分离变量：

$$
\left(\delta - \frac{\gamma}{x}\right)dx + \left(\beta - \frac{\alpha}{y}\right)dy = 0.
$$

积分即得系统在第一象限内的严格守恒量（首次积分 / 类哈密顿对数能量函数）：

$$
V(x, y) = \delta x - \gamma \ln x + \beta y - \alpha \ln y = \text{const}.
$$

由于 $V(x, y)$ 为严格凸函数（$\nabla^2 V = \operatorname{diag}(\gamma/x^2, \, \alpha/y^2) > 0$）且在平衡点 $(x^*, y^*)$ 达到全局唯一极小值，其等值线 $V(x, y) = C > V(x^*, y^*)$ 是一族围绕 $(x^*, y^*)$ 的**封闭周期轨线**。

### 2.2 显式 Euler 法的非物理螺旋发散机制

对任意可微守恒函数 $V(x, y)$（沿精确轨线满足 $\nabla V(u)^{\mathsf T} f(u) \equiv 0$），考察显式 Euler 步 $u_{n+1} = u_n + h f(u_n)$ 一步后的能量变化。由二阶 Taylor 展开：

$$
V(u_{n+1}) = V(u_n) + h \underbrace{\nabla V(u_n)^{\mathsf T} f(u_n)}_{= 0} + \frac{h^2}{2} f(u_n)^{\mathsf T} \nabla^2 V(\xi_n) f(u_n).
$$

在 Lotka-Volterra 系统的第一象限内，由于 Hessian 矩阵 $\nabla^2 V = \operatorname{diag}(\gamma/x^2, \, \alpha/y^2)$ **处处严格正定**，只要不在平衡点（$f(u_n) \neq 0$），二阶余项恒严格为正：

$$
V(x_{n+1}, y_{n+1}) - V(x_n, y_n) = \frac{h^2}{2}\left[\frac{\gamma}{\xi_x^2}x_n^2(\alpha - \beta y_n)^2 + \frac{\alpha}{\xi_y^2}y_n^2(\delta x_n - \gamma)^2\right] > 0.
$$

这从数学上严格证明了：在 Lotka-Volterra 模型中，**只要步长 $h > 0$ 足够小使得单步更新点 $x_{n+1} = x_n(1 + h(\alpha - \beta y_n)) > 0,\, y_{n+1} = y_n(1 + h(\delta x_n - \gamma)) > 0$ 仍留在正象限 $\mathbb{R}_+^2$ 内**（从而连接 $u_n$ 与 $u_{n+1}$ 的线段 $\xi_n \in \mathbb{R}_+^2$ 落在对数守恒量 $V(x,y)$ 的严格凸定义域内；若 $h$ 过大则一步就可能直接跨出正象限导致种群出现非物理负值），**显式 Euler 法在每一步都会使守恒量 $V(x, y)$ 严格单调递增**，导致数值相轨迹向外呈螺旋状不断发散膨胀！
- **高阶 RK 方法与辛格式的长期行为辨析**：改用改进 Euler 法或高阶显式 Runge-Kutta 法（如 `ode45` 配合小容差）可将单步能量漂移压低至 $O(h^3)$ 或 $O(h^5)$，从而在**有限个周期 $[0, T]$** 内使数值相图在视觉上几乎闭合，但由于它们并非保结构积分器，在极长积分时间 $T \to \infty$ 下仍存在微弱的长期能量漂移与相位误差（phase error）；而若在对数坐标 $(p, q) = (\ln x, \ln y)$ 的可分哈密顿形式下改用**辛分块 Euler 格式（Symplectic Euler）**，当**固定步长 $h > 0$ 足够小且数值轨线保持在远离边界奇点的有界紧集内**时，由几何数值积分的**后向误差分析（Backward Error Analysis，参见 [Gauckler--Hairer--Lubich §2.3–2.4](https://www.unige.ch/~hairer/preprints/icm.pdf)）**可知，数值解在指数级长时间尺度上近似保持截断修正哈密顿量，从而使原守恒量 $V(x_n, y_n)$ 在长时间内围绕初始值做有界小幅振荡（近守恒，而非一般意义上存在精确闭式影子不变量或在任意步长/无界时间下无条件守恒）。

```matlab
function lotka_volterra_phase_demo()
% LOTKA_VOLTERRA_PHASE_DEMO 对比显式 Euler 发散轨线与 ode45 闭合相图
    alpha = 1.0; beta = 0.5; gamma = 0.75; delta = 0.25;
    lv_rhs = @(t, u) [u(1)*(alpha - beta*u(2)); u(2)*(-gamma + delta*u(1))];
    V_func = @(x, y) delta*x - gamma*log(x) + beta*y - alpha*log(y);

    u0 = [2.0; 1.5];
    T_end = 30; h = 0.02; N = round(T_end / h);

    % 1. 显式 Euler 步进
    U_eu = zeros(2, N + 1); U_eu(:, 1) = u0;
    for k = 1:N
        U_eu(:, k+1) = U_eu(:, k) + h * lv_rhs(0, U_eu(:, k));
    end

    % 2. 高精度 ode45 求解
    opts = odeset('RelTol', 1e-9, 'AbsTol', 1e-12);
    [~, U_45] = ode45(lv_rhs, [0, T_end], u0, opts);

    V0 = V_func(u0(1), u0(2));
    fprintf('显式 Euler 末态守恒量漂移 dV = +%.4f, ode45 守恒量漂移 dV = %.2e\n', ...
        V_func(U_eu(1,end), U_eu(2,end)) - V0, V_func(U_45(end,1), U_45(end,2)) - V0);
end
```

## 三、 Van der Pol 极限环振荡器与刚性问题（Stiff ODEs）对比

考察 Van der Pol 自激振荡方程 $y'' - \mu(1 - y^2)y' + y = 0$（降阶为 $u_1' = u_2, \, u_2' = \mu(1 - u_1^2)u_2 - u_1$）：
1. **非刚性情形（如 $\mu = 1$ 或 $\mu = 2$）**：原点 $(0, 0)$ 为不稳定源点，当 $|y| < 1$ 时阻尼为负（系统注入能量），当 $|y| > 1$ 时阻尼为正（系统耗散能量），根据 Liénard 定理，相平面上存在**唯一稳定的孤立闭轨（极限环 / Limit Cycle）**，`ode45` 可高效求解。
2. **强刚性弛豫振荡情形（$\mu \gg 1$，如 $\mu = 1000$）**：解交替经历极缓慢的准静态爬升阶段与时间尺度为 $O(\mu^{-1})$ 的极陡峭跳跃层（快慢时间尺度相差 $10^6$ 倍）。此时显式求解器 `ode45` 受绝对稳定域步长限制 $h = O(\mu^{-1})$ 制约，需要数十万步才能走完一个周期；而隐式刚性求解器 `ode15s`（基于 $A(\alpha)$-稳定的数值微分公式 NDF）在慢流形上可自动放大步长，仅需数百步即完成求解。

```matlab
function vdp_stiff_comparison()
% VDP_STIFF_COMPARISON 对比强刚性 Van der Pol 方程 (mu = 500) 下 ode45 与 ode15s 的步数
    mu = 500;
    vdp = @(t, u) [u(2); mu * (1 - u(1)^2) * u(2) - u(1)];
    tspan = [0, 1000]; u0 = [2; 0];

    tic; [t45, ~]  = ode45(vdp, tspan, u0);  time45  = toc;
    tic; [t15s, ~] = ode15s(vdp, tspan, u0); time15s = toc;
    fprintf('mu = %d: ode45 步数 = %6d (耗时 %.3fs), ode15s 步数 = %4d (耗时 %.3fs)\n', ...
        mu, numel(t45), time45, numel(t15s), time15s);
end
```

## 四、 两点边值问题（BVP）：打靶法、有限差分法与 `bvp4c` / `bvp5c`

针对二阶两点边值问题（Boundary Value Problem）：

$$
y'' = f(x, y, y'), \quad a < x < b, \qquad y(a) = \alpha, \quad y(b) = \beta.
$$

### 4.1 打靶法（Shooting Method）
将未知左端点初始斜率设为待定靶角参数 $s = y'(a)$，求解对应的初值问题：

$$
\begin{cases}
u_1' = u_2, & u_1(a) = \alpha, \\
u_2' = f(x, u_1, u_2), & u_2(a) = s,
\end{cases}
$$

记数值积分到达右端点 $x = b$ 时的位置为 $u_1(b; s)$。利用非线性求根器 `fzero` 求解标量残差方程 $F(s) = u_1(b; s) - \beta = 0$，即得满足右边界条件的精确初始斜率 $s^*$。

### 4.2 有限差分法（Finite Difference Method, FDM）
将 $[a, b]$ 等分为 $N$ 段，步长 $h = \frac{b-a}{N}$，内部节点为 $x_i = a + ih \, (i = 1, \dots, N-1)$。用二阶中心差商离散导数：

$$
y''(x_i) \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}, \qquad y'(x_i) \approx \frac{y_{i+1} - y_{i-1}}{2h}.
$$

对线性边值问题 $-y'' + p(x)y' + q(x)y = r(x)$，代入上述差商并移入边界值 $y_0 = \alpha, \, y_N = \beta$，直接化为 $(N-1) \times (N-1)$ **三对角线性方程组** $T \mathbf{y} = \mathbf{d}$，全局截断误差为 $O(h^2)$。

### 4.3 内建配置法求解器 `bvp4c` 与 `bvp5c` 的阶数及误差控制量辨析

MATLAB 提供两个基于 Lobatto IIIa 隐式 Runge-Kutta 配置法（Collocation Method）的边值问题求解器，二者的**精度阶数与误差控制目标量**存在本质区别（参见 [MathWorks Boundary Value Problems 官方文档](https://www.mathworks.com/help/matlab/math/boundary-value-problems.html)）：
1. **`bvp4c`（四阶 Lobatto IIIa 公式，控制缩减残差）**：在每个子区间上用 $C^1$ 分段三次多项式 $S(x)$ 逼近解，全局精度为 $O(h^4)$。`bvp4c` 通过自适应加密网格来**控制连续数值解的缩减残差（Scaled Residual）** $\|S'(x) - f(x, S(x))\|$，利用残差大小间接控制真误差。
2. **`bvp5c`（五阶四级 Lobatto IIIa 公式，直接控制真误差）**：全局精度为 $O(h^5)$。与 `bvp4c` 仅控制残差不同，`bvp5c` 同时估计并**直接控制真实代数误差（True Error）** $\|y(x) - S(x)\|$（在条件良态问题上残差与真误差渐近等价，但在病态或奇异摄动边值问题上两者可能显著不同）。
3. **误差评估边界**：无论 `bvp4c` 还是 `bvp5c`，其容差控制均基于局部渐近展开的启发式估计，**不能将设定的 `RelTol`/`AbsTol` 直接视为严格数学定理意义下的误差上界证书**。

```matlab
function bvp_methods_comparison()
% BVP_METHODS_COMPARISON 对比打靶法、三对角有限差分法与 bvp4c
%   求解边值问题: y'' - 4*y = 0, x in [0, 1], y(0) = 1, y(1) = exp(2) (精确解 y = exp(2*x))
    a = 0; b = 1; ya = 1; yb = exp(2);
    y_exact = @(x) exp(2 * x);

    % 1. 打靶法 (ode45 + fzero)
    ode_rhs = @(x, u) [u(2); 4 * u(1)];
    shoot_res = @(s) get_end_val(ode_rhs, a, b, [ya; s]) - yb;
    s_opt = fzero(shoot_res, 2.0);
    [x_shoot, U_shoot] = ode45(ode_rhs, linspace(a, b, 101), [ya; s_opt]);

    % 2. 二阶中心有限差分法 (三对角矩阵求解)
    N = 100; h = (b - a) / N;
    x_fdm = linspace(a, b, N + 1).';
    e = ones(N - 1, 1);
    A_tri = spdiags([e, -(2 + 4*h^2)*e, e], -1:1, N - 1, N - 1);
    rhs_fdm = zeros(N - 1, 1);
    rhs_fdm(1) = -ya; rhs_fdm(end) = -yb;
    y_inner = A_tri \ rhs_fdm;
    y_fdm = [ya; y_inner; yb];

    % 3. bvp4c 配置法求解
    solinit = bvpinit(linspace(a, b, 20), [1; 2]);
    sol4c = bvp4c(ode_rhs, @(ua, ub) [ua(1) - ya; ub(1) - yb], solinit);
    y_bvp4c = deval(sol4c, x_fdm, 1).';

    fprintf('最大绝对误差: 打靶法 = %.2e, 有限差分法(N=100) = %.2e, bvp4c = %.2e\n', ...
        max(abs(U_shoot(:,1) - y_exact(x_shoot))), ...
        max(abs(y_fdm - y_exact(x_fdm))), ...
        max(abs(y_bvp4c - y_exact(x_fdm))));
end

function val = get_end_val(ode_rhs, a, b, u0)
    opts = odeset('RelTol', 1e-10, 'AbsTol', 1e-12);
    [~, U] = ode45(ode_rhs, [a, b], u0, opts);
    val = U(end, 1);
end
```
