## 一、 第 1 题：最大公约数（GCD）与最小公倍数（LCM）程序设计

### 1.1 Euclid 辗转相除法与复杂度分析
对非负整数 $a, b \in \mathbb{Z}_{\ge 0}$（不全为零），由带余除法 $a = q b + r \, (0 \le r < b)$ 有 $\gcd(a, b) = \gcd(b, a \bmod b)$。由 Lamé 定理，欧几里得辗转相除法的取模步数不超过较小数十进制位数的 $5$ 倍，时间复杂度为 $O(\log(\min(a, b)))$。

求得 $g = \gcd(a, b)$ 后，最小公倍数满足恒等式 $a \cdot b = \gcd(a, b) \cdot \operatorname{lcm}(a, b)$。为防止大整数直接相乘 $a \cdot b$ 超出双精度精确整数上限 `flintmax`（$2^{53} \approx 9.007 \times 10^{15}$），在代码中应遵循**先整除后相乘**原则：

$$
\operatorname{lcm}(a, b) = \left(\frac{|a|}{\gcd(a, b)}\right) \cdot |b|.
$$

```matlab
function [g, l] = gcd_lcm_custom(a, b)
% GCD_LCM_CUSTOM 辗转相除法计算最大公约数与防溢出最小公倍数
    a = abs(round(a));
    b = abs(round(b));
    x = a; y = b;
    while y ~= 0
        r = mod(x, y);
        x = y;
        y = r;
    end
    g = x;
    if g == 0
        l = 0;
    else
        l = (a / g) * b; % 先除后乘，规避 a*b 中间结果溢出
    end
end
```

（MATLAB 内建函数 `gcd(A, B)` 与 `lcm(A, B)` 支持同尺寸整数数组的逐元素向量化计算。）

## 二、 第 2 题：试除法、Eratosthenes 素数筛法与素数红包枚举

### 2.1 单数试除法与 Eratosthenes 筛法
- **单数试除法**：若整数 $n > 1$ 为合数，则必存在非平凡素因子 $d$ 满足 $2 \le d \le \lfloor\sqrt{n}\rfloor$。检验单个整数的时间复杂度为 $O(\sqrt{n})$。
- **Eratosthenes 筛法（Sieve of Eratosthenes）**：批量生成 $[2, N]$ 内全部素数时，维护长度为 $N$ 的逻辑数组 `is_p = true(1, N)`（并将 `is_p(1) = false`）。对 $p = 2, 3, \dots, \lfloor\sqrt{N}\rfloor$，若 `is_p(p)` 为真，则从 $p^2$ 开始将其倍数 `p^2 : p : N` 批量置为 `false`（小于 $p^2$ 的合数倍数必已被更小的素因子筛去）。由 Mertens 定理 $\sum_{p \le N} \frac{1}{p} = \ln\ln N + O(1)$，总时间复杂度为 $O(N \log \log N)$。

### 2.2 十进制数字拼接与“素数红包”枚举
在“日期/数字素数红包”问题中，枚举满足特定十进制数位格式（如固定前缀或后缀，或在通配位填入 `00`–`99`）的素数时，直接利用十进制位权公式（如 $N = 10^k \cdot A + B$）构造候选整数数组并调用内建 `isprime`（或预生成的素数逻辑表）进行向量化筛选，比逐个转换为字符串拼接再调 `str2double` 效率高出数个数量级：

```matlab
function [primes_up_to_N, lucky_primes] = prime_sieve_and_redpacket(N)
% PRIME_SIEVE_AND_REDPACKET Eratosthenes 筛法与日期素数红包枚举
    is_p = true(1, N);
    is_p(1) = false;
    for p = 2:floor(sqrt(N))
        if is_p(p)
            is_p(p^2 : p : N) = false;
        end
    end
    primes_up_to_N = find(is_p);

    % 示例：在 202611XX (后两位 01~99) 中利用十进制位权向量化筛选全部素数
    candidates = 202611 * 100 + (1:99);
    lucky_primes = candidates(isprime(candidates));
end
```

## 三、 第 3 题：复平面 Newton 迭代分形吸引域（Newton Fractal）

### 3.1 数学原理与复向量化迭代
在复平面 $\mathbb{C}$ 上用 Newton-Raphson 法求解多项式方程 $f(z) = z^3 - 1 = 0$，其三个精确三次单位根为：

$$
\omega_1 = 1, \qquad \omega_2 = e^{2\pi i / 3} = -\frac{1}{2} + \frac{\sqrt{3}}{2}i, \qquad \omega_3 = e^{4\pi i / 3} = -\frac{1}{2} - \frac{\sqrt{3}}{2}i.
$$

Newton 迭代映射为：

$$
z_{k+1} = z_k - \frac{z_k^3 - 1}{3 z_k^2} = \frac{2 z_k^3 + 1}{3 z_k^2}.
$$

每个单位根 $\omega_j$ 的吸引域（Basin of Attraction）$B(\omega_j) = \{z_0 \in \mathbb{C} : \lim_{k\to\infty} z_k = \omega_j\}$ 之间的公共边界构成具有无穷自相似结构的 Julia 分形集（边界上任意一点的任意小邻域同时包含全部三个根的吸引域）。

```matlab
function newton_fractal_demo()
% NEWTON_FRACTAL_DEMO 复平面 z^3 - 1 = 0 的 Newton 迭代分形吸引域向量化绘制
    grid_n = 500;
    x = linspace(-1.5, 1.5, grid_n);
    y = linspace(-1.5, 1.5, grid_n);
    [X, Y] = meshgrid(x, y);
    Z = X + 1i * Y;

    % 预置极小偏移避免原点 z = 0 处除零
    Z(abs(Z) < eps) = eps;

    for iter = 1:35
        Z = (2 * Z.^3 + 1) ./ (3 * Z.^2);
    end

    roots_exact = [1, exp(2i*pi/3), exp(4i*pi/3)];
    basin_id = zeros(size(Z));
    for r = 1:3
        mask = abs(Z - roots_exact(r)) < 1e-3;
        basin_id(mask) = r;
    end

    figure;
    imagesc(x, y, basin_id);
    axis equal tight xy;
    colormap([0.1 0.1 0.1; 0.85 0.25 0.25; 0.25 0.70 0.35; 0.25 0.45 0.85]);
    xlabel('Re(z)'); ylabel('Im(z)');
    title('z^3 - 1 = 0 的复平面 Newton 迭代分形吸引域');
end
```

## 四、 第 4 题：二维随机游走（2D Random Walk）模拟与均方位移验证

### 4.1 数学模型與无循环 `cumsum` 实现
设粒子从原点 $\mathbf{R}_0 = (0, 0)$ 出发，每步独立等概率沿四个坐标轴方向 $\{(1,0), (-1,0), (0,1), (0,-1)\}$（或单位圆周连续随机方向 $\theta_k \sim U[0, 2\pi)$）移动步长 $1$。记第 $k$ 步位移增量为 $\Delta \mathbf{R}_k = (\Delta X_k, \Delta Y_k)$，则第 $N$ 步位置为部分和 $\mathbf{R}_N = \sum_{k=1}^N \Delta \mathbf{R}_k$。

由独立增量性质与 $\mathbb{E}[\Delta \mathbf{R}_k] = \mathbf{0}$、$\mathbb{E}[\|\Delta \mathbf{R}_k\|_2^2] = 1$，经过 $N$ 步后的理论均方位移（Mean Squared Displacement, MSD）严格满足扩散线性律：

$$
\mathbb{E}\bigl[\|\mathbf{R}_N\|_2^2\bigr] = \sum_{k=1}^N \mathbb{E}\bigl[\|\Delta \mathbf{R}_k\|_2^2\bigr] + 2\sum_{1 \le j < k \le N} \mathbb{E}[\Delta \mathbf{R}_j]^{\mathsf T}\mathbb{E}[\Delta \mathbf{R}_k] = N, \qquad \sqrt{\mathbb{E}\bigl[\|\mathbf{R}_N\|_2^2\bigr]} = \sqrt{N}.
$$

```matlab
function random_walk_2d_demo()
% RANDOM_WALK_2D_DEMO 二维格点随机游走向量化模拟与均方位移 E[R_N^2] = N 验证
    rng(2026);
    N_steps = 1000;
    M_paths = 5000;

    % 随机抽取 4 个方向: 1->(1,0), 2->(-1,0), 3->(0,1), 4->(0,-1)
    dirs = randi(4, N_steps, M_paths);
    dx = (dirs == 1) - (dirs == 2);
    dy = (dirs == 3) - (dirs == 4);

    X = [zeros(1, M_paths); cumsum(dx, 1)];
    Y = [zeros(1, M_paths); cumsum(dy, 1)];
    msd = mean(X.^2 + Y.^2, 2);

    fprintf('N = %d 步时样本均方位移 MSD = %.2f (理论精确值 = %d)\n', ...
        N_steps, msd(end), N_steps);
end
```

## 五、 第 5 题：连通道路网最小生成树（MST）与新增路口（Steiner 点）寻优

### 5.1 连通道路网的最小生成树（MST）算法
给定平面上 $n = 100$ 个点的坐标 $(x_i, y_i)$，以欧氏距离 $d_{ij} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$ 为边权构造完全无向图 $K_n$，要求使所有节点连通且道路总长度最短。在不引入额外新路口的前提下，该问题即为经典的**最小生成树（Minimum Spanning Tree, MST）**问题：

1. **Prim 算法（加点法）**：从任一顶点出发，维护已入选顶点集 $S$ 及树外顶点到 $S$ 的最短距离向量 `lowcost`，每步贪心并入距离最小的树外顶点并松弛更新邻接距离。对稠密图（$E = O(V^2)$）不使用堆时的时间复杂度为 $O(V^2)$，非常适合平面欧氏完全图。
2. **Kruskal 算法（加边法）**：将所有边按权值升序排序，借助并查集（Disjoint Set Union）依次加入不构成环路的轻边，直到选满 $V - 1$ 条边。时间复杂度为 $O(E \log E)$。
3. **MATLAB 内建实现**：构造邻接距离矩阵 `D` 后，调用 `G = graph(D); T = minspantree(G); total_len = sum(T.Edges.Weight);` 即可精确求得最小生成树总长。

### 5.2 新增路口优化（Fermat-Weber 点与 Steiner 树）
若允许在平面上新增一个或多个中转路口 $P(x, y)$ 以进一步缩短连通总长度（即 **Euclidean Steiner Minimal Tree** 问题的单点简化情形）：
- 对固定的新增点坐标 $P(x, y)$，将其作为第 $n + 1$ 个顶点加入点集，重新计算 $(n + 1)$ 个顶点的最小生成树总权值 $L(x, y) = \operatorname{MST}(V \cup \{P(x, y)\})$。
- 由于生成树拓扑结构（边连接关系）随 $P(x, y)$ 移动会发生离散切换，目标函数 $L(x, y)$ 是分段光滑但整体非凸、存在多个局部极小值的连续函数。
- **求解策略**：先在坐标包围盒内采用二维粗网格搜索（Grid Search）定位若干低值候选盆地，再以各候选点为初值调用 `fminsearch`（或模拟退火算法）做局部精细寻优。在最优 Steiner 点处，若该点连接三个邻点，由局部一阶最优性条件（Fermat-Torricelli 点性质）知三条连线两两夹角必为 $120^\circ$。

```matlab
function [mst_base_len, mst_opt_len, p_best] = mst_and_steiner_demo(coords)
% MST_AND_STEINER_DEMO 平面点集最小生成树 (Prim) 与新增单 Steiner 路口优化
%   coords: n x 2 节点坐标矩阵 [x, y]
    n = size(coords, 1);
    D = hypot(coords(:,1) - coords(:,1).', coords(:,2) - coords(:,2).');
    T_base = minspantree(graph(D));
    mst_base_len = sum(T_base.Edges.Weight);

    % 定义加入新路口 p = [x, y] 后的 (n+1) 节点 MST 总长度目标函数
    mst_with_point = @(p) sum(minspantree(graph( ...
        hypot([coords(:,1); p(1)] - [coords(:,1); p(1)].', ...
              [coords(:,2); p(2)] - [coords(:,2); p(2)].'))).Edges.Weight);

    % 以样本质心为初值调用 fminsearch 局部寻优（实际应用中配合多起点粗网格搜索）
    p0 = mean(coords, 1);
    [p_best, mst_opt_len] = fminsearch(mst_with_point, p0);
    if mst_opt_len >= mst_base_len
        mst_opt_len = mst_base_len;
        p_best = [NaN, NaN];
    end
end
```
