## 一、 原参考作业四题逐题核对与精确参照（`第六周参考作业.pdf`）

### 1.1 参考题 Q1：有限区间 $[-5\pi, 10\pi]$ 上振荡衰减积分 $\int_{-5\pi}^{10\pi} e^{-|x|}|\sin x|\,dx$ 的精确参照与容差分析

原参考题第 1 题考察有限区间 $[-5\pi, 10\pi]$ 上的非光滑振荡衰减定积分：

$$
I = \int_{-5\pi}^{10\pi} e^{-|x|}|\sin x|\,dx = \int_0^{5\pi} e^{-x}|\sin x|\,dx + \int_0^{10\pi} e^{-x}|\sin x|\,dx.
$$

- **有限等比级数精确解析参照**：记公比 $q = e^{-\pi}$。在每个半周期 $[k\pi, (k+1)\pi]\ (k \ge 0)$ 上，由变量代换 $x = k\pi + t\ (t \in [0, \pi])$ 及 $\int_0^\pi e^{-t}\sin t\,dt = \frac{1+e^{-\pi}}{2} = \frac{1+q}{2}$，有 $\int_{k\pi}^{(k+1)\pi} e^{-x}|\sin x|\,dx = \frac{1+q}{2} q^k$。因此，在 $[-5\pi, 0]$（共 $5$ 个半周期）与 $[0, 10\pi]$（共 $10$ 个半周期）上分别对有限等比级数求和，立得原积分的精确闭式解：
  $$
  I_{\text{exact}} = \frac{1 + q}{2}\left(\sum_{k=0}^{4} q^k + \sum_{k=0}^{9} q^k\right) = \frac{1 + q}{2(1 - q)}\bigl(2 - q^5 - q^{10}\bigr), \qquad q = e^{-\pi} \approx 0.04321391826,
  $$
  数值精确值为 **$I_{\text{exact}} \approx 1.0903313285699423$**（注：若令积分上下限趋于无穷 $(-\infty, +\infty)$，则 $q^5, q^{10} \to 0$，全实轴极限为 $\frac{1+q}{1-q} = \coth(\pi/2) \approx 1.0903314107273683$，两者相差约 $8.22\times 10^{-8}$；原题在有限区间 $[-5\pi, 10\pi]$ 上必须使用保留有限截断项 $2 - q^5 - q^{10}$ 的精确值 $1.0903313285699423$ 作为高精度容差核对参照）。由于被积函数在 $x = k\pi$（及 $x = 0$）处存在一阶导数跳跃尖点，调用 `integral` 时可分段求积或通过 `'Waypoints', (-5:10)*pi` 显式指定尖点位置以消除跨尖点插值误差。
- **容差阈值说明**：在调用 `integral(fun, -5*pi, 10*pi, 'AbsTol', tol)` 时，`AbsTol` 是自适应求积器内部的局部误差估计停止阈值，并不保证真实绝对误差 $|I_{\text{num}} - I_{\text{exact}}|$ 严格随 `AbsTol` 单调线性下降。

### 1.2 参考题 Q2：函数 $f(x) = \ln(1+x)$ 在 $[0, 2]$（步长 $h = 10^{-5}$）上 $x=1$ 处的数值导数与一基下标 `100001`

原参考题第 2 题给定测试函数 $f(x) = \ln(1 + x)$（精确导数 $f'(x) = \frac{1}{1+x}$，在 **$x = 1$** 处的精确导数值为 $f'(1) = \frac{1}{1+1} = 0.5$；在 $[0, 2]$ 上的精确积分为 $\int_0^2 \ln(1+x)\,dx = 3\ln 3 - 2 \approx 1.295836866$），在区间 **$[0, 2]$** 上取等距步长 **$h = 10^{-5}$** 生成网格 `x = 0 : 1e-5 : 2`（共 $200001$ 个节点）：
- **MATLAB 1-based 下标对齐（$x = 1$ 对应下标 `100001`）**：在 MATLAB 的一基索引（1-based indexing）下，首节点 $x(1) = 0$，第 $k$ 个节点为 $x(k) = (k - 1)h$。因此测试点 **$x = 1.0$ 对应的精确数组下标为 $k = 1 + \frac{1.0 - 0}{10^{-5}} = 100001$**（即 `x(100001) == 1`），切勿按 0-based 思维误取 `100000`！
  - 统一按**“数值差商近似值减去精确导数值 $D_h f(1) - f'(1)$”**的符号约定（注：在 $x = 1$ 处，$f'(1) = \frac{1}{2}, \, f''(1) = -\frac{1}{4}, \, f'''(1) = +\frac{1}{4}$，双精度浮点舍入误差另计）：
    - 在 `idx = 100001` 处，一阶前向差商 `d_fwd = (y(100002) - y(100001)) / h` 的理论截断误差主项为 $+\frac{f''(1)}{2}h = -\frac{1}{8}h = -1.25\times 10^{-6}$；
    - 二阶中心差商 `d_cen = (y(100002) - y(100000)) / (2*h)`（或 `dy = gradient(y, h); dy(100001)`）满足 $\frac{\ln(2+h)-\ln(2-h)}{2h} = \frac{1}{2} + \frac{h^2}{24} + O(h^4)$，故其理论截断误差主项为 **$+\frac{f'''(1)}{6}h^2 = +\frac{1}{24}h^2 \approx +4.17\times 10^{-12}$**（正号；若改按“真值减近似值”约定，则两者的符号同步反转为 $+\frac{1}{8}h$ 与 $-\frac{1}{24}h^2$）。
- **非均匀随机采样点求积**：若给定的随机采样点 $(X_j, Y_j)$ 并非均匀分布，通过样本算术均值 $(b - a)\frac{1}{K}\sum_{j=1}^K Y_j$ 估计积分会产生分布偏差，此时应先按横坐标联合排序 `[Xs, idx] = sort(X); Ys = Y(idx);` 后调用非等距梯形积分 `trapz(Xs, Ys)`。

### 1.3 参考题 Q3：正方形内随机投点命中内切圆估计 $\pi$

在正方形 $[-1, 1]^2$（面积为 $4$）内独立均匀投点 $(X_j, Y_j) \stackrel{\text{i.i.d.}}{\sim} U([-1, 1]^2)$，统计落入单位圆盘 $X_j^2 + Y_j^2 \le 1$（面积为 $\pi$）的命中比例 $\hat{p} = \frac{1}{K}\sum_{j=1}^K \mathbf{1}_{\{X_j^2 + Y_j^2 \le 1\}}$：
- 由于单次试验服从成功概率为 $p = \frac{\pi}{4}$ 的 Bernoulli 分布，估计量 $\hat{\pi} = 4\hat{p}$ 为 $\pi$ 的无偏估计，其方差与标准误差精确满足：

$$
\operatorname{Var}(\hat{\pi}) = \frac{16 p(1 - p)}{K} = \frac{\pi(4 - \pi)}{K}, \qquad \operatorname{Std}(\hat{\pi}) = \frac{\sqrt{\pi(4 - \pi)}}{\sqrt{K}} \approx \frac{1.642}{\sqrt{K}}.
$$

### 1.4 参考题 Q4：半径 $R=2$ 球面上的第一型曲面积分 $\oiint_S (x^2 + \sin x - \operatorname{arsinh} z)\,dS = \frac{64\pi}{3}$ 与采样方差边界

**原题完整被积函数与精确解析解（球面奇偶对称性与轮换对称性）**：
原参考题第 4 题要求计算半径 $R = 2$ 的整个球面 $S = \{(x, y, z) \in \mathbb{R}^3 : x^2 + y^2 + z^2 = 4\}$ 上的第一型曲面积分：

$$
I = \oiint_{x^2 + y^2 + z^2 = 4} \bigl(x^2 + \sin x - \operatorname{arsinh} z\bigr)\,dS.
$$

- **奇偶对称性消去奇函数项**：球面 $S$ 关于平面 $x = 0$ 与平面 $z = 0$ 均严格对称（且曲面面积元 $dS$ 为偶对称），而被积函数中的 $\sin x$ 是关于 $x$ 的奇函数，$-\operatorname{arsinh} z = -\ln\bigl(z + \sqrt{1 + z^2}\bigr)$ 是关于 $z$ 的奇函数，因此在整个球面 $S$ 上有：
  $$
  \oiint_S \sin x\,dS = 0, \qquad \oiint_S \operatorname{arsinh} z\,dS = 0!
  $$
- **坐标轮换对称性求二次项**：由球面关于三个坐标轴的完全轮换对称性，有 $\oiint_S x^2\,dS = \oiint_S y^2\,dS = \oiint_S z^2\,dS$。利用球面方程 $x^2 + y^2 + z^2 = R^2 = 4$ 及半径 $2$ 的球面总面积 $\operatorname{Area}(S) = 4\pi R^2 = 16\pi$，立得原积分的精确解析值为：

$$
I = \oiint_S x^2\,dS = \frac{1}{3}\oiint_S (x^2 + y^2 + z^2)\,dS = \frac{1}{3} \cdot 4 \cdot \operatorname{Area}(S) = \frac{4}{3} \times 16\pi = \frac{64\pi}{3} \approx 67.02064327658.
$$

**原参考解答核对说明（曲面面积元、投影半径笔误与赤道奇异方差）**：
1. **原参考解已正确包含曲面面积元因子**：将整个球面 $S$ 拆分为上半球面 $z = +\sqrt{4 - x^2 - y^2}$ 与下半球面 $z = -\sqrt{4 - x^2 - y^2}$，向底面圆盘 $D = \{x^2 + y^2 \le 4\}$（半径 $R = 2$，圆盘面积 $\pi R^2 = 4\pi$）投影时，曲面面积元雅可比因子为
   $$
   dS = \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy = \frac{2}{\sqrt{4 - x^2 - y^2}}\,dx\,dy.
   $$
   原参考解答 PDF 第 3 页写出的上下半球两项二重积分公式，以及第 4 页 MATLAB 代码中定义的被积函数 `f1` 与 `f2`，**均已显式乘入了面积元因子 $\frac{2}{\sqrt{4 - x^2 - y^2}}$，并在代码末尾乘以底面圆盘面积 $4\pi$**（因此不能误判原参考解遗漏了面积元）。
2. **原参考解文字中的投影半径笔误**：原参考 PDF 正文文字叙述中曾将球面 $x^2 + y^2 + z^2 = 4$ 在 $xy$ 平面上的投影圆盘误写为 **$x^2 + y^2 \le 2$（即半径 $\sqrt{2}$）**，但其实际二重积分上下限与第 4 页代码均按正确的投影圆盘 **$x^2 + y^2 \le 4$（半径 $R = 2$，底面圆盘面积 $\pi R^2 = 4\pi$）**执行。
3. **底面圆盘均匀投点的赤道奇异性与球面均匀采样改进**：
   若在底面圆盘 $x^2 + y^2 < 4$ 上均匀投点并对包含因子 $\frac{2}{\sqrt{4 - x^2 - y^2}}$ 的被积函数求算术均值，由于靠近赤道边界 $r = \sqrt{x^2+y^2} \to 2^-$ 时被积函数无界，且其二阶矩积分 $\iint_D \frac{4}{4 - x^2 - y^2}\,dx\,dy = 8\pi \int_0^2 \frac{r}{4 - r^2}\,dr = +\infty$ 发散，该朴素投影 Monte Carlo 估计量的**理论方差为无穷大**，当随机点偶然落在边界附近时会引发剧烈的数值跳变！
   **高稳健性球面面积均匀采样法**：利用 Archimedes 帽面等面积投影定理（球面面积元 $dS = R\,dz\,d\theta$），直接抽取 $Z \sim U[-2, 2]$、$\Theta \sim U[0, 2\pi)$，并令 $r_{xy} = \sqrt{4 - Z^2}, \, X = r_{xy}\cos\Theta, \, Y = r_{xy}\sin\Theta$，则点 $(X, Y, Z)$ 在半径 $2$ 的球面 $S$ 上**关于球面面积严格均匀分布**，此时估计量 $\hat{I} = 16\pi \cdot \frac{1}{K}\sum_{j=1}^K g(X_j, Y_j, Z_j)$ 完全消除了分母奇异性，方差有界且收敛极快。

```matlab
% 半径 R = 2 球面积分 \oiint_S x^2 dS = 64*pi/3 的球面面积均匀采样实现
rng(2026);
K = 1e6;
Z_sph = -2 + 4 * rand(K, 1);                  % z ~ U[-2, 2]
theta = 2 * pi * rand(K, 1);                  % \theta ~ U[0, 2\pi)
r_xy  = sqrt(4 - Z_sph.^2);
X_sph = r_xy .* cos(theta);

I_exact = 64 * pi / 3;
I_sph_mc = (16 * pi) * mean(X_sph.^2);        % 球面总面积 4*pi*R^2 = 16*pi
fprintf('球面均匀采样估计值 = %.6f, 精确值 64*pi/3 = %.6f\n', I_sph_mc, I_exact);
```

## 二、 数值微积分四道核心算法与推导习题

### 2.1 习题一：中心差商最优步长 $h^* \propto \varepsilon_{\text{mach}}^{1/3}$ 推导与验证

设 $f \in C^3$ 在点 $x$ 邻域内三阶导数满足 $|f'''(\xi)| \le M_3$，计算机计算函数值 $\tilde{f}(x \pm h) = f(x \pm h) + e_\pm$ 存在绝对界为 $|e_\pm| \le \delta = \varepsilon_{\text{mach}}|f(x)|$ 的浮点舍入误差。由 Taylor 展开：

$$
f(x \pm h) = f(x) \pm h f'(x) + \frac{h^2}{2}f''(x) \pm \frac{h^3}{6}f'''(\xi_\pm).
$$

用浮点计算值构造中心差商近似 $f'(x)$，总误差可分解为截断误差与舍入误差之和：

$$
\left|\frac{\tilde{f}(x+h) - \tilde{f}(x-h)}{2h} - f'(x)\right|
\le \frac{|f(x+h) - f(x-h) - 2hf'(x)|}{2h} + \frac{|e_+ - e_-|}{2h}
\le \frac{M_3}{6}h^2 + \frac{\delta}{h} \triangleq E(h).
$$

对总误差上界函数 $E(h) = \frac{M_3}{6}h^2 + \frac{\delta}{h}$ 关于步长 $h > 0$ 求导并令 $E'(h) = 0$：

$$
E'(h) = \frac{M_3}{3}h - \frac{\delta}{h^2} = 0 \implies h^* = \left(\frac{3\delta}{M_3}\right)^{1/3} = \left(\frac{3|f(x)|}{M_3}\right)^{1/3} \varepsilon_{\text{mach}}^{1/3} \propto \varepsilon_{\text{mach}}^{1/3}.
$$

代入最优步长 $h^*$，最小可达总误差量级为：

$$
E(h^*) = \frac{3}{2}\left(\frac{M_3}{3}\right)^{1/3} \delta^{2/3} = O\bigl(\varepsilon_{\text{mach}}^{2/3}\bigr).
$$

在 IEEE 754 双精度下 $\varepsilon_{\text{mach}} \approx 2.22 \times 10^{-16}$，故中心差商的最优步长在 $h^* \approx \varepsilon_{\text{mach}}^{1/3} \approx 6 \times 10^{-6}$ 附近，最小绝对误差约为 $10^{-11}$ 量级（对比一阶前向差商 $E_1(h) = \frac{M_2}{2}h + \frac{2\delta}{h}$，其最优步长为 $h_1^* \propto \varepsilon_{\text{mach}}^{1/2} \approx 1.5 \times 10^{-8}$，最小误差约为 $10^{-8}$）。

```matlab
x0 = 1.0;
f = @(x) exp(x);
h_vec = logspace(-16, -1, 160);
err_fwd = abs((f(x0 + h_vec) - f(x0)) ./ h_vec - exp(x0));
err_cen = abs((f(x0 + h_vec) - f(x0 - h_vec)) ./ (2 * h_vec) - exp(x0));

[min_err_c, idx_c] = min(err_cen);
fprintf('中心差商实测最优步长 h* = %.2e (理论 eps^(1/3) = %.2e), 最小误差 = %.2e\n', ...
    h_vec(idx_c), eps^(1/3), min_err_c);
```

### 2.2 习题二：Romberg 积分（Richardson 外推加速）推导与实现

设复合梯形公式在步长 $h_k = \frac{b-a}{2^k} \, (k = 0, 1, \dots, M)$ 下的近似值为 $R_{k, 0} = T(h_k)$。由 Euler-Maclaurin 求和公式，当 $f \in C^{2M+2}[a,b]$ 时，梯形求积误差具有仅含 $h^2$ 偶次幂的渐近展开：

$$
I - T(h) = c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots + c_M h^{2M} + O(h^{2M+2}).
$$

通过步长逐次折半与 **Richardson 外推（Richardson Extrapolation）** 逐列消去低阶误差项 $h^{2j}$，得到 Romberg 下三角求积表递推公式（对行 $k = 1, \dots, M$，列 $j = 1, \dots, k$）：

$$
R_{k, j} = R_{k, j-1} + \frac{R_{k, j-1} - R_{k-1, j-1}}{4^j - 1} = \frac{4^j R_{k, j-1} - R_{k-1, j-1}}{4^j - 1}, \qquad I - R_{k, j} = O\bigl(h_k^{2j+2}\bigr).
$$

其中第 $j = 1$ 列即为复合 Simpson 序列 $O(h^4)$，第 $j = 2$ 列即为复合 Cotes（Boole）序列 $O(h^6)$。

```matlab
function R = romberg_quad(f, a, b, M)
% ROMBERG_QUAD 构造 (M+1) x (M+1) 阶 Romberg 数值积分加速表 (1-based 下标)
    R = zeros(M + 1, M + 1);
    h = b - a;
    R(1, 1) = 0.5 * h * (f(a) + f(b));

    for k = 1:M
        h = h / 2;
        % 仅计算新增的 2^(k-1) 个中点函数值，复用上一层梯形和
        x_mid = a + (1 : 2 : 2^k - 1) * h;
        R(k + 1, 1) = 0.5 * R(k, 1) + h * sum(f(x_mid));
        for j = 1:k
            R(k + 1, j + 1) = R(k + 1, j) + (R(k + 1, j) - R(k, j)) / (4^j - 1);
        end
    end
end
```

### 2.3 习题三：椭圆周长参数积分（第二类完全椭圆积分）计算

设椭圆方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \, (a \ge b > 0)$，参数方程为 $x(\theta) = a\sin\theta, \, y(\theta) = b\cos\theta \, (\theta \in [0, 2\pi])$，离心率为 $e = \frac{\sqrt{a^2 - b^2}}{a} \in [0, 1)$。由弧长微分 $ds = \sqrt{x'(\theta)^2 + y'(\theta)^2}\,d\theta = a\sqrt{1 - e^2\sin^2\theta}\,d\theta$ 及四象限对称性，椭圆周长为：

$$
L = 4a \int_0^{\pi/2} \sqrt{1 - e^2\sin^2\theta}\,d\theta = 4a \, E(e^2),
$$

其中 $E(m) = \int_0^{\pi/2}\sqrt{1 - m\sin^2\theta}\,d\theta$ 为第二类完全椭圆积分（MATLAB 内建函数 `ellipke(e^2)`，注意输入参数为模数平方 $m = e^2$），展开为幂级数可得：

$$
L = 2\pi a \left[ 1 - \sum_{n=1}^{\infty} \left(\frac{(2n-1)!!}{(2n)!!}\right)^2 \frac{e^{2n}}{2n - 1} \right].
$$

```matlab
a = 5; b = 3;
e2 = (a^2 - b^2) / a^2;                   % e^2 = 16/25 = 0.64
L_quad = 4 * a * integral(@(th) sqrt(1 - e2 * sin(th).^2), 0, pi/2, 'AbsTol', 1e-14);
[~, E_val] = ellipke(e2);
L_ellip = 4 * a * E_val;
fprintf('椭圆周长 integral = %.12f, ellipke 精确值 = %.12f\n', L_quad, L_ellip);
```

### 2.4 习题四：极坐标区域面积计算

由极坐标扇形面积微元 $dA = \frac{1}{2}r(\theta)^2\,d\theta$，极坐标曲线 $r = r(\theta) \, (\theta \in [\alpha, \beta])$ 围成区域的面积为 $S = \frac{1}{2}\int_\alpha^\beta r(\theta)^2\,d\theta$；若区域由外边界 $r_{\text{out}}(\theta)$ 与内边界 $r_{\text{in}}(\theta)$ 共同围成，则面积为：

$$
S = \frac{1}{2}\int_\alpha^\beta \Bigl(r_{\text{out}}(\theta)^2 - r_{\text{in}}(\theta)^2\Bigr)\,d\theta.
$$

以心形线 $r_1(\theta) = 1 + \cos\theta$ 在圆 $r_2(\theta) = \frac{3}{2}$ 外部（或心形线全区域面积 $S_{\text{cardioid}} = \frac{1}{2}\int_0^{2\pi}(1+\cos\theta)^2\,d\theta = \frac{3\pi}{2}$）为例：

```matlab
% 1. 心形线 r = 1 + cos(\theta) 围成的总面积 (精确值 3*pi/2)
r1 = @(th) 1 + cos(th);
S_cardioid = 0.5 * integral(@(th) r1(th).^2, 0, 2*pi);

% 2. 心形线 r1 = 1 + cos(\theta) 在圆 r2 = 1 外部的月牙形区域面积 (-\pi/2 <= \theta <= \pi/2)
r2 = @(th) ones(size(th));
S_crescent = 0.5 * integral(@(th) r1(th).^2 - r2(th).^2, -pi/2, pi/2); % 精确值 2 + pi/4
fprintf('心形线总面积 = %.10f (3*pi/2 = %.10f), 月牙区面积 = %.10f\n', ...
    S_cardioid, 1.5*pi, S_crescent);
```
