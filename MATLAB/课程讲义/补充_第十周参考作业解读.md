### 1.2 Q1：候选生成模型判别与均匀分布 $U[0, \theta]$ 的矩估计 / 最大似然估计

在拿到未知分布的样本矩阵 `A`（容量 $n = 10^6$）时，首先通过频率直方图 `histogram(A(:), 'Normalization', 'pdf')`、经验分布函数 `ecdf` 与极值/分位数特征区分不同的候选生成模型（例如：有界平坦密度对应均匀分布 $U[0, \theta]$、钟形对称无界支撑对应正态分布 $\mathcal{N}(\mu, \sigma^2)$、右偏非负单调衰减且均值等于标准差对应指数分布 $\operatorname{Exp}(\lambda)$）。

确认为均匀分布模型 $X_1, \dots, X_n \stackrel{\text{i.i.d.}}{\sim} U[0, \theta]$（密度 $f(x; \theta) = \frac{1}{\theta} \mathbf{1}_{[0, \theta]}(x)$）后，两种经典点估计量的性质对比如下：
1. **一阶矩估计（Method of Moments）**：由总体期望 $E[X] = \frac{\theta}{2} = \bar{X}$，解得无偏矩估计量：

$$
\hat{\theta}_{\text{MM}} = 2 \bar{X} = \text{\texttt{2 * mean(A(:))}}, \qquad \operatorname{Var}(\hat{\theta}_{\text{MM}}) = \frac{\theta^2}{3n} = O(n^{-1}).
$$

2. **最大似然估计（MLE）**：联合似然函数为：

$$
L(\theta) = \prod_{i=1}^n \frac{1}{\theta} \mathbf{1}_{[0, \theta]}(x_i) = \theta^{-n} \cdot \mathbf{1}_{\{\min_i x_i \ge 0\}} \cdot \mathbf{1}_{\{\theta \ge X_{(n)}\}},
$$

其中 $X_{(n)} = \max_{1 \le i \le n} X_i$ 为最大次序统计量。当 $\theta \ge X_{(n)}$ 时，$L(\theta) = \theta^{-n}$ 关于 $\theta$ 严格单调递减，因此在闭支撑集约定下，似然函数在边界点取得唯一最大值：

$$
\hat{\theta}_{\text{MLE}} = X_{(n)} = \text{\texttt{max(A(:))}}, \qquad E[\hat{\theta}_{\text{MLE}}] = \frac{n}{n+1}\theta, \quad \operatorname{MSE}(\hat{\theta}_{\text{MLE}}) = \frac{2\theta^2}{(n+1)(n+2)} = O(n^{-2}).
$$

（注：若密度严格定义在开区间 $(0, \theta)$ 上，则开集 $\theta \in (X_{(n)}, +\infty)$ 上无最大值点，上确界 $\sup_{\theta > X_{(n)}} L(\theta)$ 在右极限 $\theta \to X_{(n)}^+$ 处达到，统计上仍取 $\hat{\theta}_{\text{MLE}} = X_{(n)}$；当 $n = 10^6$ 时，$\hat{\theta}_{\text{MLE}}$ 的均方误差阶 $O(n^{-2}) \sim 10^{-12}$ 远优于矩估计的 $O(n^{-1}) \sim 10^{-6}$。）

### 1.3 Q2：两组观测数据 `(x1, y1)` 与 `(x2, y2)` 的不同生成模型、鲁棒回归与中值滤波边界

在原参考数据文件 `Q2.mat` 中，包含两组底层生成机理截然不同的观测序列，分析时必须首先加以区分：
- **第一组数据 `(x1, y1)`（光滑周期谐波生成模型）**：底层信号由三角谐波基函数生成（形如 $y = c_0 + c_1 \sin x + c_2 \sin(2x)$ 或含余弦项的低阶傅里叶级数），无离群脉冲，适合直接构造三角设计矩阵 $X = [\mathbf{1}, \, \sin x_1, \, \sin(2x_1)]$ 进行线性最小二乘拟合；
- **第二组数据 `(x2, y2)`（三次多项式基线 $y = 0.5x^3 + 2x^2 + x$ 叠加孤立脉冲异常值）**：底层光滑趋势为三次多项式 $y_{\text{true}}(x) = 0.5 x^3 + 2 x^2 + x$，但部分采样点被大幅值的孤立脉冲噪声污染。

针对含孤立异常点的第二组观测序列 `(x2, y2)`，各去噪与拟合方法的数学边界如下：
1. **一维中值滤波 `medfilt1` 的作用与局限（不保证无失真保峰）**：
   先按自变量升序排列 `[x2s, idx] = sort(x2); y2s = y2(idx);`，调用窗口长度为 $2k+1$ 的一维中值滤波 `medfilt1(y2s, 2*k+1)` **能够有效抑制宽度小于或等于 $k$ 个采样点的孤立单点/窄脉冲异常值**。
   **重要数学边界（反例辨析）**：中值滤波属于非线性次序统计滤波，**绝不保证对正常光滑波形的真实极值峰“无失真”**！例如，考察完全正常的离散光滑峰样本序列 `[0, 1, 2, 1, 0]`，在中心点处取 5 点滑动窗口中值：
   $$
   \operatorname{median}\bigl(\{0, \, 1, \, 2, \, 1, \, 0\}\bigr) = \operatorname{median}\bigl(\{0, \, 0, \, 1, \, 1, \, 2\}\bigr) = 1 \neq 2,
   $$
   真实的局部极值峰 `2` 被直接削平（Clipping）为 `1`！此外，在使用 `medfilt1` 与对照原始数据 `Q2.mat` 时还需注意三点：
   - **窗口宽度选择**：窗口过宽会严重削平真实波形的波峰与波谷；
   - **端点填充效应**：`medfilt1` 默认在序列首尾两端补零（`'zeropad'`），当端点处真实函数值非零时会产生人为的边界塌陷失真（应显式指定 `'truncate'` 截断边界窗口）；
   - **非均匀横坐标畸变**：`medfilt1` 仅按数组下标等距滑动，若横坐标 `x2s` 为非均匀随机采样，下标邻域不等同于空间等宽邻域。
2. **鲁棒回归（Robust Fitting）与谐波基拟合**：
   普通最小二乘（OLS）最小化 $\sum r_i^2$，受单个大离群点影响极大；改用最小绝对残差（LAR，最小化 $\sum |r_i|$）或 Bisquare 双权 M-估计（`fit(x2(:), y2(:), 'poly3', 'Robust', 'LAR')`）可在不预先改写原始纵坐标的前提下直接抵抗离群点。若底层真实规律为谐波信号 $y = c_0 + c_1 \sin x + c_2 \sin(2x)$，则采用三角基函数线性最小二乘拟合比三次多项式具有更准确的全局解释力。

### 1.4 Q3：成绩调分变换与原参考解答已记录的两项具体矛盾核对

针对 `Q3.mat` 中的原始成绩列向量 `score`（实际样本容量为 $N = 152$，即 `152 x 1 double`），对比两类调分方案与原参考脚本的核对记录：
1. **线性 Z-score 标准化**：
   $$
   \text{score}_{\text{linear}} = 80 + 10 \times \frac{\text{score} - \mu}{\sigma}, \qquad \mu = \operatorname{mean}(\text{score}), \; \sigma = \operatorname{std}(\text{score}).
   $$
   仿射线性变换严格将样本均值调整为 $80$、标准差调整为 $10$，但**不改变原始成绩分布的偏度（Skewness）与峰度（Kurtosis）**；若叠加保底截断 `max(score_linear, score)`、满分封顶 `min(..., 100)` 或四舍五入 `round`，该非线性截断会使最终均值与标准差略微偏离 $80$ 与 $10$。
2. **正态分位数映射（Quantile Mapping）与原参考脚本的具体数据矛盾记录**：
   原参考解答试图通过名次百分位秩映射构造正态化调分，但经逐行核对原参考代码与 `Q3.mat` 数据，存在两项明确的内部矛盾（保留原核对记录供复盘对照）：
   - **矛盾一（样本量 $152$ 却硬编码分母 `185`）**：`Q3.mat` 中 `score` 的实际人数为 $N = \text{\texttt{numel(score)}} = 152$ 人，但原参考脚本在计算经验分布秩次分位数时未调用 `length(score)`，而是直接写入了硬编码常数分母 `185`（即按 $i / 185$ 计算累积概率），导致最高分学生的分位数仅达到 $152 / 185 \approx 0.8216$，整批调分后分布被系统性压低；
   - **矛盾二（文字宣称“只升不降”，实测有 $35$ 人分数下降）**：原参考解答在文字说明中宣称该调分方案对所有学生满足“只加分、不扣分（只升不降）”，但将原参考脚本输出的调分结果与原始 `score` 逐人比对（`nnz(score_new < score)`）可见，共有 **$35$ 名学生的调分后成绩低于其原始成绩**！若要严格兑现“只升不降”承诺，必须在变换末尾显式执行保底取大操作 `score_final = max(score_transformed, score)`。

## 二、 第十周概率统计与曲线拟合四道综合习题与代码实现

### 2.1 专题一：Monte Carlo 积分与对偶变量法、重要性抽样方差缩减

计算定积分 $I = \int_0^1 f(x)\,dx$（以 $f(x) = e^x, \, I = e - 1 \approx 1.718281828$ 为例），对比三种采样估计器的方差：
1. **简单随机抽样（Crude MC）**：抽取 $U_1, \dots, U_K \stackrel{\text{i.i.d.}}{\sim} U(0, 1)$，$\hat{I}_{\text{MC}} = \frac{1}{K}\sum_{j=1}^K f(U_j)$，方差为 $\frac{\sigma_f^2}{K}$。
2. **对偶变量法（Antithetic Variates）**：当 $f(x)$ 在 $[0, 1]$ 上单调时，$f(U)$ 与 $f(1 - U)$ 同分布且**负相关**（$\operatorname{Cov}(f(U), f(1-U)) < 0$）。用 $K/2$ 对负相关样本构造无偏估计：
   $$
   \hat{I}_{\text{AV}} = \frac{2}{K}\sum_{j=1}^{K/2} \frac{f(U_j) + f(1 - U_j)}{2}, \qquad \operatorname{Var}(\hat{I}_{\text{AV}}) = \frac{\sigma_f^2 + \operatorname{Cov}\bigl(f(U), f(1-U)\bigr)}{K} \ll \operatorname{Var}(\hat{I}_{\text{MC}}).
   $$
3. **重要性抽样（Importance Sampling）**：选取与 $|f(x)|$ 形状接近且易于逆变换抽样的概率密度 $p(x) > 0$（对 $\int_0^1 e^x\,dx$ 可取线性密度 $p(x) = \frac{2}{3}(1 + x), \, x \in [0, 1]$，其逆变换为 $X = \sqrt{1 + 3U} - 1$），构造无偏估计：
   $$
   \hat{I}_{\text{IS}} = \frac{1}{K}\sum_{j=1}^K \frac{f(X_j)}{p(X_j)}, \qquad X_j \stackrel{\text{i.i.d.}}{\sim} p(x),
   $$
   由于比值 $\frac{e^x}{\frac{2}{3}(1+x)}$ 在 $[0, 1]$ 上几乎为常数，方差可进一步缩减数十倍。

```matlab
function mc_variance_reduction_demo()
% MC_VARIANCE_REDUCTION_DEMO 对比简单 MC、对偶变量法与重要性抽样的方差缩减效果
    rng(2026);
    f = @(x) exp(x);
    K = 10000;

    % 1. 简单 Monte Carlo (K 次函数求值)
    U = rand(K, 1);
    Y_mc = f(U);
    var_mc = var(Y_mc) / K;

    % 2. 对偶变量法 (K/2 对，共 K 次函数求值)
    U_half = rand(K / 2, 1);
    Y_av = 0.5 * (f(U_half) + f(1 - U_half));
    var_av = var(Y_av) / (K / 2);

    % 3. 重要性抽样 p(x) = 2/3*(1+x), F(x) = (2*x + x^2)/3 => X = sqrt(1 + 3*U) - 1
    X_is = sqrt(1 + 3 * U) - 1;
    W_is = f(X_is) ./ ((2/3) * (1 + X_is));
    var_is = var(W_is) / K;

    fprintf('K = %d 下估计量理论方差估计:\n', K);
    fprintf('  Crude MC 方差 = %.3e\n  对偶变量法方差 = %.3e (缩减 %.1f 倍)\n  重要性抽样方差 = %.3e (缩减 %.1f 倍)\n', ...
        var_mc, var_av, var_mc / var_av, var_is, var_mc / var_is);
end
```

### 2.2 专题二：中心极限定理（Central Limit Theorem）数值模拟验证

设 $X_1, X_2, \dots, X_n$ 独立同分布，具有有限期望 $\mu = \mathbb{E}[X_i]$ 与有限正方差 $\sigma^2 = \operatorname{Var}(X_i) \in (0, \infty)$。由 Lindeberg-Lévy 中心极限定理，当样本容量 $n \to \infty$ 时，标准化样本均值依分布收敛于标准正态分布：

$$
Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} = \frac{\sum_{i=1}^n X_i - n\mu}{\sqrt{n}\,\sigma} \xrightarrow{d} \mathcal{N}(0, 1).
$$

```matlab
function clt_verification_demo()
% CLT_VERIFICATION_DEMO 验证强偏态指数分布 Exp(1) 的标准化样本均值向 N(0,1) 收敛
    rng(42);
    M = 20000;                    % 重复抽样实验次数
    n_list = [1, 5, 30, 100];     % 样本容量 n
    z_grid = linspace(-4, 4, 200);

    figure;
    for k = 1:numel(n_list)
        n = n_list(k);
        % 生成 n x M 的 Exp(1) 样本 (理论均值 mu = 1, 标准差 sigma = 1)
        X = -log(rand(n, M));
        X_bar = mean(X, 1);
        Z_n = sqrt(n) * (X_bar - 1) / 1;

        subplot(2, 2, k);
        histogram(Z_n, 45, 'Normalization', 'pdf'); hold on;
        plot(z_grid, normpdf(z_grid, 0, 1), 'r-', 'LineWidth', 1.8);
        title(sprintf('Exp(1) 均值标准化分布 (n = %d)', n));
        xlim([-4, 4]); grid on;
    end
end
```

### 2.3 专题三：非线性模型对数变换线性化拟合与 `lsqcurvefit` 直接拟合对比

考察含加性测量噪声的指数衰减模型 $y_i = a e^{b x_i} + \varepsilon_i \, (a > 0)$：
1. **对数线性化变换拟合（有偏代理目标）**：对两端取自然对数 $\ln y_i \approx \ln a + b x_i$，令 $Y_i = \ln y_i, \, A = \ln a$，调用 `polyfit(x, log(y), 1)` 最小化的是**对数域残差平方和**：
   $$
   \min_{a, b} \sum_{i=1}^N \bigl(\ln y_i - \ln(a e^{b x_i})\bigr)^2 \approx \sum_{i=1}^N \frac{1}{y_i^2}\bigl(y_i - a e^{b x_i}\bigr)^2.
   $$
   由一阶 Taylor 近似 $\ln y_i - \ln \hat{y}_i \approx \frac{y_i - \hat{y}_i}{y_i}$ 可见，对数线性化实质上给**小幅值的尾部数据点赋予了高达 $1/y_i^2$ 的极端权重**，当尾部存在加性背景噪声时会严重拉偏参数估计（且当出现 $y_i \le 0$ 的含噪观测点时对数变换直接失效）。
2. **直接非线性最小二乘拟合（[`lsqcurvefit`](https://www.mathworks.com/help/optim/ug/lsqcurvefit.html) / `nlinfit`）与统计建模注意事项**：直接最小化**原始观测空间的残差平方和**：
   $$
   \min_{a, b} \sum_{i=1}^N \bigl(y_i - a e^{b x_i}\bigr)^2.
   $$
   - **未截断加性高斯模型下的最大似然等价性**：唯有当观测值严格服从**未经人为下界截断（Uncensored）**的加性同方差独立高斯噪声模型 $y_i = a e^{b x_i} + \varepsilon_i\ (\varepsilon_i \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(0, \sigma^2))$ 时，最小化原空间残差平方和 $\sum (y_i - a e^{b x_i})^2$ 的全局极小值点才严格等价于高斯最大似然估计（MLE）。**切忌在生成或预处理数据时强行施加人工保底下限 `y_obs = max(y_raw, 0.02)`**：一旦对高斯观测值做截断（Censoring），数据在下界 $0.02$ 处会产生离散概率质量点（Point Mass），破坏正态分布假设，此时普通最小二乘不再是该截断模型的真实最大似然估计（后者需采用 Tobit 截断似然函数）！
   - **数学上的全局 MLE 等价性与实际局部数值寻优的严格区分**：在数学理论上，未截断加性同方差高斯模型下的最大似然估计等价于原空间残差平方和 $S(a, b) = \sum_{i=1}^N (y_i - a e^{b x_i})^2$ 的**全局最小值点**；但在数值计算中，由于 $S(a, b)$ 是关于 $(a, b)$ 的非凸函数，调用 [`fminsearch`](https://www.mathworks.com/help/matlab/ref/fminsearch.html)、`lsqcurvefit` 或 `nlinfit` 执行的均是**局部搜索**（其中 `fminsearch` 甚至不保证停止点必为局部极小值点）。在工程实践中，可将对数线性化回归得到的参数 $[a_{\text{log}}, b_{\text{log}}]$ 作为非线性最小二乘的一个合理**热启动初值建议（Initial Guess）**，但热启动本身并不从数学上提供收敛至全局（或局部）极小值点的理论保证，对求得的参数仍需核查残差与梯度条件。

```matlab
function log_transform_vs_nonlinear_ls_demo()
% LOG_TRANSFORM_VS_NONLINEAR_LS_DEMO 对比对数变换拟合与非线性最小二乘拟合的原空间 SSE
    rng(2026);
    x = linspace(0, 2.5, 40).';
    a_true = 5.0; b_true = -0.8;
    y_clean = a_true * exp(b_true * x); % 最小真值 5*exp(-2) ≈ 0.6767
    % 叠加未截断的同方差高斯白噪声 N(0, sigma^2), sigma = 0.05, 自然满足全体 y_obs > 0
    y_obs = y_clean + 0.05 * randn(size(x));
    assert(all(y_obs > 0), '样本存在非正值，对数变换不适用');

    % 1. 对数变换线性拟合: ln(y) = b*x + ln(a) (最小化对数域加权残差)
    p_log = polyfit(x, log(y_obs), 1);
    a_log = exp(p_log(2));
    b_log = p_log(1);
    y_fit_log = a_log * exp(b_log * x);
    sse_log = sum((y_obs - y_fit_log).^2);

    % 2. 直接最小化原空间残差平方和（以对数拟合结果为热启动初值，寻优高斯 MLE）
    sse_orig = @(p) sum((y_obs - p(1) * exp(p(2) * x)).^2);
    p_nls = fminsearch(sse_orig, [a_log, b_log]);
    a_nls = p_nls(1); b_nls = p_nls(2);
    sse_nls = sse_orig(p_nls);

    fprintf('真实参数:       a = %.4f, b = %.4f\n', a_true, b_true);
    fprintf('对数变换拟合:   a = %.4f, b = %.4f, 原空间 SSE = %.4f\n', a_log, b_log, sse_log);
    fprintf('非线性最小二乘: a = %.4f, b = %.4f, 原空间 SSE = %.4f (更小)\n', a_nls, b_nls, sse_nls);
end
```

### 2.4 专题四：异方差数据下的加权最小二乘拟合（Weighted Least Squares, WLS）

设线性模型为 $\mathbf{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon}$，其中各观测点的随机误差相互独立但具有不同的方差 $\operatorname{Var}(\varepsilon_i) = \sigma_i^2$（异方差性 / Heteroscedasticity）。由 **Gauss-Markov-Aitken 定理**，选取权重 $w_i = 1 / \sigma_i^2 > 0$（记对角权重矩阵 $W = \operatorname{diag}(w_1, \dots, w_N)$），极小化加权残差平方和：

$$
\min_{\boldsymbol{\beta}} \sum_{i=1}^N w_i \bigl(y_i - \mathbf{x}_i^{\mathsf T}\boldsymbol{\beta}\bigr)^2 = \min_{\boldsymbol{\beta}} \bigl\|W^{1/2}(X\boldsymbol{\beta} - \mathbf{y})\bigr\|_2^2,
$$

当设计矩阵 $X$ 列满秩且 $w_i > 0$ 时，加权正规方程 $(X^{\mathsf T} W X)\boldsymbol{\beta} = X^{\mathsf T} W \mathbf{y}$ 给出最佳线性无偏估计（BLUE）：

$$
\hat{\boldsymbol{\beta}}_{\text{WLS}} = (X^{\mathsf T} W X)^{-1} X^{\mathsf T} W \mathbf{y}.
$$

**MATLAB 实现与关键注意事项**：
- **区分权重 $w_i$ 与标准差缩放因子 $\sqrt{w_i}$**：在调用 `lscov(X, y, w)` 或 `fit(x, y, fittype, 'Weights', w)` 时，传入的 `w` 是目标函数 $\sum w_i r_i^2$ 中的权重 $w_i$；而若使用矩阵左除手工实现白化超定系统 $W^{1/2}X\boldsymbol{\beta} \approx W^{1/2}\mathbf{y}$，则每一行必须乘以**权重的平方根 $\sqrt{w_i}$**：`beta_wls = (sqrt(w) .* X) \ (sqrt(w) .* y)`。
- **加权 SSE 与未加权 SSE 不可直接比大小**：由于权重向量 $w$ 改变了目标函数的量纲与尺度，评估不同模型优劣时不能将加权残差平方和 $\sum w_i r_i^2$ 与未加权残差平方和 $\sum r_i^2$ 直接比较数值大小。

```matlab
function wls_fitting_demo()
% WLS_FITTING_DEMO 异方差观测数据的加权最小二乘拟合 (WLS) 与 OLS 对比
    rng(2026);
    N = 50;
    x = linspace(1, 10, N).';
    beta_true = [2.0; 1.5];               % y = 2.0 + 1.5 * x
    X = [ones(N, 1), x];

    % 异方差噪声：标准差随 x 线性增长 \sigma_i = 0.2 * x_i
    sigma_i = 0.2 * x;
    y = X * beta_true + sigma_i .* randn(N, 1);

    % 1. 普通最小二乘 (OLS)
    beta_ols = X \ y;

    % 2. 最优加权最小二乘 (WLS): w_i = 1 / \sigma_i^2
    w = 1 ./ (sigma_i.^2);
    beta_wls_lscov = lscov(X, y, w);
    beta_wls_qr    = (sqrt(w) .* X) \ (sqrt(w) .* y); % 注意左除白化必须乘以 sqrt(w)

    fprintf('参数真值:   [%.4f, %.4f]\n', beta_true(1), beta_true(2));
    fprintf('OLS 估计:   [%.4f, %.4f] (参数L2误差 = %.4f)\n', ...
        beta_ols(1), beta_ols(2), norm(beta_ols - beta_true));
    fprintf('WLS 估计:   [%.4f, %.4f] (参数L2误差 = %.4f, lscov与QR差异 = %.2e)\n', ...
        beta_wls_qr(1), beta_wls_qr(2), norm(beta_wls_qr - beta_true), ...
        norm(beta_wls_lscov - beta_wls_qr));
end
```
