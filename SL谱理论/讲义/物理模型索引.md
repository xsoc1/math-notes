# SL 谱理论讲义物理模型索引

> [!info] 用途
> 只登记各讲作为“动机”的物理模型，不另设物理章节，也不展开推导。
> 每条给出物理图像、SL 形式、对应讲次与数学落点；详细内容见对应讲次。

| 物理系统 | 物理图像 | 方程 / SL 形式 | 讲次 | 数学落点 |
|---|---|---|---|---|
| 受压杆屈曲 | 达到临界压力时出现弯曲平衡态 | 简支时化为 $-EIy''=Py$ | 01 | 最小特征值=临界载荷，特征函数=失稳模态 |
| 边界条件 | 固定、自由、弹性支撑、闭合环 | $Ky-L(py')=0$ | 01、02 | 自伴边界条件=边界不耗能、互易 |
| 变密度弦/杆 | 密度或刚度随位置变化 | $-(Ty')'=\lambda\rho y$ | 01、02、08 | 权函数的意义、自然频率、Rayleigh 商 |
| 圆膜与悬挂链 | 鼓面振动、链的摆动 | 径向方程化为 Bessel 方程 | 03 | $J_m$ 零点、节线、基频 |
| 球面角向问题 | 球坐标下的 Laplace 方程 | Legendre 方程 | 03 | $P_n$、球面调和、多极展开 |
| 无限深势阱 | 粒子被限制在区间内 | $-\psi''=E\psi$，Dirichlet | 04、05、06、10 | 能级、结点数=量子数、完备性 |
| 弦与管乐器 | 谐波列、节点与波腹 | $u_{tt}=c^2u_{xx}$ | 04、05 | 频率 $f_n=n c/(2L)$、零点计数 |
| 热传导与波动 | 初值分解为衰减/振荡模态 | $-(ky')'=\lambda c\rho y$ | 06、10 | Fourier 展开、谱隙、长期衰减 |
| 能量守恒与互易性 | 无阻尼系统的能量不流失 | 自伴算子 | 07 | 实频率、正交模态、完备性 |
| 点电荷与波导 | 点源响应、腔体共振 | $-\Delta G=\delta$；$-\Delta u=\lambda u$ | 09、11 | Green 函数、截止频率、Weyl 计数 |
| 谱几何 | 听音辨鼓 | 特征值决定鼓声 | 10、11、28 | Weyl 定律、逆谱问题 |

## 物理术语白话表

| 术语 | 白话解释 |
|---|---|
| 互易性 | 在 $A$ 点加力、$B$ 点测位移，与在 $B$ 点加同样力、$A$ 点测位移，结果相同；数学上就是 $G(x,\xi)=G(\xi,x)$ 或 $(Au,v)=(u,Av)$。只对无损耗的线性系统成立。 |
| 屈曲 / 临界载荷 | 压杆在压力达到某个值时突然侧向弯曲，称为屈曲；这个压力就是临界载荷，等于最小特征值。 |
| 弹性支撑（Robin） | 端点接在弹簧或弹性材料上，恢复力与位移成正比，于是出现 $y'=hy$ 型边界条件。 |
| 节线 / 波腹 | 节线是振动中始终不动的曲线；波腹是振幅最大的位置。 |
| 谱隙 | 相邻两个特征值之差，决定最慢衰减模态的衰减速度或迭代收敛速度。 |
| 截止频率 / 共振频率 | 截止频率是“低于它就传不过去”的频率；共振频率是腔体或系统的固有振动频率。两者都由 $\sqrt{\lambda}$ 给出。 |
| 多极展开 | 把远处的静电场或引力场按球谐函数（单极、偶极、四极……）展开，便于提取主导项。 |
| 听音辨鼓 / 谱几何 | 问鼓的振动频率（谱）能否唯一决定鼓的形状；这是逆谱问题的入门版本。 |
| 无阻尼 | 没有摩擦、黏性或辐射等能量损耗的理想系统；自伴边界条件正对应这种情形。 |

> [!note] 阅读约定
> 物理模型只用来解释“为什么会出现这个数学问题”，不替代证明。
> 涉及无穷区间、极限圆或周期系数的模型，会明确标注属于后续奇异/周期理论。
