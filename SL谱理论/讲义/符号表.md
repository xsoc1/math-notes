# SL 谱理论讲义符号表

> [!info] 本讲位置
> 模块：全局参考；用于统一 01–09 及后续讲次的符号。

## 基本对象

| 符号 | 含义 | 说明 |
|---|---|---|
| $[a,b]$ | 有限闭区间 | 正则问题的定义域 |
| $p,q,r$ | SL 方程系数 | $p>0$，$r>0$，$q$ 可变号 |
| $L$ | SL 算子 | $Ly=-(py')'+qy$ |
| $A$ | 带权算子 | $A=r^{-1}L$，作用在 $L^2_r$ 上 |
| $(u,v)_r$ | 带权内积 | $\int_a^b r u\bar v$ |

## 谱与展开

| 符号 | 含义 | 说明 |
|---|---|---|
| $\lambda_n$ | 第 $n$ 个特征值 | $\lambda_0<\lambda_1<\cdots$ |
| $\varphi_n$ | 第 $n$ 个特征函数 | $A\varphi_n=\lambda_n\varphi_n$ |
| $e_n$ | 归一化特征函数 | $e_n=\varphi_n/\sqrt{S_n}$ |
| $S_n$ | 特征函数模方 | $S_n=\int_a^b r\varphi_n^2$ |
| $c_n$ | 广义 Fourier 系数 | $c_n=(f,e_n)_r$ |

## 振荡与相位

| 符号 | 含义 | 说明 |
|---|---|---|
| $W$ | Wronskian | $W=\varphi\psi'-\varphi'\psi$ |
| $\rho$ | Prüfer 振幅 | $\rho=\sqrt{\varphi^2+\varphi'^2}$ |
| $\theta$ | Prüfer 相位 | $\varphi=\rho\sin\theta$，$\varphi'=\rho\cos\theta$ |

## 预解式与变分

| 符号 | 含义 | 说明 |
|---|---|---|
| $G(x,\xi;\lambda)$ | Green 函数 | 预解算子的积分核 |
| $R_\lambda$ | 预解算子 | $(A-\lambda I)^{-1}$ |
| $Q(y),M(y)$ | 二次型与质量 | $Q=\int(py'^2+qy^2)$，$M=\int ry^2$ |
| $R[y]$ | Rayleigh 商 | $R[y]=Q(y)/M(y)$ |

## 证据标记

- `严格证明` / `STRICT`：完整解析证明；
- `数值证据` / `EVIDENCE`：只作直觉或现状说明，不构成证明；
- `猜想` / `OPEN`：明确未解决；
- `NOT-YET-STRICT`：有证明骨架但仍有缺口。
