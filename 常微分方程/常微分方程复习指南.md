# 常微分方程重点与求解方法总览

> [!abstract] 核心概述
> 本篇系统梳理本科阶段常微分方程（ODE）的三大核心支柱：**初等求解方法**、**解的存在唯一性与定性理论**，以及**常系数线性微分方程组与相平面分析**。

---

## 模块一：初等积分法与经典求解方法

初等解法的核心哲学是：**通过变量代换、积分因子或变换，将方程降阶或转化为可直接分离变量的形态**。

### 1. 一阶微分方程分类与解法

| 方程类型 | 标准形式 | 核心解法 / 通解公式 |
| :--- | :--- | :--- |
| **可分离变量型** | $\frac{dy}{dx} = f(x)g(y)$ | 分离变量：$\frac{dy}{g(y)} = f(x)dx$，两边积分（注意检验 $g(y)=0$ 是否产生常数奇解）。 |
| **齐次型** | $\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$ | 换元 $u = \frac{y}{x} \implies y = ux, \ y' = u + x u'$，化为可分离变量型。 |
| **一阶线性方程** | $y' + P(x)y = Q(x)$ | **常数变易法 / 积分因子公式**：<br>$$ y = e^{-\int P(x)dx} \left( \int Q(x)e^{\int P(x)dx}dx + C \right) $$ |
| **伯努利方程 (Bernoulli)** | $y' + P(x)y = Q(x)y^n$ $(n \neq 0, 1)$ | 两边同除以 $y^n$，作代换 $z = y^{1-n}$，转化为关于 $z$ 的一阶线性方程：<br>$\frac{1}{1-n}z' + P(x)z = Q(x)$。 |
| **全微分方程 (恰当方程)** | $P(x,y)dx + Q(x,y)dy = 0$<br>满足 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ | 沿折线积分求势函数 $U(x,y) = \int_{x_0}^x P(t,y)dt + \int_{y_0}^y Q(x_0,t)dt = C$。 |
| **积分因子法** | $\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x}$ | 寻找积分因子 $\mu$：<br>• 若 $\frac{1}{Q}\left(\frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x}\right) = f(x)$，则 $\mu(x) = e^{\int f(x)dx}$<br>• 若 $\frac{1}{P}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = g(y)$，则 $\mu(y) = e^{\int g(y)dy}$ |
| **黎卡提方程 (Riccati)** | $y' = P(x)y^2 + Q(x)y + R(x)$ | 一般无初等通解；**若已知一特解 $y_1(x)$**，作代换 $y = y_1 + \frac{1}{z}$ 可化为关于 $z$ 的一阶线性方程。 |

### 2. 可降阶的高阶微分方程

1. **不显含未知函数 $y$**：$F(x, y', y'') = 0$
   * **方法**：令 $p = y'$，则 $y'' = p'$，降阶为关于 $p(x)$ 的一阶方程 $F(x, p, p') = 0$。
2. **不显含自变量 $x$**：$F(y, y', y'') = 0$
   * **方法**：令 $p = y'$，利用复合求导法则 $y'' = \frac{dp}{dx} = \frac{dp}{dy}\frac{dy}{dx} = p\frac{dp}{dy}$，降阶为关于 $p(y)$ 的一阶方程 $F(y, p, p\frac{dp}{dy}) = 0$。

---

### 3. 高阶常系数线性微分方程

标准形式：$y^{(n)} + a_1 y^{(n-1)} + \cdots + a_n y = f(x)$。

* **齐次通解**：由特征多项式 $\lambda^n + a_1 \lambda^{n-1} + \cdots + a_n = 0$ 的根决定：
  * 单实根 $\lambda$ $\implies C e^{\lambda x}$
  * $k$ 重实根 $\lambda$ $\implies (C_0 + C_1 x + \cdots + C_{k-1}x^{k-1})e^{\lambda x}$
  * 单对共轭复根 $\alpha \pm i\beta$ $\implies e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$
  * $k$ 重共轭复根 $\implies e^{\alpha x}[P_{k-1}(x)\cos\beta x + Q_{k-1}(x)\sin\beta x]$
* **非齐次特解（待定系数法）**：
  * **形式一**：$f(x) = P_m(x)e^{\alpha x}$
    * 设特解 $y^* = x^k Q_m(x)e^{\alpha x}$，其中 $k$ 是 $\alpha$ 作为**特征根的重数**（若非特征根则 $k=0$）。
  * **形式二**：$f(x) = e^{\alpha x}[P_l(x)\cos\beta x + Q_n(x)\sin\beta x]$
    * 设特解 $y^* = x^k e^{\alpha x}[R_m(x)\cos\beta x + S_m(x)\sin\beta x]$，其中 $m = \max(l, n)$，$k$ 是 $\alpha \pm i\beta$ 作为**特征根的重数**。

## 模块二：解的存在唯一性与定性理论

对于初值问题（IVP）：
$$
\begin{cases}
\frac{dy}{dx} = f(x, y) \\
y(x_0) = y_0
\end{cases}
\tag{IVP}
$$
其等价于 **Volterra 积分方程**：
$$
y(x) = y_0 + \int_{x_0}^x f(t, y(t)) dt
$$

```mermaid
graph TD
    A[f(x, y) 在区域 R 连续] --> B[Peano 存在定理]
    A --> C[Picard-Lindelöf 存在唯一性定理]
    B --> B1[局部解存在, 但解不唯一]
    C --> C1[条件: f 关于 y 满足局部 Lipschitz 条件]
    C1 --> C2[在区间 |x-x0| <= h 内存在唯一局部解]
```

### 1. 核心存在与唯一性定理

1. **Picard-Lindelöf 定理（柯西-皮卡定理）**：
   * **条件**：$f(x, y)$ 在矩形域 $R: |x-x_0| \le a, |y-y_0| \le b$ 上连续，且关于 $y$ 满足 **Lipschitz 条件**（$|f(x, y_1) - f(x, y_2)| \le L|y_1 - y_2|$；充分条件为 $\frac{\partial f}{\partial y}$ 在 $R$ 上连续有界）。
   * **结论**：在区间 $|x-x_0| \le h = \min\left(a, \frac{b}{M}\right)$（$M = \max_R |f(x,y)|$）上，(IVP) 存在**唯一的连续可微解**。
   * **证明方法**：构造 **Picard 逐次逼近序列**：
     $$
     y_0(x) = y_0, \quad y_{k+1}(x) = y_0 + \int_{x_0}^x f(t, y_k(t)) dt
     $$
     利用 Banach 空间中的压缩映射原理证明其一致收敛于唯一解。

2. **Peano 存在定理**：
   * **条件**：仅要求 $f(x, y)$ 在 $R$ 上**连续**。
   * **结论**：存在局部解，但**不保证解的唯一性**。
   * **经典反例**：$y' = 3y^{2/3}, \ y(0)=0$。
     * 解有 $y(x) \equiv 0$ 和 $y(x) = x^3$ 等无穷多个解（原因：$\frac{\partial f}{\partial y} = 2y^{-1/3}$ 在 $y=0$ 处发散，不满足 Lipschitz 条件）。

3. **解的延拓定理 (Extension Theorem)**：
   * 若 $f$ 连续且满足局部 Lipschitz 条件，局部解可向两端唯一延拓至最大解区间 $(\alpha, \beta)$。
   * 当 $x \to \beta^-$ 时，点 $(x, y(x))$ 必**趋于定义域的边界或发生爆破（$\|y(x)\| \to \infty$）**。
   * **全局存在性判定（线性增长条件）**：若在带状区域上 $|f(x,y)| \le A(x)|y| + B(x)$，则解在整个区间上全局存在。

4. **解对初值与参数的依赖性**：
   * **连续依赖性**：解 $y(x; x_0, y_0)$ 对初值 $(x_0, y_0)$ 连续。
   * **可微性与变分方程**：若 $\frac{\partial f}{\partial y}$ 连续，则 $\Phi(x) = \frac{\partial y(x; y_0)}{\partial y_0}$ 满足**变分方程**：
     $$
     \begin{cases}
     \frac{d\Phi}{dx} = \frac{\partial f(x, y(x; y_0))}{\partial y} \Phi(x) \\
     \Phi(x_0) = 1
     \end{cases}
     $$

## 模块三：常系数线性微分方程组

一阶常系数线性系统：
$$
\dot{\mathbf{x}} = A \mathbf{x} + \mathbf{f}(t), \quad \mathbf{x} \in \mathbb{R}^n, \ A \in \mathbb{R}^{n \times n}
$$

### 1. 矩阵指数 $e^{At}$ 与通解结构

矩阵指数定义为幂级数：
$$
e^{At} = \sum_{k=0}^{\infty} \frac{A^k t^k}{k!} = I + At + \frac{A^2 t^2}{2!} + \cdots
$$

* **齐次系统解**：$\mathbf{x}(t) = e^{A(t-t_0)}\mathbf{x}_0$。
* **Liouville 公式**：$\det(e^{At}) = e^{\mathrm{tr}(A)t}$。
* **非齐次常数变易公式（Duhamel 原理）**：
  $$
  \mathbf{x}(t) = e^{A(t-t_0)}\mathbf{x}_0 + \int_{t_0}^t e^{A(t-s)} \mathbf{f}(s) \, ds
  $$

### 2. 计算 $e^{At}$ 的四大实用方法

1. **Jordan 标准型与对角化法**：$A = P J P^{-1} \implies e^{At} = P e^{Jt} P^{-1}$。
2. **广义特征向量法（待定指数多项式法）**：针对重根构造链 $(A - \lambda I)\mathbf{v}_k = \mathbf{v}_{k-1}$，直接写出特解 $\mathbf{x}(t) = e^{\lambda t} \sum_{j=0}^{k-1} \frac{t^j}{j!} (A-\lambda I)^j \mathbf{v}$。
3. **Cayley-Hamilton 定理法**：利用特征多项式 $P(A) = 0$，将 $e^{At}$ 降次为 $\sum_{k=0}^{n-1} \alpha_k(t) A^k$。
4. **Laplace 变换法**：$e^{At} = \mathcal{L}^{-1}\left[(sI - A)^{-1}\right]$。

---

### 3. 二维平面自治系统相图与平衡点分类

设 $\dot{\mathbf{x}} = A\mathbf{x}$，平衡点为 $(0,0)$。令 $p = \mathrm{tr}(A) = \lambda_1 + \lambda_2$，$q = \det(A) = \lambda_1 \lambda_2$，判别式 $\Delta = p^2 - 4q$。

| 特征根性质 | 平衡点类型 | 稳定性判别 | 相轨线几何特征 |
| :--- | :--- | :--- | :--- |
| **同号实根** ($q > 0, \Delta \ge 0$) | **结点 (Node)** | $p < 0$ 渐近稳定 / $p > 0$ 不稳定 | 轨线沿特征方向单调汇入或发散 |
| **异号实根** ($q < 0$) | **鞍点 (Saddle)** | 不稳定 | 存在两条渐近线（稳定/不稳定流形），其余呈双曲线分支 |
| **共轭复根** ($\alpha \pm i\beta, \alpha \neq 0$) | **焦点 (Focus/Spiral)** | $\alpha < 0$ 渐近稳定 / $\alpha > 0$ 不稳定 | 轨线呈螺旋线旋转收敛或发散 |
| **纯虚根** ($\pm i\beta, p = 0, q > 0$) | **中心 (Center)** | 中性稳定（Lyapunov稳定） | 围绕原点的闭合椭圆族 |
| **重根且不可对角化** | **退化结点 (Degenerate Node)** | $p < 0$ 渐近稳定 / $p > 0$ 不稳定 | 轨线切向唯一特征向量方向 |
