# 第一篇授课安排与来源核对

## 1. 本篇的教学定位与内容范围

本套材料是面向大学概率论课程的体系化教师讲义，旨在引导学生从问题动机出发掌握现代概率论的集类与测度工具。讲义以任佳刚、刘继成《概率论教程》为主教材，同时参考袁德美、王学军《测度论基础与高等概率论》（上册）以补充外测度构造与好集原理的理论细节。按照全课程约八次课、每次 120 分钟的整体教学规划，第一篇“集类与测度”对应前两次辅导课。

在内容编排上，第一篇系统整合了主教材中与集类及测度公理相关的全部核心模块，具体涵盖：§1.2 中的集合运算、不交化与集合列上下极限；§2.7 与 §3.2 中关于 $\pi$-类、$\lambda_0$-类、代数、$\sigma$-代数、单调类与 $\lambda$-类的定义、等价判据、生成结构以及 $\pi$-$\lambda_0$ 定理、单调类定理、$\pi$-$\lambda$ 定理；§2.8 中利用好集方法推广事件独立性的核心论证；§3.1 中从无穷试验与连续模型引出公理化的建模动机；以及 §3.3 中概率测度的公理体系、基本性质、单调连续性等价判据与五类基本概率模型（详细章节对应关系见第 4 节）。至于主教材前两章中的古典概型、组合计数与初等条件概率计算，以及第三章后续关于条件独立性与随机变量分布的展开内容，则按逻辑归属留待后续篇章讲授。

讲义正文完整保留了全部定义、定理条件与证明过程，作为教师备课母稿与学生课后深入研读的参考资料。在两次课堂的现场讲授中，教师可按照第 2、3 节的时间规划突出主干思想要点，而将测度扩张中篇幅较长的紧致覆盖估计与完备化细节作为备课储备与课后延展阅读。对于一般乘积概率空间的存在性定理，讲义与主教材一致采用准确陈述结论并证明唯一性的处理方式；同时，讲义在 §11.2 中利用对角线紧性方法专门给出了二点无限 Bernoulli 重复试验模型存在性的初等完整证明，以帮助学生具体理解预测度可列可加性的验证过程。

## 2. 第一次课：为什么需要集类，怎样使用生成与推广

| 时间 | 讲授与互动 | 对应材料 |
|---|---|---|
| 0–10分钟 | 以反复抛硬币试验串联事件、概率、随机变量、期望与极限定理；提问“无限次试验的一个基本结果是什么” | [[01_课程总导入]] |
| 10–25分钟 | 从单点长度为零过渡到可列与不可列的区别；剖析长度四项自然要求的内在冲突，推导有理平移覆盖的核心不等式（Vitali 反例） | 正文§1 |
| 25–45分钟 | 梳理集合运算、不交化构造与集合列上下极限；结合有限点集实例辨析 $\pi$-类、$\lambda_0$-类、代数与 $\sigma$-代数的定义及等价判据 | 正文§2、§3.1–3.2、§4.1 |
| 45–60分钟 | 演示如何将两个集合切分为互不相交的原子；通过双向包含关系证明有限集合生成的代数结构 | 正文§3.3、§5.1；E1 |
| 60–65分钟 | 课间休息 | - |
| 65–95分钟 | 详细板演 $\pi$-$\lambda_0$ 定理的“两次固定参数”证明；阐明单调类定理如何纳入可列单调极限，并由此导出 $\pi$-$\lambda$ 定理 | 正文§3.4、§4.2–4.4 |
| 95–110分钟 | 证明有理端点半直线生成实直线 Borel $\sigma$-代数；结合逆像性质说明为何验证随机变量可测性只需考察半直线 | 正文§5.3、§7.3；E6 |
| 110–120分钟 | 指导学生当堂完成可列划分生成 $\sigma$-代数的双向包含证明，教师在关键步骤予以点拨；布置课后练习 E3、E5 | 正文§5.2；E4、E3、E5 |

**课堂板书取舍建议。** 第一次课建议在黑板上完整板演 $\pi$-$\lambda_0$ 定理的“两次固定变元”证明过程，使学生切实看清为什么必须分两步推广；在随后的单调类定理中，课堂板书可重点呈现“验证补封闭—固定生成元—固定任意成员”的三步证明骨架，而不必在同一次课内重复书写三轮高度相似的集合验证细节（完整推导可引导学生课后对照讲义正文研读）。若课堂反馈显示学生在完成 E1 的双向包含证明时仍有困难，可适当精简多维 Borel 矩形（§5.4）的课堂展开时间，优先保证学生扎实掌握生成集类的双向包含证明与好集封闭性检验。

**第一次课结语设计。** “面对 Vitali 不可测集的矛盾，我们并没有放弃为集合赋予长度和概率，而是先找出了能够安全进行可列运算的事件集类，并掌握了从简单生成元推广性质的好集方法。下一次课，我们将在此基础上探讨如何从简单区间出发真正构造出测度。”

**随堂掌握度核查要点。** 课末可通过提问确认学生是否掌握以下三项基本功：(1) 能否准确区分包含关系 $A\subseteq\Omega$ 与属于关系 $A\in\mathcal F$；(2) 给定两个集合 $A,B$，能否熟练写出四个基本划分块并据此确定生成代数的元素个数；(3) 能否准确复述 $\pi$-$\lambda$ 定理与单调类定理各自对初始生成族和目标好集类所要求的封闭条件。

## 3. 第二次课：测度的性质、唯一性与构造

| 时间 | 讲授与互动 | 对应材料 |
|---|---|---|
| 0–10分钟 | 回顾有限—余有限代数的反例，温习 $\pi$-$\lambda$ 方法；引导学生动手写出证明两个概率相等时所需构造的好集类 | E3、E7开头 |
| 10–30分钟 | 讲授测度与概率的公理、基本性质及不交分解证法；推导测度的上下连续性，结合反例强调上连续性中有限性条件的必要性，并证明有限可加下可列可加与连续性的等价性 | 正文§6 |
| 30–50分钟 | 完整板演概率与有限测度唯一性定理；展示等值集类不对交运算封闭的四点反例，帮助学生辨析为何不能将好集类直接视为 $\sigma$-代数 | 正文§7.1–7.2；E7 |
| 50–60分钟 | 对比“有理数集 $\mathbb Q\cap[0,1)$ 上不存在均匀分布”与“实区间 $[0,1]$ 上存在均匀分布”，深化对可列可加性的理解 | E9；正文§11.1、§11.3 |
| 60–65分钟 | 课间休息 | - |
| 65–90分钟 | 阐述从代数预测度、可列覆盖下确界（外测度）到 Carathéodory 可测性切分条件的构造脉络；完整板演外测度可列次可加性的 $\varepsilon 2^{-k}$ 证明，并说明延拓保值与 $\sigma$-有限唯一性的作用机制 | 正文§8–9 |
| 90–105分钟 | 通过两点空间外测度的具体计算，引导学生亲手检验 Carathéodory 可测集，体会“外测度有定义”与“集合可测”的本质区别 | E10 |
| 105–115分钟 | 借助三点空间算例讲解零测集与测度空间的完备化；介绍无限 Bernoulli 抛硬币模型与一维分布函数生成测度的构造意义 | E15；正文§9.3、§10、§11.2 |
| 115–120分钟 | 总结生成集类、测度唯一性、测度存在性与空间完备化四者之间的逻辑关系；布置课后练习 E8、E11、E12、E14 | 题解篇 |

**测度构造部分的课堂讲授策略。** 讲授 §8–9 时，建议先从半开区间长度的自然可加性出发，引出用可列覆盖下确界定义外测度 $m^*$ 的直观思想。课堂板书应重点讲透三个核心环节：(1) 证明外测度可列次可加性时如何通过 $\varepsilon 2^{-k}$ 分配覆盖误差；(2) Carathéodory 切分等式为何要求对一切测试集 $T$ 成立，以及它如何通过切分测试集恢复可加性；(3) 初始代数上的预测度可列可加性如何保证原赋值在扩张后保持不变。至于正文 §8.3 中验证 $\mathcal M^*$ 构成 $\sigma$-代数的完整细节、§9.1 中的紧致覆盖引理、§9.3 中的分布函数测度构造以及 §10 的完备化良定义证明，可在课堂上概述核心思路，将完整推导留作学生课后对照讲义精读。

**学情分层调整建议。** 若班级学生已修读过《实变函数》并熟悉外测度构造，可适当缩减基础定义辨析的时间，改为当堂板演 **E13**（利用单调类定理证明生成代数对 $\sigma$-代数的对称差逼近）与 **E16**（独立性的两次好集推广）；若学生对集合列极限与测度连续性尚不熟悉，则建议在课堂上优先详解 **E11** 与 **E12**（Borel-Cantelli 第一引理）。

## 5. 参考教材补充与文献校勘说明

袁德美、王学军《测度论基础与高等概率论》（上册）在本篇中主要用于补充以下测度论内容（原书 PDF 页码为正文印刷页码 $+15$）：

- **第三章 §3.2（印刷第 65 页）**：好集原理与 $\pi$-$\lambda$ 方法的系统总结；其中习题 3.11(2)（印刷第 66 页）选入本篇正文 §5.2 与例题 E4，用于训练可列划分生成的 $\sigma$-代数。
- **第四章 §4.1–§4.5**：外测度、Carathéodory 可测集、测度扩张定理与测度空间完备化的理论框架；本讲义正文采用更契合课堂认知规律的“先讲测度性质与唯一性，后讲外测度与扩张构造”的顺序予以重组。
- **第四章典型习题与反例**：习题 4.14（印刷第 85 页，生成代数对 $\sigma$-代数的测度逼近）选作例题 E13；习题 4.19（印刷第 91 页，两点空间上的外测度计算）选作例题 E10 并增补了可测集类求解；第四章例 4.50（印刷第 108–109 页，Vitali 不可测集）则作为正文 §1.2 开篇讨论“长度四项自然要求不可兼得”以及《外测度与 Lebesgue 外测度综合题》第三部分的理论依据。

**教材细节校勘注记：**
1. 主教材《概率论教程》§2.7 在讨论“是 $\lambda_0$-类但不是代数”的例子时，若仅假设 $A\cap B\ne\varnothing$，并不足以保证集类 $\{\varnothing,\Omega,A,B,A^c,B^c\}$ 对真差封闭（如例题 E2 追问所示，当 $A\subsetneq B$ 时差集 $B\setminus A$ 可能落在该集类之外）。本讲义正文 §3.1 例 3.4 采用了四点空间 $\Omega=\{1,2,3,4\}$ 上 $A=\{1,2\},B=\{1,3\}$ 的具体模型，由于四个非平凡子集均为二元集、彼此无真包含关系，严格满足 $\lambda_0$-类定义且对交不封闭。
2. 主教材 §3.3 在介绍无穷重独立 Bernoulli 试验模型的柱集预测度权重公式时，将基本字 $(\omega_1,\ldots,\omega_n)\in\{0,1\}^n$（其中成功次数为 $\sum_{i=1}^n\omega_i$）中失败概率 $q=1-p$ 的指数误印为 $1-\sum_{i=1}^n\omega_i$；由于前 $n$ 次试验中失败的总次数应为 $n$ 减去成功次数（例如 $n=2$ 时全失败字 $(0,0)$ 的权重显然应为 $q^2$ 而非 $q^1$），正确的指数应修正为 $n-\sum_{i=1}^n\omega_i$，即基本柱集权重为 $p^{\sum_{i=1}^n\omega_i}q^{n-\sum_{i=1}^n\omega_i}$。本讲义在正文 §11.2 中已按修正后的公式写出。
3. 主教材 §3.3 在介绍 $d$ 维欧氏空间子集 $\Omega\subseteq\mathbb R^d$ 上的几何概率模型时，需显式指明体积正有限条件 $0<m_d(\Omega)<\infty$，以确保比例公式 $P(A)=m_d(A)/m_d(\Omega)$ 的分母非零且有限。本讲义在正文 §11.4 中对此作了明确补充。
