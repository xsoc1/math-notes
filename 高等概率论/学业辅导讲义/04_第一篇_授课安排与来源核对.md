# 第一篇授课安排与来源核对

## 1. 本篇的用途和边界

本套材料是教师讲义，不是把教材压缩成考点清单。任佳刚、刘继成《概率论教程》是主教材；袁德美、王学军《测度论基础与高等概率论》提供测度构造与好集方法的补充。沿用户确定的约八次、每次120分钟安排，第一篇占前两次课。

本次“完整包含任书相关内容”指：集类部分§2.7、§3.2的定义、判据、生成对象与主定理；§1.2中所需集合运算；§2.8独立性推广的方法；§3.1的建模动机；§3.3的公理、性质、连续性与五类模型。不是全文抄录，不是把任书此前所有古典概率、组合计数与条件概率内容都塞入第一篇，也不是声称相关章的全部习题都已解答。具体对应见第4节。

母稿保留完整备课论证。课堂按下面路线选择板演，构造中较长的技术证明可作为教师讲解储备及学生课后读物。一般乘积概率存在定理按任书边界准确引用；本篇另外证明了二点Bernoulli重复模型的存在，但不据此冒称证明了一般乘积存在定理。

## 2. 第一次课：为什么需要集类，怎样使用生成与推广

| 时间 | 讲授与互动 | 对应材料 |
|---|---|---|
| 0—10分钟 | 用反复抛硬币梳理事件、概率、随机变量、期望与极限定理；问“一个无限试验结果是什么” | [[01_课程总导入]] |
| 10—25分钟 | 从点长为零讲到可列与不可列；解释长度的四要求冲突，展示有理平移覆盖的核心不等式 | 正文§1 |
| 25—45分钟 | 集合运算、不交化与集合极限；用有限点集区分π-类、λ₀-类、代数、σ-代数 | 正文§2、§3.1、§4.1 |
| 45—60分钟 | 从两个集合切成原子；验证生成对象的两边包含 | 正文§3.3、§5.1；E1 |
| 60—65分钟 | 休息 | — |
| 65—95分钟 | 详细板演π-λ₀定理的两次固定；说明单调类定理如何补入可列极限，再得到π-λ定理 | 正文§3.4、§4.3—4.4 |
| 95—110分钟 | 半直线生成Borel σ-代数；解释为什么只需可列的有理端点 | 正文§5.3；E6前半 |
| 110—120分钟 | 学生完成可列划分的两个包含，教师只在关键处补全；布置E3、E5 | E4、E3、E5 |

**板书取舍。** 第一次课现场完整证明π-λ₀定理；单调类定理在课堂写出“补封闭—固定生成元—固定任意成员”骨架，完整推导已在正文，不要求在同一课重复抄三轮相似验证。如果学生尚不能完成E1，缩短多维Borel讨论，不挤掉两边包含与好集验证。

**导入的结束句。** “我们没有放弃给集合赋值，而是先明确在哪些集合上可以同时保留需要的运算规则。下一次课要在这样的集类上真正造出测度。”

**离堂检查。** 能否区别$A\subseteq\Omega$与$A\in\mathcal F$；能否列出两集合的非空原子；能否说出π-λ定理两侧各需什么封闭性。学生只会背定理名称，不算会使用。

## 3. 第二次课：测度的性质、唯一性与构造

| 时间 | 讲授与互动 | 对应材料 |
|---|---|---|
| 0—10分钟 | 回收有限—余有限反例，复述π-λ方法；让学生写出“相等的好集” | E3、E7开头 |
| 10—30分钟 | 概率公理、一般测度；从不交分解证明连续性，强调上连续性的有限性条件 | 正文§6 |
| 30—50分钟 | 板演概率唯一性；给出等值类不对交封闭的反例，让学生定位常见错证 | 正文§7.2；E7 |
| 50—60分钟 | 用有理数上不能均匀分布、实区间上可以的对照，回到建模问题 | E9；正文§11.1、§11.3 |
| 60—65分钟 | 休息 | — |
| 65—90分钟 | 区间赋值、覆盖取下确界、Carathéodory切分；完整讲一个关键不等式，说明延拓保值与唯一性各自负责什么 | 正文§8—9 |
| 90—105分钟 | 两点外测度实际计算，检验可测集；让学生解释“有外测度值”为何不等于“可测” | E10 |
| 105—115分钟 | 用三点例子引入完备化；无限抛硬币模型作为构造的另一个用途 | E15；正文§10、§11.2 |
| 115—120分钟 | 总结生成、唯一性、存在性、完备化四件不同的事；布置E8、E11、E12、E14 | 题解篇 |

**构造部分怎样讲。** 先用区间长度说明希望得到什么，再写外测度定义。课堂必须讲清覆盖的$\varepsilon2^{-n}$选择、Carathéodory等式对所有测试集成立、原代数赋值被保留这三点。正文§8.3完整的σ-代数证明、§9.1紧覆盖技术、§9.3分布函数构造与§10完备化证明作为备课母稿保留；若现场逐行板演这些内容，需要增加课时，不以“讲完所有证明”作为两次课的虚假承诺。

**机动题。** 学生已有实变基础时，减少定义辨析，改板演E13的单调类逼近证明；若对概率连续性不熟，优先E11，再讲E12。E16留到随机变量与独立性篇复用，但本篇已给出完整答案。

## 6. 校勘和教学中的准确表述

1. **任书λ₀-类例2，PDF53、印刷51。** 仅假设$A\cap B\ne\varnothing$不足以保证六元素候选类对真差封闭。E2给出嵌套集合反例；正文改用四点、四原子非空的模型。任书PDF55重复使用该断言时，也须保留此条件修正。
2. **任书PDF55的生成类列举。** 用非空原子的全部并进行核对；四原子非空时必须有16个集合。讲义不依赖原文枚举清单，采用E1的双向包含证明，避免漏项和重复项。
3. **任书Bernoulli字权重，PDF86、印刷84。** 原件公式中$q$的指数写成$1-\sum_i\omega_i$，应为$n-\sum_i\omega_i$。否则$n$次试验的权重不符合各坐标相乘。正文§11.2采用修正后的公式并验证相容性。
4. **几何概率，PDF87、印刷85。** 规范化必须要求$0<m_d(\Omega)<\infty$；一般体积测度取值于$[0,\infty]$，不是$[0,1]$。在有界给定区域上的总量虽有限，也未必不超过1。
5. **唯一性定理。** 两测度须在同一生成σ-代数上讨论。有限测度需共同有限总质量；σ-有限版本先局部化，不能做$\infty-\infty$。
6. **不可测集的结论。** 排除的是“全部子集、通常长度、平移不变、可列可加”同时成立，不是说幂集上不能定义任何测度。离散测度和Dirac测度就是反例。
7. **外测度、Borel与完备化。** 外测度对所有子集有值；只有满足切分条件的集合才能进入所构造的可测集类。Borel结构由拓扑生成，完备化还依赖测度。三个过程不混为一谈。
